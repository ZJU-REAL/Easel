# 内容复盘评估维度详解

## Hook 力（前 3 秒 / 首屏吸引力）

| 分数 | 标准 |
|------|------|
| 1-3 | 开头平淡无吸引力，无悬念/冲突/利益点，用户大概率划走 |
| 4-6 | 有一定吸引力但不够强，开头信息密度低或节奏慢 |
| 7-8 | 开头有明确钩子（提问/冲突/数据），能让多数目标用户停留 |
| 9-10 | 前 3 秒即产生强烈好奇/共鸣/冲突感，完播率/阅读率远超同类 |

## 内容结构

| 分数 | 标准 |
|------|------|
| 1-3 | 逻辑混乱，信息堆砌，无清晰主线 |
| 4-6 | 有基本逻辑但节奏平，缺少起伏和转折 |
| 7-8 | 结构清晰，节奏有变化，信息密度适中 |
| 9-10 | 结构精巧，每个段落都有存在价值，节奏感强 |

## 信息密度

| 分数 | 标准 |
|------|------|
| 1-3 | 大量废话/重复，或过于简略缺乏干货 |
| 4-6 | 信息量尚可但有冗余段落 |
| 7-8 | 信息量充足且紧凑，没有明显水分 |
| 9-10 | 每句话都有信息增量，干货密度极高 |

## 互动引导

| 分数 | 标准 |
|------|------|
| 1-3 | 无任何互动引导，评论区冷清 |
| 4-6 | 有简单引导（"点赞关注"）但缺乏互动话题 |
| 7-8 | 有明确的互动问题或争议点，能引发讨论 |
| 9-10 | 互动设计精巧，评论区自发产生二次传播内容 |

## 视觉/排版

| 分数 | 标准 |
|------|------|
| 1-3 | 排版混乱/画面粗糙，影响阅读/观看体验 |
| 4-6 | 基本整洁但无设计感 |
| 7-8 | 视觉舒适，有品牌一致性 |
| 9-10 | 视觉本身就是传播力，用户愿意截图/分享 |

## 平台适配

| 分数 | 标准 |
|------|------|
| 1-3 | 明显不适合该平台的内容形式/调性 |
| 4-6 | 基本适配但未利用平台特有功能/算法偏好 |
| 7-8 | 充分利用平台机制，格式/标签/时长都到位 |
| 9-10 | 深谙平台规则，内容形式与平台算法高度契合 |
