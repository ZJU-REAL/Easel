# 中文去 AI 感规则（权威源）

本文件是 Easel 全项目**中文**去 AI 感的单一权威定义。
英文侧规则见 `phrases-to-remove.md` / `structures-to-avoid.md`，本文件是它们的中文对应与补充。
其他 SKILL（如 xhs-note-creator）的去 AI 化步骤应引用本文件，不再自维护副本。

## 五条核心原则（每次处理前先内化）

1. **删填充，留事实** — 开场白、强调性拐杖词、铺垫句一律删掉
2. **打破公式结构** — 凡"总-分-总"、二元对比、三段式列举，打散重组
3. **变化节奏** — 短句之后跟长句。两项优于三项。段落结尾要不一样
4. **信任读者** — 直接陈述，不软化，不辩解，不手把手引导
5. **删金句** — 听起来像可以被引用的句子，基本是 AI 写的，重写

## 一、禁用词（见一个处理一个）

| 禁用词/结构 | 替换方向 |
|------------|---------|
| 说白了 | 坦率的讲、其实就是、说到底 |
| 值得注意的是 / 值得一提的是 | 直接说，或删掉 |
| 不难发现 | 删掉，直接陈述 |
| 综上所述 / 总的来说 | 用具体回扣句替代，或删掉 |
| 首先…其次…再次…最后 | 口语化转场（"说到这""回到上面那个问题"） |
| 不仅……更…… / 不仅……而且…… | 直接说结论，删掉结构词 |
| 通过……来…… | 改为直接动作句 |
| 此外 / 与此同时 / 与此相关的是 | 删掉，或用"还有一个"直接连接 |
| 这意味着 / 意味着什么 | "那结果会怎样呢""所以呢""换句话说" |
| 本质上 | "说到底""其实" |
| 换句话说 | "你想想看""也就是说" |
| 不可否认 / 毋庸置疑 | 直接正面陈述 |
| 可以说 | 直接说 |
| 某种程度上 | 具体说清楚，或删掉 |

**英文源 AI 词汇（中文翻译版）高频词：** 持久的、格局、关键性的、展示、织锦、彰显了、增强、培养、至关重要、深入探讨、宝贵的、充满活力的 → 见到即删或改具体。

**填充短语替换：** 为了实现这一目标→为此；由于……的事实→因为；在这个时间点→现在；系统具有处理的能力→系统可以处理；在……的背景下→删掉；基于上述分析→所以。

## 二、禁用标点

| 禁用 | 替换 |
|------|------|
| 破折号 `——` | 逗号或句号 |
| 冒号 `：`（用于"标题：内容"内联列表时） | 逗号，或改为疑问句 |
| 装饰性双引号 `""` | 用「」，或直接不加 |

## 三、句式与结构问题

对应英文 `structures-to-avoid.md`，以下是中文高频形态：

1. **长句堆砌** — 一句超 30 字、含多个"通过/对/进行/实现"。拆成 20 字内短句，术语后紧跟具体例子，用句号切断。
2. **段落过渡词堆叠** — 每段开头"首先/其次/最后"。删序号词，用时序叙述（做完这个就去做那个），加细节让过渡自然。
3. **过度强调意义** — "标志着/见证了/是……的体现/奠定坚实基础" → 说出具体改变了什么。
4. **模糊归因** — "专家认为/研究表明/数据证明" → 给出具体来源，无来源就删掉整句。
5. **-ing 式肤浅升华** — "象征着/彰显了/凸显了/体现了" 结尾分词 → 换成具体事实。
6. **宣传性语言** — "充满活力/令人叹为观止/开创性/卓越" → 换成它具体做了什么。
7. **否定式排比** — "不仅……而且……""这不仅仅是……而是……" → 直接说结论。
8. **三段式法则** — AI 强凑三组 → 改成两项或四项。
9. **刻意换词 / 虚假范围** — 同义词循环、"从 X 到 Y" 空泛两端 → 直接陈述。

## 四、交流模式问题

- **AI 助手口吻残留**："希望对您有帮助/当然！/请告诉我/您说得完全正确" → 删掉。
- **谄媚语气**："好问题！您说得完全正确" → 删掉，直接进入内容。
- **过度限定**："可以潜在地可能产生一些影响" → "会影响结果"。
- **通用积极结尾**："未来充满无限可能" → 删掉，或换成具体行动/观察作结。

## 五、注入活人感

去掉坏东西只是一半，还要加进真实个性：

- **情绪体感化** — "我感到非常震撼"→"我当时就愣住了"（写身体反应，不写情绪总结）。
- **论述中故意打断** — "出于好奇我进行了调查"→"没什么特定理由，就是心血来潮，就是单纯的，想看看"。
- **加入私货（第一手细节）** — "实验精度显著提升"→"跑完第三次，精度从 80 飙到 92，我当时就拍了桌子"。AI 编不出第一手动作细节。
- **句式断裂** — 情绪高点用极短句独立成段（如"黑暗森林。"），不能每段都用。
- **承认对立面** — 讲观点前先把读者处境讲透，读者防御心会低很多。

**推荐口语化词组：**
- 转场：坦率的讲、说真的、反正我觉得、怎么说呢、其实吧、你想想看、我跟你说
- 判断：我有时候觉得、我一直觉得、我自己的感受是
- 承认不确定：说实话我也不确定、我自己也还在摸索、可能有些想法还不成熟
- 情绪：我当时就愣住了、想想就觉得兴奋、太离谱了、你敢信

## 六、平台特化：小红书

小红书的去 AI 感在上面通用规则之上，额外要求"素人感"，供 xhs-note-creator 等 SKILL 复用：

- **闺蜜语气** — 像跟朋友私聊，不像品牌宣传。多用"姐妹们""真的会谢""我先冲了""亲测"。
- **素人感** — 不追求完美排版和金句，允许口语碎句、语气词、不对称结构。品牌腔（"赋能""一站式""匠心")直接删。
- **emoji 节奏** — emoji 是断句和情绪节拍，不是装饰。每行 0-2 个，卡在情绪点或分项处，别整行堆砌。
- **痛点前置** — 开头直接戳痛点/给结果，不铺垫"随着……的发展"。
- **卡片文案** — 每张卡 ≤80 字，一张只讲一个点，口语短句 > 完整长句。

## 快速检查清单

- [ ] 有没有"说白了/值得注意的是/综上所述"
- [ ] 有没有"首先/其次/最后"序号词
- [ ] 有没有"不仅……更……"结构
- [ ] 有没有破折号（——）或内联"标题：内容"
- [ ] 连续三句句式长度相同？打断一句
- [ ] 有没有三段式列举？改成两项或四项
- [ ] 有没有"通过……来……"？改直接动作句
- [ ] 情绪表达是体感记忆还是知识性描述？
- [ ]（小红书）语气够不够素人/闺蜜感？emoji 是节拍还是堆砌？

## 质量评分（总分 50）

| 维度 | 标准 | 得分 |
|------|------|------|
| 直接性 | 直截了当 vs 充满铺垫 | /10 |
| 节奏 | 长短交错 vs 机械重复 | /10 |
| 信任度 | 尊重读者 vs 过度解释 | /10 |
| 活人感 | 有体感细节 vs 机械生硬 | /10 |
| 精炼度 | 无冗余 vs 大量废话 | /10 |

- 45-50：可发布；35-44：良好，可继续打磨；<35：AI 味明显，需重修。
