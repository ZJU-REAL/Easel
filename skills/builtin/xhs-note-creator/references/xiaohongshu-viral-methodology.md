# 小红书爆款笔记制作方法论

> 可复用的爆款笔记方法论：素人感设计 + 卖点优先级 + 真实素材优先 + 迭代优化。
> 全文用占位符与规则表述，不绑定任何具体项目 / 品牌 / 生图服务。

## 一、核心原则

> **视觉走 [card-design](../../card-design/SKILL.md) 设计系统**（选风格锁 spec、字大字细、填满画幅、禁大 emoji 廉价感）。本文件只讲**文案与内容**方法论，卡片长什么样以 card-design 为准。

### ❌ 内容上不要做的
1. **堆砌所有功能**：把所有特性都讲 → 没重点
2. **正式文案 / 品牌腔**：书面语、"革命性/颠覆性" → 距离感
3. **纯 AI 生图凑数**：能用真实素材（实拍/截图/对比）就别用假图

### ✅ 内容上要做的
1. **抓核心卖点**：只讲 1-2 个最稀缺的点（见"二、卖点优先级"）
2. **口语化**："有没有"、"宝藏"、"好看哭了"（闺蜜语气）
3. **真实素材优先**：实拍、截图、实际效果对比 > 概念图
4. **痛点共鸣**：说出用户具体场景的困扰

---

## 二、卖点优先级判断法则

### 判断标准（按优先级）
1. **稀缺性** > 常见功能 — 问：别人也能做到吗？独家 > 常见
2. **实用性** > 炫技 — 问：解决什么具体痛点？解决痛点 > 展示技术
3. **可感知** > 抽象概念 — 问：用户能直接看到效果吗？视觉对比 > 文字描述

### 打分法（可套任意主题）

把每个卖点按三维各打 1-5 分，相乘取 Top 1-2 作为核心：

| 卖点 | 稀缺性 | 实用性 | 可感知 | 得分 | 优先级 |
|------|--------|--------|--------|------|--------|
| {卖点A} | {1-5} | {1-5} | {1-5} | 乘积 | 🥇 核心 |
| {卖点B} | … | … | … | … | 🥈 辅助 |
| {卖点C} | … | … | … | … | 🥉 锦上添花 |

**结论**：封面主打得分最高的核心卖点，其余作背书或一笔带过。

## 三、素材使用策略

### 真实素材 > AI 生图

| 内容类型 | 素材来源 | 处理方式 |
|---|---|---|
| **功能/效果对比** | 实际截图 / before-after | 左右分屏或上下对比，加文字标注 |
| **使用场景** | 实拍照片 | 模仿爆款的真实感 |
| **纯文字卡片** | 纯色背景 + emoji | 代码生成或文生图 |

盘点素材时优先用真实素材（实拍、截图、对比图），只有纯文字/概念卡才用文生图。素材路径用工程内相对路径，不要硬编码本机绝对路径。

## 四、爆款封面文案模板

> 下面是**封面文案结构**（钩子怎么写）。封面**视觉**一律走 card-design 的封面骨架（大标题细字重 + 钩子副标 + kicker/信息行），用字号层级和留白营造张力，**不靠大 emoji / 手写感**。

### 模板 A：提问式封面
```
有没有那种
[核心功能描述]
的工具/方法？
[1-2 个关键数据/特点]
```
**适用**：新工具推荐、功能发现

### 模板 B：对比式封面（高转化）
```
左：[对比项 A]   右：[对比项 B]
大字：[反差点，如"几乎看不出差别"]
```
**适用**：有明显效果对比的内容（有真实 before/after 照片时用真实素材卡）

### 模板 C：发现式封面（高共鸣）
```
我发现了个宝藏！
[核心价值]
[解决的痛点]
终于不用 [痛点] 了
```
**适用**：解决痛点的工具/方法

## 五、文案公式库

### 封面钩子 / 标题公式
→ 公共源 `skills/shared/references/hook-title-formulas.md`（提问式/发现式/身份共鸣/对比式/数字冲击/热点切入等，小红书场景通用）。

### 正文结构（3 段式）
```
第 1 段 痛点共鸣："[具体场景痛点]？"
第 2 段 解决方案："[方案] 能做到："✅[卖点1] ✅[卖点2] ✅[卖点3]
第 3 段 社交证明 + CTA："我试了下，[具体效果]" + "[引导互动/拿资源]"
```

### 情绪词库
| 场景 | 正面情绪 | 负面情绪（痛点） |
|---|---|---|
| 发现 | 宝藏、绝了、爱了 | 后悔没早知道 |
| 效果 | 好看哭了、太强了 | 之前白熬夜了 |
| 速度 | 秒出、瞬间搞定 | 等到天荒地老 |
| 质量 | 专业、设计师级 | 土到掉渣 |

## 六、视觉风格

**卡片视觉完全交给 [card-design](../../card-design/SKILL.md) 设计系统**，本文件不再自定义视觉规则（旧版"纯色 + 大 emoji + 手写感 + 看起来不专业 + 文生图 prompt"已废弃——那套糙美学与高级感冲突、执行效果差）。

- 出卡时走 `html_card` 路径：读 card-design → **选一个风格**（想要温柔/生活感就用手账贴纸 / 奶油温柔 / 植物清新；知识/工具用瑞士 / 杂志）→ 锁 spec → 写 HTML → `render_card.py` 渲染 → `card_audit.py` 硬门禁。
- 「素人 / 真实感」诉求通过 card-design 的**风格选择**表达（手账/奶油仍是高质量 HTML 渲染），**不是**靠大 emoji 和糙排版。
- 只有**有真实照片**时才走 Pillow 真实素材卡（`text_on_photo` / `collage`），叠字/拼图也保持克制、不堆 emoji。

## 七、制作流程 SOP

1. **卖点分析**（~5 min）：列全部卖点 → 按"稀缺性 × 实用性 × 可感知"打分 → 选 Top 1 核心。
2. **素材盘点**（~5 min）：实拍/截图/对比图/数据图 → 判断哪些直接用、哪些需生成。
3. **确定封面类型**：有对比图 → 模板 B；解决痛点 → 模板 C；新工具推荐 → 模板 A。
4. **设计卡片结构**：
   ```
   卡片 1（封面）：核心卖点 + 视觉冲击
   卡片 2-3：展开核心卖点（真实素材 + 标注）
   卡片 4：背书 / 对比
   卡片 5：使用场景 / 案例
   卡片 6-7：CTA + 互动引导
   ```
5. **生成卡片**：真实照片卡直接用 + 克制标注；纯文字/概念卡走 card-design（`html_card`：选风格 → HTML → 渲染 → `card_audit`）。
6. **文案优化**：口语化？有情绪词？关键词突出？痛点+解决在位？

## 八、发布前 Checklist

- [ ] 封面抓住了最稀缺的卖点？（不是堆砌所有功能）
- [ ] 视觉走了 card-design 选定风格、填满画幅、`card_audit` PASS？（不是糙卡）
- [ ] 文案口语化？（不是正式文案 / 品牌腔）
- [ ] 优先用了真实素材？（能实拍/截图就不用假图）
- [ ] 关键词突出（字号层级 / 强调色）、层级清晰？
- [ ] 有情绪共鸣（痛点 + 解决）？CTA 清晰？

---

## 九、迭代优化原则

第一版做到 60 分即可，靠迭代提升：快速出稿 → 收集反馈 → 每次改进 1-2 个关键点。
时间分配上，迭代往往比第一版更重要。**真实素材 > AI 生图；聚焦核心卖点 > 功能堆砌；用户痛点 > 功能罗列。**
