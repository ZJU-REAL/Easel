# 镜头一转，世界模型就失忆了？

📢 大家好，分享一下我们近期关于视频世界模型记忆能力的工作： 	 WorldMemBench: A Comprehensive Benchmark for Memory of Video World Models 	 🧭 当镜头转开再转回来，世界还是刚才的样子吗？正在发生的事情，会在看不见的时候继续发展吗？ 	 视频世界模型生成的画面越来越逼真，但它们真的记得刚才的世界吗？🧠 	 💡 为此，我们提出 WorldMemBench，系统评估视频世界模型的“世界记忆”。 	 🧩 两种记忆，分别考察 ① 静态记忆：人物还是同一个人吗？物体外观、形状和场景布局有没有改变？ ② 动态记忆：暂时看不见时，事件能否继续？已经发生的变化，回来后还在吗？ 	 🛠 怎么测？ WorldMemBench 包含 260 个测试案例，覆盖 23 个类别，从四个维度刻画模型能力： ① 静态记忆。通过七项指标分别评估人物身份与外观、物体外观与几何，以及环境的可见内容、深度关系和三维结构。 ② 动态记忆。评估事件在视野外的进展、状态是否持续保留、最终结果是否正确，以及是否符合因果与物理规律。 ③ 视频质量。单独评估画面质量与美学质量。 ④ 相机跟随。衡量模型对指定平移和旋转轨迹的执行准确度。 	 🔍 如何判断模型是否真的“记住了”？ 我们设计了受控的“离开—返回”轨迹，包括沿方形路径平移、反复左右转动，以及从左右转动切换到上下转动。 	 📊 主要发现： ① 记得住静态场景，不代表能维持动态演化。在九个代表性模型中，HY-WorldPlay 在七项静态记忆指标上均排名第一，但仅在 31.7% 的动态案例中成功启动指定事件；LingBot-World 则取得最高的动态记忆综合得分。没有一个模型在四个评估维度上全面领先。 ② 第一次回来没问题，不代表之后都能记住。在连续三次返回的测试中，九个模型的平均静态记忆得分在全部七项指标上逐次下降。 ③ 换一个探索方向，会暴露更多记忆问题。相比重复左右转动，第二次改为上下转动会带来更大的平均退化。 	 🌱 WorldMemBench 为研究世界模型记忆能力提供了一套评测与诊断工具，帮助我们更具体地理解模型在哪里遗忘、何时重置，以及怎样利用历史信息改善长期一致性。 	 🌟 欢迎大家关注项目，交流讨论，也欢迎帮忙点点 GitHub Star，感谢支持！❤️ 	 📄 arXiv：[https://arxiv.org/abs/2610.19063](https://arxiv.org/abs/2610.19063) 🌐 项目主页：[https://zju-real.github.io/WorldMemBench/](https://zju-real.github.io/WorldMemBench/) 💻 Code：[https://github.com/ZJU-REAL/WorldMemBench](https://github.com/ZJU-REAL/WorldMemBench) 🤗 Dataset：[https://huggingface.co/datasets/rescuerz/WorldMemBench](https://huggingface.co/datasets/rescuerz/WorldMemBench)
