# 让CUA从实时反馈中自我蒸馏

📢 分享一下实验室近期关于计算机使用智能体（CUA）的工作： ComputerSD: Online Self-Distillation from Real-Time Feedback for Computer-Use Agents 	 🖱 一个任务失败了，就意味着每一步都做错了吗？CUA 在线训练在线训练大多只看任务最终成功或失败。但几十步操作中，哪些有效、哪些出错？最终奖励很难提供细致的学习信号。 💡 我们希望让 CUA 从每一步操作的实际反馈中学习。在线自蒸馏（On-policy self-distillation, OPSD）让模型借助额外指导，重新评估自己的回答，把概率变化转成 token 级监督。但直接使用它有两个问题：指导可能跟不上实际状态，概率变化也不一定代表操作对错。 🛠 ComputerSD 从真实 GUI 交互中获取实时反馈： ① 用约3.4万条专家标注样本微调 GUI 分析器，根据操作前后的截图生成步骤评分和指导。 ② 同一个策略模型在有、无指导的上下文中，对已生成的回答重新评分，将 token 概率差异转成学习信号。 ③ 用价值门控调节信号强度，强化与步骤判断一致的信号，减弱冲突信号，再与轨迹级 GRPO 联合优化。 📊 在通用模型 Qwen3-VL-8B-Thinking 和专用模型 EvoCUA-8B 上，ComputerSD 在 OSWorld 的成功率分别达到 39.8%和 47.9%，比仅使用任务结果奖励的 GRPO 提高 1.9 和 4.1 个百分点。 ⚡ 我们采用全异步训练框架，让环境交互、GUI 分析、指导重评分和策略更新并行推进，吞吐量达到同步训练框架的 5 倍。 🌱 我们希望 CUA 能将实时反馈内化为自身能力，从真实交互中持续学习。 	 论文、代码现已开放，欢迎大家交流讨论、提交 Issue/PR，也欢迎点点 Star 和Upvote一下，感谢支持！ 📄 arXiv：2609.40253 💻 Code：ZJU-REAL/ComputerSD
