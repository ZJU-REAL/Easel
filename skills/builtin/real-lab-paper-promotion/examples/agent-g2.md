# EMNLP 2026｜长程Agent训练，专家该提示多少？

分享组里最新被 EMNLP 2026 接收的工作：Agent-G²: Gaussian Guidance for Agentic Reinforcement Learning。 	 🤔 长程 Agentic 任务通常只有终局奖励，训练早期容易出现奖励稀疏。现有 Hint-based RL 通过执行部分专家轨迹，将 Agent 引导至更接近成功的状态，但其效果高度依赖 guidance depth：统一的全局调度难以适应不同任务的难度差异，而逐样本搜索又需要大量额外 rollout。 	 💡 我们发现，有效的 guidance depth 并非集中在某个唯一最优点，而是分布在一段 informative band 中，其训练信号呈现近似 Gaussian 的分布结构（σ=0.22，R²=0.92）。基于这一观察，我们提出 Agent-G²：利用训练过程中已有的 rollout 反馈，在线建模不用任务的 Gaussian guidance distribution，并从中采样专家前缀长度。分布中心同时考虑全局训练进度与任务难度，方差则刻画任务内部的不确定性，从而实现细粒度、自适应的 guidance，同时无需额外 probing rollout 或独立的 depth predictor。 	 💡 在ALFWorld 和 WebShop 上，Agent-G² 在 Qwen2.5-1.5B / 7B 两个规模下均取得稳定提升。ALFWorld 成功率分别达到 95.3% / 98.4%；WebShop reward score 达到 92.3，最终购买成功率分别达到 78.9% / 84.4%。同时，相比逐样本 probing 方法，Agent-G² 以更低的 rollout 成本实现了更高效的长程 Agent 强化学习。
