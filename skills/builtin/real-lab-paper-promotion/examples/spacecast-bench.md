# 物体移动后，AI 能推断新的空间关系吗？

💡 看一张房间的照片，我们能判断桌子在哪、哪个物体被挡住。但移动物体或旋转场景后，空间关系会怎样变化？视觉语言模型能看懂眼前的场景，也能预判这些变化吗？ 现有评测大多关注图像中已经呈现的空间关系。我们希望再往前一步，提出了 SpaceCast-Bench，进一步评估模型的预测性空间推理能力：只提供变化前的图像和文字描述的操作，让模型推断变化后的空间关系。 	 🛠 从看懂场景，到推演变化 SpaceCast-Bench 包含来自 ScanNet 和 ScanNet++ 的 182 个真实室内场景、3,862 道题目、16 类任务，分为三个层级： 🔹 L1 静态感知：理解当前的方向、距离、遮挡和附着关系。 🔹 L2 局部预测：移动、旋转或移除一个物体后，相关空间关系如何变化？ 🔹 L3 全局预测：旋转整个场景后，从相机、物体和世界等不同参照系判断方向。 通过分层评测，我们希望进一步区分：模型是没看懂初始场景，还是无法正确更新变化后的空间状态？ 	 📊 测了 21 个模型，差距仍然明显 在评估的基线模型中，最佳得分为 58.0%，人类达到 87.2%；参与评测的空间专项模型仍接近随机水平。 整体得分为 16 类任务准确率的宏平均。 受控分析还发现：模型对当前空间关系的感知能力，并不能直接转化为对变化后空间关系的预测能力。 	 📈 这种能力可以训练吗？ 我们用同一数据构建流程，从与评测集不重叠的场景中生成训练样本。经过分阶段监督微调，Qwen3-VL-4B： ✨ SpaceCast-Bench：34.0% → 65.7% ✨ 六个域外基准宏平均：33.5% → 38.1% 这些结果说明，针对空间状态变化的训练，既能改善预测性空间推理，也能带来一定的跨任务迁移收益。 	 🌱 从理解“现在是什么样”，走向推断“变化后会怎样”，是我们希望继续探索的空间能力。 	 代码和评测数据集已开放，欢迎交流讨论、提交 Issue / PR，也欢迎点个 Star 支持！❤️ 📄 arXiv：2610.12402 💻 Code：ZJU-REAL/SpaceCast-Bench 🤗 Dataset：hongxingli/SpaceCast-Bench
