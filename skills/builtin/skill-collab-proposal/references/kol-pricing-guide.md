# KOL 定价与 KPI 预估参考手册

本文件为 `skill-collab-proposal` 的报价计算和 KPI 预估提供数据基准。所有数字基于 2024-2025 年国内主流社媒平台的行业中位数，仅作参考区间，实际报价受供需、时间节点、垂类等因素影响。

---

## 1. KOL 层级定义

| 层级 | 粉丝量 | 典型特征 |
|------|--------|----------|
| 素人 | <1 万 | 真实用户身份，内容朴素，适合铺量种草 |
| KOC | 1-10 万 | 有一定内容能力，垂类小圈子影响力，性价比高 |
| 腰部 KOL | 10-50 万 | 稳定产出，粉丝粘性强，品牌合作主力军 |
| 头部 KOL | 50-500 万 | 行业影响力显著，品牌背书效应强 |
| 顶流 | >500 万 | 跨圈层影响力，品牌大事件合作首选 |

## 3. 报价调整因子

基础报价需叠加以下因子。多个因子同时适用时，累加后乘以基础报价。

| 调整因子 | 溢价幅度 | 触发条件 |
|----------|----------|----------|
| 垂直度溢价 | +20% 至 +50% | 账号深耕特定垂类（美妆、母婴、3C 等），品牌方看中精准人群 |
| 时效性/节日溢价 | +30% | 双十一、618、春节、情人节等大促/节日期间 |
| 独家排他 | +50% | 要求合作期间不接竞品（排他期通常 1-3 个月） |
| 二创授权 | +30% | 品牌方获得素材的二次剪辑、投流、落地页使用权 |
| 多平台分发 | +20% 至 +40% | 一条内容要求在多个平台同步发布 |
| 置顶/加精 | +10% 至 +20% | 要求内容在账号主页置顶一定时间 |

**计算公式：**

```
调整后报价 = 基础报价 x (1 + 垂直度溢价 + 节日溢价 + 独家溢价 + ...)
```

**示例：** 腰部 KOL 小红书图文，基础报价 10,000 元，垂直度溢价 +30%，节日溢价 +30%：
调整后报价 = 10,000 x (1 + 0.3 + 0.3) = 16,000 元

## 4. CPE 校验

CPE（Cost Per Engagement）用于反向验证报价合理性。

**公式：**

```
CPE = 报价 / 预估互动量
```

**各平台 CPE 合理区间：**

| 平台 | CPE 合理区间 | 说明 |
|------|-------------|------|
| 小红书 | 1-5 元/互动 | 图文互动成本低，视频偏高 |
| 抖音 | 0.5-3 元/互动 | 算法推荐下互动量大，CPE 较低 |
| B站 | 2-8 元/互动 | 弹幕+评论活跃但基数偏小 |
| 微博 | 1-5 元/互动 | 转发链可放大互动 |
| 公众号 | 3-10 元/互动 | 互动形式有限（在看+留言） |

**判断规则：**
- CPE 低于合理区间下限：报价可能偏低，KOL 可能不接受
- CPE 在合理区间内：报价合理
- CPE 高于合理区间上限：报价偏高，建议与品牌方沟通调整或换更高性价比的合作形式

## 5. KPI 预估公式

### 5.1 曝光量预估

```
预估曝光 = 粉丝数 x 平台曝光系数 x 内容类型系数
```

**平台曝光系数：**

| 平台 | 曝光系数 | 说明 |
|------|----------|------|
| 小红书 | 0.15-0.3 | 搜索推荐为主，图文取 0.15，视频取 0.3 |
| 抖音 | 0.5-2.0 | 推荐算法强，中位取 0.8，爆款可超粉丝数 |
| B站 | 0.3-0.8 | 视频取 0.8，动态取 0.3 |
| 微博 | 0.05-0.15 | 信息流竞争激烈，曝光系数低 |
| 公众号 | 0.1-0.3 | 头条取 0.3，次条取 0.1 |

**内容类型系数：**

| 内容类型 | 系数 | 说明 |
|----------|------|------|
| 测评/教程 | 1.2 | 实用价值高，分享率高 |
| 种草/推荐 | 1.0 | 标准基线 |
| 品牌硬广 | 0.6 | 用户抵触，完播/阅读率低 |
| 故事/vlog | 1.1 | 人格化内容，完播率高 |
| 直播切片 | 0.8 | 二次传播有一定衰减 |

**示例：** 10 万粉小红书视频种草
预估曝光 = 100,000 x 0.3 x 1.0 = 30,000

### 5.2 互动量预估

```
预估互动 = 预估曝光 x 平台互动率基线
```

**平台互动率基线：**

| 平台 | 互动率基线 | 包含的互动行为 |
|------|-----------|---------------|
| 小红书 | 3%-8% | 点赞 + 收藏 + 评论 + 分享 |
| 抖音 | 2%-5% | 点赞 + 评论 + 分享 + 收藏 |
| B站 | 3%-10% | 点赞 + 投币 + 收藏 + 弹幕 + 评论 |
| 微博 | 0.5%-2% | 点赞 + 评论 + 转发 |
| 公众号 | 1%-5% | 在看 + 留言 + 分享 |

使用区间时：图文/短内容取低值，视频/深度内容取高值；素人/KOC 取高值（粉丝粘性强），头部/顶流取低值（粉丝基数大但粘性分散）。

**示例：** 续上例，小红书视频互动率取 5%
预估互动 = 30,000 x 5% = 1,500

### 5.3 转化预估

```
预估转化 = 预估互动 x 内容转化率
```

**内容转化率参考：**

| 内容类型 | 转化率 | 适用场景 |
|----------|--------|----------|
| 种草文/测评 | 0.5%-2% | 电商导流、小程序跳转 |
| 带货视频 | 1%-5% | 直接挂商品链接 |
| 品牌曝光 | 不适用 | 无直接转化链路，以曝光/互动为目标 |
| 直播带货 | 3%-15% | 实时转化，受价格和话术影响大 |

**注意：** 转化率高度依赖落地页质量、优惠力度、品类客单价等因素。上表仅作参考基线，实际偏差可达 2-5 倍。对无直接转化链路的品牌曝光类合作，不强行预估转化率。

## 6. 定价速查流程

遇到一个具体合作需求时，按以下步骤操作：

1. **确定层级**：用粉丝量查第 1 节层级表
2. **查基础报价**：用层级 + 平台 + 内容形式查第 2 节报价表
3. **叠加调整因子**：检查第 3 节各项是否适用，计算调整后报价
4. **预估 KPI**：用第 5 节公式逐层计算曝光 → 互动 → 转化
5. **CPE 校验**：用第 4 节公式反算 CPE，对比合理区间
6. **输出区间**：报价和 KPI 均给出保守值-乐观值区间
