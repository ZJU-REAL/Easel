# 合作/联名方案输出模板

> `skill-collab-proposal` 的输出结构模板。SKILL.md 保留执行逻辑，具体 Markdown 骨架在此按需加载。

---

## 模式 A：商单方案

```markdown
# 品牌合作方案：<品牌名> x <账号名>

## 1. 账号概况
（平台、粉丝量、近 30 天平均互动率、内容垂类、过往商单经验）

## 2. 合作形式与报价
| 内容形式 | 报价区间 | CPE 参考 | 推荐理由 |
|----------|----------|----------|----------|
| ...      | ...      | ...      | ...      |

## 3. 内容创意方案（2-3 个方向）
### 方向 A：<标题>
- 形式 / 时长 / 脚本思路 / 植入方式

## 4. KPI 预估
| 指标 | 预估值 | 计算依据 |
|------|--------|----------|
| 预估曝光 | ... | 粉丝数 x 平台系数 x 内容系数 |
| 预估互动 | ... | 曝光 x 互动率基线 |
| 预估转化 | ... | 互动 x 转化率参考 |

## 5. 排期建议
（制作周期、推荐发布时间、节日/热点匹配）

## 6. 合作条款建议
（授权范围、修改次数、结算方式、独家条款）
```

## 模式 B：联名方案

```markdown
# 联名方案：<己方> x <对方>

## 1. 双方概况对比
| 维度 | 己方 | 对方 |
|------|------|------|
| 平台/粉丝量/互动率/受众画像/内容风格 |

## 2. 受众互补分析
（重叠度估算、差异化受众价值、各自能带来的增量）

## 3. 联合内容方案（2-3 种形式）
### 形式 A：<标题>
- 内容分工（谁拍/谁发/谁剪）
- 植入/露出方式

## 4. 互推策略
（交叉引流路径、联动话题/标签、评论区互动剧本）

## 5. 执行排期
| 阶段 | 时间 | 动作 | 负责方 |
|------|------|------|--------|
| 预热期 | ... | ... | ... |
| 发布期 | ... | ... | ... |
| 互动期 | ... | ... | ... |

## 6. 预期效果
| 指标 | 己方预估 | 对方预估 | 计算依据 |
|------|----------|----------|----------|
```
