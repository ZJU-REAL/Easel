# 分析模板（中文社媒竞品拆解）

以下模板全部面向小红书 / 抖音 / B站 / 微博 / 公众号 / 知乎的账号拆解。填不到的字段标注"无公开数据"，不留空、不编造。

## 账号画像卡

```
竞品账号: [昵称]
平台: [小红书 / 抖音 / ...]   粉丝量级: [如 10w+]   获赞收藏: [量级]
定位标签: [3-5 个关键词]      人设: [一句话]
主力格式: [图文 / 短视频 / 中长视频 / 直播 / 轮播 / 合集]
更新频率: [日更 / 隔天 / 周更 / 不规律]   活跃度: [近30天篇数]
代表作 Top3:
  1. [标题] — [互动量级] — [爆点拆解]
  2. ...
  3. ...
一句话打法: [该账号的核心内容公式]
```

## 选题分布表

```
| 选题方向 | 占比 | 代表篇 | 平均互动量级 | 是否常青 |
|---------|------|--------|-------------|---------|
```

统计口径：基于近 30–90 天样本（注明覆盖范围）。占比之和≈100%。

## 内容层 SWOT

```
竞品 SWOT: [昵称]
优势 S: [内容质量 / 更新稳定 / 人设辨识 / 粉丝粘性 — 附证据]
劣势 W: [格式单一 / 选题窄 / 少回评 / 断更 — 证据来自评论区吐槽、更新记录]
机会 O: [未覆盖需求 / 新格式 / 赛道空白]
威胁 T: [对我方的直接竞争压力点]
```

劣势证据来源：内容页高赞吐槽评论、"求出教程/讲得不清楚"类追问、更新断层、格式重复导致的审美疲劳信号。

## 行动建议模板

```
行动建议（按优先级）
1. 定位差异: 当前 vs 建议定位、要占领的人设/选题空白
2. 选题: 竞品盲区 + 质量洼地里可切入的方向
3. 格式: 竞品扎堆 A 格式时用 B 格式突围
4. 节奏: 对照自己产能定更新频率
5. 速赢: 本周可落地的 3 个具体选题（含平台+形式+角度）
```

每条建议必须引用具体竞品证据（"竞品A 用 XX 格式的 XX 篇拿到 XX 量级互动"）。按影响力 × 实施难度排序，区分速赢与长线。
