# 审核维度

## 文本类产物（脚本、文案、小说）

| 维度 | 检查内容 |
|------|----------|
| **完整性** | 是否有开头/主体/结尾，分镜是否齐全，时长是否匹配要求 |
| **任务匹配** | 是否回应了用户的具体要求（主题、时长、风格、镜头数） |
| **格式规范** | Markdown 结构是否清晰，分镜标注是否完整（时间段/画面/台词） |
| **内容质量** | 有没有明显的逻辑断裂、角色混乱、情节跳跃 |
| **平台适配** | （有 Profile 时）是否符合目标平台的内容风格和时长要求 |

## 图片类产物

| 维度 | 检查内容 |
|------|----------|
| **文件存在** | 文件是否实际创建成功 |
| **尺寸/格式** | 是否符合平台要求（竖屏 9:16 / 横屏 16:9 / 正方形） |
| **内容匹配** | 画面是否与描述一致 |

## 视频类产物

| 维度 | 检查内容 |
|------|----------|
| **文件存在** | 文件是否实际创建成功，能否播放 |
| **时长** | 是否在要求范围内 |
| **拼接** | 转场是否自然，有没有黑屏/卡顿 |
