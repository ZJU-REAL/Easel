# 平台规范

> 主线是国内平台（小红书 / 抖音 / B站 / 微博 / 公众号 / 知乎 / 今日头条）。X/Twitter、LinkedIn 作为出海次要兜底，放在文末。

## 证据等级（读规格前先看这个）

平台规则会变、也会互相矛盾（同一件事在不同口径下能差出十倍）。本文件的规格分三档，
**引用前先确认它属于哪一档**，别把行业经验当成官方规则往外讲：

| 标记 | 含义 | 怎么用 |
|------|------|--------|
| **【官方】** | 平台公开文档/公告明文规定 | 可作为硬约束（如字数上限、类目资质） |
| **【经验】** | 运营圈长期流传的经验值，未经官方确认 | 拿来参考、拿来试，**别写成"平台规定"** |
| **【存疑】** | 口径互相矛盾、时效不明 | 只取方向性结论；引用前多源交叉，不给具体数字 |

**写作时必须带年份限定词**（"2025-08 起……"），平台政策变动频繁，没有年份的规则等于没有规则。
拿不准的，宁可写"通常""多数情况下"，也不要编一个精确数字——**编造的平台规则比不确定更伤账号**
（可能被读者当场戳穿，也可能踩到治理红线）。

## 小红书

| 元素 | 规格 |
|------|------|
| 标题 | ≤20 字，带 emoji，制造好奇/利益点 |
| 正文 | 300-800 字，短段落 + emoji 分点 |
| 图片 | 1080×1440（3:4 竖版），封面图决定点击 |
| 图片数 | 图文 1-9 张，首图=封面钩子 |
| 标签 | 5-10 个，正文末尾 #话题 |
| 发布时间 | 11-13 点、19-22 点 |

**内容规则：**
- 封面首图 + 标题决定 90% 点击，正文决定收藏
- 语气口语化、闺蜜感、素人分享感，忌硬广、忌 AI 味
- 多用 emoji 分点，每段 1-3 行，避免大段文字
- 结尾引导收藏/评论（"码住"、"姐妹们冲"、"评论区蹲一个"）
- 违禁词会限流：避免绝对化用语、医疗功效、引流外链话术

## 抖音

| 元素 | 规格 |
|------|------|
| 视频 | 1080×1920（9:16 竖版），15-60s 为主 |
| 标题/文案 | ≤55 字可见，钩子前置 |
| 标签 | 3-5 个，含 1-2 个热点/挑战话题 |
| 音频 | 热门 BGM 提升推荐 |
| 发布时间 | 12-13 点、18-22 点 |

**内容规则：**
- 前 3 秒定生死，钩子必须在开头
- 完播率是核心指标，节奏快、每 3-5 秒有变化
- 字幕/大字报必备（大量静音观看）
- 结尾 CTA："关注不迷路"、"评论区告诉我"、"看到最后有彩蛋"
- 蹭热点音频/话题提升初始推荐

## B站

| 元素 | 规格 |
|------|------|
| 视频 | 1920×1080（16:9）为主，竖屏走动态/小视频 |
| 标题 | ≤40 字，信息量足、带梗或悬念 |
| 封面 | 1146×717，三连引导封面文案 |
| 简介/标签 | 简介前 2 行关键，标签 4-10 个 |
| 时长 | 中视频 3-10 分钟留存最佳 |

**内容规则：**
- 受众年轻、懂梗、反感恰饭硬广，重内容深度与真诚
- 开头 15 秒交代"这期讲什么、为什么值得看"
- 引导"一键三连"（点赞/投币/收藏）+ 弹幕互动
- 标题党适度，标题与内容不符会被差评反噬

## 微博

| 元素 | 规格 |
|------|------|
| 正文 | 140 字精华最佳，可长文但折叠 |
| 图片 | 单图 / 九宫格，配图强化传播 |
| 话题 | 1-3 个 #话题#（双井号包裹）带话题广场流量 |
| 发布时间 | 早 8-9 点、午 12 点、晚 20-22 点 |

**内容规则：**
- 短平快，情绪化/观点化内容易转发
- #话题# 蹭热搜、带话题主持人流量
- @相关大 V/官微 提升曝光（相关时）
- 引导转发+评论（转发抽奖、"转发本条"）

## 公众号

| 元素 | 规格 |
|------|------|
| 标题 | 主标题 ≤64 字，双标题制造点击 |
| 正文 | 1000-3000 字深度文，排版讲究 |
| 首图 | 900×383（2.35:1）封面 |
| 排版 | 小标题分段、重点加粗、留白 |

**内容规则：**
- 打开率靠标题，完读率靠开头 3 段和排版
- 一次只讲一个核心观点，逻辑递进
- 结尾引导"在看/分享/关注"，可留互动话题
- 外链受限，引流靠公众号矩阵和菜单

## 知乎

| 元素 | 规格 |
|------|------|
| 回答/文章 | 800-3000 字，专业、有信息增量 |
| 开头 | 前 3 行给结论或反常识钩子 |
| 结构 | 分点论述 + 案例 + 数据 |
| 标签 | 绑定相关话题，蹭话题流量 |

**内容规则：**
- 专业、理性、有干货，忌口水和情绪化
- 开头先抛结论/反直觉观点，再展开论证
- 用数据、案例、亲身经历建立可信度
- 结尾引导"赞同+收藏"（赞同提升排序权重）

## 今日头条

| 元素 | 规格 |
|------|------|
| 标题 | 【官方】≤30 字；直给信息、不吊胃口（悬念式标题党是平台打击项） |
| 正文 | 【经验】长图文 1200-1800 字（信息增量 + 故事化叙事，短段落 1-4 行）；微头条 200-400 字 |
| 配图 | 【经验】实拍生活场景优先（真实感是信任资产），慎用网图/AI 图 |
| 标签 | 【经验】3-5 个垂类相关话题；跨领域发文会稀释垂类标签 |
| 发布时间 | 【经验】早 6-9 点、午间、晚 21 点后 |

**内容规则：**
- 【经验】受众以中年男性 + 下沉市场为基本盘，"跟长辈聊家常"的语感优于精致文案
- 【存疑】收益含互动权重（评论等互动直接影响分成）：选题为"能被讨论"设计，结尾留开放式问题
- 【官方】发布勾选"头条首发"可获额外分成补贴（2025-08 起与内容质量挂钩）；AI 水文、洗稿、标题党是重点打击项，不享受分成与补贴
- 【官方】医疗/财经/健康等类目需资质认证
- 【经验】时政观点为高风险区，个人号慎碰
- 【经验】排版：小标题分段 + 短段落，移动端优先；结尾引导评论（补充式评论是主要互动形态）
- **交付前必须过 `text-polisher`**（`skills/builtin/text-polisher/`）：AI 水文是头条的重点治理项，
  而"AI 味"和"公文腔/吊胃口"在头条读者侧的体感几乎一致——读着像 AI 写的稿子，
  完读和互动会直接吃亏。走它的「平台特化：今日头条」一节逐条过
  （见 `../../text-polisher/references/zh-ai-markers.md`），并满足中文去 AI 感评分 ≥45/50。

## 次要兜底：出海平台

### X / Twitter

| 元素 | 规格 |
|------|------|
| 字符 | 280（免费）/ 25,000（Premium） |
| 标签 | 1-2 个，多了降互动 |
| 链接 | 降 reach，放第一条回复 |

- 首行钩子决定一切，短句、多换行；提问驱动回复；引用转发优于纯转发。

### LinkedIn

| 元素 | 规格 |
|------|------|
| 字符 | 3,000（帖子），约 210 字符后折叠 |
| 标签 | 3-5 个放末尾 |
| Carousel | PDF，1080×1080 或 1080×1350/页 |

- 前 2-3 行必须在折叠前抓住注意力；个人故事 > 企业公告；外链放评论。
