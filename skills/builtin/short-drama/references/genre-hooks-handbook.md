# 微短剧题材 × 钩子 × 因果反转手册（治「剧情太简单 / 反转空降」）

> 剧情简单 = 没选对题材爽感 + 钩子弱 + **反转是空降的**。本手册给：题材/钩子**素材库** +
> **因果反转生成法**（核心，治空降反转）+ 集末悬念 + 情绪钩子。
> 配套：人物/引擎见 `story-engine.md`；爽点/反派见 `satisfaction-and-villain.md`；落节拍见 `causal-beats.md`。

## 一、题材库（选一个主类，可叠加子类）

> ⚠️「高频反转」列是**素材灵感、不是方法**——具体反转必须过下方第三节的因果测试，别直接套。

| 题材 | 核心爽点/情绪 | 主人物母题 | 高频反转（素材） |
|---|---|---|---|
| **逆袭/扮猪吃虎** | 隐藏身份被揭穿、打脸看不起自己的人 | 落魄者实为大佬 | 亮明身份 / 实力碾压 |
| **战神归来** | 王者归来、护短、横扫 | 退隐强者回归 | 旧敌来犯被反杀 |
| **重生/复仇** | 带记忆重来、精准复仇、改命 | 前世被害今生反击 | 预知未来先下手 |
| **甜宠/先婚后爱** | 心动、宠溺、双向奔赴 | 契约婚→真情 | 醋意/误会→表白 |
| **虐恋/追妻火葬场** | 求而不得、后悔、卑微 | 错过后追悔 | 真相揭开/她要走了 |
| **马甲/身份反转** | 多重隐藏身份被逐层揭穿 | 神秘人 N 重马甲 | 又一个马甲掉了 |
| **豪门恩怨** | 权谋、撕、争产 | 豪门内斗 | 亲情背叛/血缘反转 |
| **穿越/古装宅斗** | 现代智商碾压、逆袭上位 | 穿越者 | 用现代知识破局 |
| **校园/青春** | 心动、成长、热血 | 学生 | 学霸/隐藏身份同学 |

**选题铁律**：微短剧要**单一强爽点 + 高浓度**，别贪多。一句话卖点必须让人「想看被打脸/想磕糖/想看复仇」。

## 二、开场 3 秒钩子公式（每集第一镜必用其一）

- **冲突前置**：一上来就吵/打/绝境——「你敢跟我离婚？」「跪下道歉。」
- **强反差**：身份或场面反差——落魄外卖员被叫「总裁」；婚礼上新娘换人。
- **悬念抛出**：一句勾人的反常话——「这是我重生的第 3 天，我要让他们全部付出代价。」
- **危机倒计时**：明确威胁 + 时限——「三天内还不上钱，就拿命来抵。」
- **忌**：Logo 片头、慢铺垫、大段背景旁白。3 秒内没有钩子 = 划走。

## 三、因果反转生成法（核心 · 治「空降反转」）

反转烂 = 空降（作者需要时凭空出现）。真反转从**已建立的事实**里长出来。每个反转都要能填这句：

```
因为 <已建立的事实/选择>，
原计划 <为何不再成立>，
人物现在只能在 <新代价 A / 新代价 B> 之间行动。
```

**填不出 = 假反转，重做。** 反转必须改变以下至少一项：计划 / 解释 / 关系位置 / 一个高代价的选择。

### 公平揭示 5 问（任何"揭晓"前自查）

1. 观众此前是否见过**足够可解释的线索**？
2. 谁在此前能接触到这个事实、谁不能？
3. 证据**为何此刻**浮现——而不是作者需要时凭空出现？
4. 这个新事实**排除/杀死了哪个旧解释**？
5. 得知后**谁必须改变行动**？

> 核心：强反转来自**「旧事实的新关系」**，而不是又抛一个更大的秘密。

### 别把四种动作混为一谈

- **信息揭示**：观众/角色获得一个已存在的事实。（只揭示、没人改选择 → 不算反转）
- **方向性反转**：已有事实使计划/解释/关系位置失效。（这才是"反转"）
- **情绪回报**：承诺的怕/甜/爽/虐/暖落在一个可感知的结果上。
- **情节钩子**：新决定/危险/问题让状态继续运动。（只藏一句到结尾 → 是"withhold"，不一定是钩子）

### 反转节奏

- 一集 **≤1 个大反转**；全剧 **≤3 个核心大反转**；小反转可密。
- 别逐集轮换机制。对比相邻两集：压力源是否**学习**了？主角策略是否变了？代价落在哪个价值上？
- 重复能服务节奏，但**第二次出现应产生新意义或更难的选择，而不是"形容词更大声"**。

## 四、集末悬念（cliffhanger）类型库（每集末必留其一，力度 > 本集所有冲突）

- **危机钩**：更大威胁降临——「话音未落，一群黑衣人堵住了门。」
- **反转钩**：局势/认知被颠覆——「她摘下面具，竟是他失踪三年的妻子。」
- **信息钩**：关键真相只露一半——「其实那晚，真正动手的人是——」（切）
- **误会升级钩**：误会即将酿成大错——她转身要签的，是让他万劫不复的合同。
- **期待钩**：预告下集对决/揭晓——「明天的董事会，我要让你们知道谁才是老板。」

## 五、情绪钩子清单（贯穿全集，制造「上头」）

好奇 · 愤怒 · 爽 · 甜 · 虐 · 揪心 · 意外。**每集至少命中 2 种**，且情绪有起伏（先压后放，见 `satisfaction-and-villain.md`）。

## 六、和别的文件的关系

- 题材/爽点 → 写进 `series-bible-schema.md` 的「一句话卖点 / 戏剧承诺 / 爽点节奏表」。
- 人物为何可跟随、反派阶梯 → `story-engine.md` + `satisfaction-and-villain.md`。
- 每集开场钩 + 因果反转 + 集末悬念 → 落到 `causal-beats.md` 的节拍，展开成 `script.md`。
- 写完用 `drama-review-rubric.md` 的 C 门（因果反转一句话测试）自评，填不出的反转重做。
