# 网文创作方法论

> 网文≠传统文学。核心是**留存**：读者随时可划走，每一段都要给「继续读下去」的理由。
> 下面是可执行的规则，不是文学理论。

## 一、黄金三章（决定生死）

平台推荐与读者弃书都集中在前三章。目标：**第 1 章抓住、第 2 章加深、第 3 章锁定追读**。

- **第 1 章 = 3 秒法则**：开篇 300 字内给出「冲突 / 反差 / 悬念 / 金手指信号」之一，别铺垫世界观。
  - 反例：花两页写天气和身世。正例：一睁眼就身处绝境 / 被打脸 / 捡到系统。
- **代入感**：主角要有一个读者能共情的「缺」（被轻视、被夺走、憋屈），让读者想替他翻盘。
- **爽点前置**：第 1 章末至少一个小爽点（打脸/逆袭/获得），别等到十章后。
- **每章末强钩子**：见下「钩子库」。三章各留一个越来越大的悬念。

## 二、爽点公式

爽 = **压抑 → 爆发 → 反馈**。三段缺一不可：

1. **压抑**：先给委屈/危机/被低估（读者攒情绪）。
2. **爆发**：主角出手/翻盘/揭示实力（兑现）。
3. **反馈**：旁观者震惊/打脸对象崩溃/地位提升（放大爽感）。

节奏：**小爽点每章 1 个，大爽点每 3–5 章一个高潮**。长期只憋不爽 = 弃书。

## 三、章末钩子库（每章必留一个）

| 钩子类型 | 做法 |
|---|---|
| 危机钩 | 章末抛出更大威胁/绝境 |
| 悬念钩 | 关键信息只露一半（"那人转过身，竟是——"） |
| 反转钩 | 局势突然翻转，颠覆本章认知 |
| 期待钩 | 预告下一场对决/揭晓/获得 |
| 情绪钩 | 情感爆点（重逢/背叛/牺牲）戛然而止 |

**忌**：章末平淡收束（"这一天就这样过去了")=主动放读者走。

## 四、追读节奏（长期留存）

- **信息差驱动**：始终让读者比某些角色多知道一点，或比主角少知道一点——两种都能拉动追读。
- **目标链**：主角永远有一个「当前小目标」+「远期大目标」，达成一个立刻抛下一个，不留空窗。
- **伏笔管理**：埋下的伏笔必须回收，回收时给「原来如此」的爽感；用 `bible/canon.md` 登记状态（埋下→回收），别埋了忘。
- **配角功能化**：每个反复出现的配角都要有推动主线的功能，否则删。

## 五、去 AI 味（网文语境）

网文最忌「书面腔 / 翻译腔 / 议论文腔」。规则：

- **删议论**：不写"值得注意的是""综上所述""不难看出"——叙事不解说。
- **少连接词**：连续"于是/然后/接着"是 AI 特征，用动作和画面推进代替。
- **动作代替形容**：不写"他很愤怒"，写"他攥紧了拳，指节发白"。
- **对话推进剧情**：多用短对话带出信息和冲突，少大段独白。
- **句式有长短变化**：全是中长句 = AI 味；关键处用短句甚至单句成段制造节奏。
- **避免陈词**：机械 slopcheck 会扫"缓缓地/深吸一口气/嘴角勾起/眼中闪过一丝/五味杂陈"等；把这些禁用词写进 `bible/voice.md`，命中即换。

## 六、文风指纹（bible/voice.md 要定死的）

- **人称视角**：第一人称（代入强）/ 第三人称限知（灵活）/ 上帝视角（少用）。全书统一。
- **时态与语气**：过去时叙述 / 现在时（少见但有张力）。
- **句式节奏**：偏短快（都市/爽文）还是偏细腻（言情/仙侠）。
- **用词库**：该用什么梗/称呼/口头禅，禁用什么。定下后所有章节遵守，靠它保证文风统一（换风格用 style-transfer）。
