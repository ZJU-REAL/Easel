## 3.2 最佳帖子（Top 3）

按平台核心指标排序，取 Top 3：小红书按收藏，抖音/B站按完播 + 互动，微博/公众号按互动率（无对应指标时统一用互动率）。

对每条帖子分析：
- **内容**：主题、格式、所属支柱
- **关键指标**：触达、互动率、保存数、分享数
- **成功原因**：归因到具体元素 — 开头钩子、格式选择、话题热度、发布时间、CTA 设计、内容支柱
- **可复制模式**：提炼可在下月重复使用的策略

---

## 3.3 最差帖子（Bottom 3）

按触达或互动率排序，取 Bottom 3。

对每条帖子分析：
- **内容**：主题、格式
- **失败原因假设**：弱开头、话题与格式不匹配、过度推销、发布时间差、受众太窄
- **教训**：下月应避免的做法

## 3.5 格式表现

| 格式 | 帖子数 | 平均触达 | 平均互动率 | 平均保存 |
|------|--------|----------|-----------|----------|
| 单图 | | | | |
| 轮播 | | | | |
| Reels/短视频 | | | | |

回答：
- 格式组合是否合理？
- 轮播是否如预期带来更高保存？
- Reels 是否在拉动触达？
- 注意：Reels 触达天然高于其他格式（算法推荐给非粉丝），不直接对比触达绝对值

---

## 3.6 开头分析

提取 Top 和 Bottom 帖子的首句（文案第一行），识别：

- Top 帖子的开头类型：提问、大胆断言、故事、列表、反常识？
- Bottom 帖子的开头类型？
- 开头风格与互动率之间是否存在可观测的模式？

仅在有文案数据时执行，无文案则跳过并标注。

---

## 3.7 发帖节奏

- 实际发帖数 vs 计划发帖数（对比 `context/content-calendar.md`）
- 是否有空白期（连续多天/整周未发帖）？
- 发帖一致性与触达/粉丝增长是否有关联？
- 发帖日期和时间分布（如有最佳时段数据，交叉对比）

---

## 竞品观察（阶段 4，可选）

仅在有竞品账号且配置了 Firecrawl 或 Playwright MCP 时执行。

对每个竞品账号：
- 上月发帖频率
- 内容组合（话题分布）
- 格式偏好
- 可观测的互动水平

汇总为 4-6 条要点，框架："我方做了 X，竞品做了 Y — 值得关注的点是……"

无 MCP 工具时跳过，在报告中注明"竞品分析需配置 Playwright/Firecrawl 工具"。

## 内部评分框架

综合评分 1-10，用于 `context/review-history.md` 趋势追踪：

| 维度 | 权重 | 评分依据 |
|------|------|----------|
| 互动率 vs 基准 | 25% | 对比 `references/benchmarks.md` 对应粉丝量级的基准 |
| 粉丝增长趋势 | 20% | 正增长、加速增长得高分 |
| 最佳帖子表现 | 20% | Top 帖子的保存/互动绝对值和相对表现 |
| 排期执行率 | 15% | 实际 vs 计划的完成比例 |
| 触达趋势 | 20% | 月环比触达变化方向 |

评分用于展示长期趋势，不用于评判。
