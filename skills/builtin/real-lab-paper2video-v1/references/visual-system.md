# 页面、原图与动效

## 视觉基准

尺寸以1920×1080为基准，其他分辨率按比例调整；改变画幅时重新安排布局。

按论文主题、原图中的主要色彩和用户偏好选择配色。以低饱和中性色承载背景，正文与背景保持清楚的明暗对比，选一种主强调色串联标题重点、关系线与进度。辅助色用于区分类别或状态，同一语义全片用色一致，论文原图保留原色。

浅灰＋深蓝＋蓝紫、米白＋深棕＋陶土橙、暖白＋墨色＋青绿都适用。先在一张密集图表页上检查正文、原图与强调标记的可读性，再推广到全片。模板中的暖白/墨色/青绿提供一套可替换的示例配色；在CSS `:root` 中统一修改颜色变量。

| 项目 | 默认设置 |
|---|---|
| 背景 / 正文 / 强调 | 低饱和背景 / 高对比正文 / 一种主强调色 |
| 辅助文字 / 分隔线 | 随主配色选取协调的中性色，保持文字可读、分隔线轻淡 |
| 字体 | 已安装、中文字形完整的无衬线字体；数字使用tabular-nums |
| 左右安全边 | 80–96px |
| 主标题 / 正文 / 字幕 | 54–64px / 30–40px / 约40px |
| 字幕区 | 分隔线默认y=934，字幕居中排在线下 |
| 图像外框 | 白色背景、22px内边距、12px外圆角 |
| 图像适配 | contain等比适配，保留完整内容 |
| 图框间距 | 白边外缘至字幕线≥32px；线在y=934时，图框底边≤902 |

先分配字幕区，再安排标题、文案和图框。白边包含在图框尺寸内，按整个外框计算间距。出处记录在工程元数据或片尾；页脚用字幕、页码与细进度线建立清晰层级。

每页保持一个明确的视觉焦点，用充足留白分隔信息。主标题只放一处，侧栏补充证据或解释，字幕忠实跟随口播。检查页眉、侧栏与底部，将重复或同义的标题合并到主标题；按讲解需要保留标签、装饰与动画，使画面干净、阅读顺序清楚。

## 按内容选择页面

| 页面 | 版式与动作 |
|---|---|
| 开场 | 根据素材选择 teaser、代表性成果图、标题或问题引入；需要解释关系或变化时，再加入简洁示意与动画 |
| 核心想法 | 用输入/输出、训练/推理或前后对比，突出一个关键差异 |
| Pipeline全景 | 展示完整原图，配一句总览和两三个短要点 |
| 方法细讲 | 固定Pipeline的位置与大小，侧栏切换解释，依次提示具体模块 |
| 实验结果 | 完整表格/曲线配一个大字号结论，标明模型、指标及比较对象 |
| 消融 | 完整原图配一句机制解释，强调最能支撑该解释的对比 |
| 收尾 | 一句贡献、简短适用边界、论文/代码入口 |

选择开场素材时，看它能否在短时间内直观传达研究问题或主要亮点。合适的 teaser 可配一句标题直接展示；缺少合适图片时，用标题或问题建立主线，按解释需要补充元素与动画。模板中的概念动画是一种可选示例，具体构图随内容确定。

图的纵横比决定具体区域。横向Pipeline适合左侧说明、右侧原图；宽图表可采用上方结论、下方整图。遇到密集图，优先扩大原图区域、精简侧栏，必要时增加一页讲解。

## 原图与强调

以整张Figure/Table为显示单位，保留所有子图、图例、标签、箭头及表格行列。优先使用矢量或原生高分辨率资产；从PDF提取时覆盖完整图表区域。用外框大小和位置完成构图。

按当前旁白决定强调方式：

| 讲解内容 | 画面处理 |
|---|---|
| 介绍整体方法、展示整体结果 | 保持整图稳定，侧栏概括结论 |
| 解释特定模块、连接或门控 | 短暂框住对应区域 |
| 报告某个实验数值 | 核对模型组、方法行和指标列，再框对应单元格 |
| 连续比较多个目标 | 按口播顺序逐个出现，每次保持一个框 |

框选记录包含 `id, scene, start, end, sourceSize, rect, target, evidence`。边框默认2–3px、透明填充，优先使用全片强调色；与原图局部颜色接近时，使用对比更清楚的协调色，并在同类图中保持一致。约0.18秒淡入淡出，边线贴近目标外缘并与字形留出空间。上一框退出后再显示下一框。

用原图坐标换算位置。外框为 `(X,Y,W,H)`、内边距为 `p`、源尺寸为 `(Sw,Sh)`：

- `s=min((W-2p)/Sw,(H-2p)/Sh)`
- `Cw=Sw*s, Ch=Sh*s`
- `Cx=X+p+(W-2p-Cw)/2, Cy=Y+p+(H-2p-Ch)/2`
- 源矩形 `(x,y,w,h)` 映射为 `(Cx+x*s,Cy+y*s,w*s,h*s)`

定位尺寸与文件尺寸采用相同纵横比。先在高分辨率原图或PDF字框上确定目标，再检查成片中的位置。可直接使用 `Motion.mapHighlight` 完成换算。

## 动画与转场

让动作对应信息变化：关系线随讲解画出，条件门控随解释切换，输入输出依次出现，实验结论按顺序强调。阅读密集证据时保持稳定。

将页面分为两层：

- `visual`：原图、示意图和随图定位的框选。
- `copy`：标题、正文、大数字、标签和解释链。

使用0.64秒smoothstep擦入，边界t0前后各0.32秒：

1. 转场开始后，前页copy在0.24秒内淡出。
2. visual使用互补遮罩：前页显示`[0,edge]`，后页显示`[edge,width]`，其中`edge=width*(1-smoothstep(progress))`。
3. 擦入完成后，后页copy用0.24秒淡入。
4. 页眉、字幕轨、安全区保持固定；重复Pipeline保持相同位置和缩放。

短页面可相应缩短转场或采用干净切换。查看转场全过程及新文案淡入尾段，确认标题、正文和数值都完整出现、清晰可读。
