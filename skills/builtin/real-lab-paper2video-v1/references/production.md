# 讲稿与声音制作

## 论文事实表

读取指定版本 PDF，记录标题、作者/机构、论文和代码链接、版本及 SHA256。复用同版本素材，或通过[内置资产模块](paper-assets.md)提取。

每条用于视频的结论记录以下字段：

| 字段 | 内容 |
|---|---|
| claim | 本页要讲清的结论 |
| source | 对应 PDF 页序、图表、段落或公式 |
| conditions | 模型规模、数据集、训练与推理设置 |
| values | 原始数值、单位、比较对象和提升口径 |
| limitation | 结论适用范围及论文披露的限制 |

将资产页码与实际 PDF 对照，明确采用零基页索引还是一基页序。实验数字按“模型 + 数据集/指标 + 方法 + 数值”组织；提升量标注为绝对分数或相对百分比。

## 讲稿和镜头表

面向有基本技术背景的观众，选择一条最值得记住的主线。三分钟视频可从以下时间分配开始，再依据实际口播调整：

| 段落 | 参考时长 | 讲解任务 |
|---|---:|---|
| 问题引入 | 15秒 | 用具体例子建立研究问题 |
| 核心想法 | 25秒 | 一句话说明思路及其作用 |
| 方法 | 70秒 | 先看 Pipeline 全景，再解释关键环节 |
| 实验证据 | 45秒 | 呈现主要对比和最有解释力的消融 |
| 适用范围 | 15秒 | 说明条件、代价和局限 |
| 收尾 | 10秒 | 重申贡献，给出论文/代码入口 |

按论文内容增减段落和页面。每页写出：结论、旁白、屏上文案、素材、强调目标、动画节拍。用一个主标题提出结论，侧栏按需要补充短要点，字幕呈现口播。将重复标题合并，文案精简到足以配合图像讲清当前信息。

策划阶段标注目标时长；取得音轨后，用实际对齐结果生成制作时间轴。已有指定配音时先匹配其内容和时长，再安排镜头。

## 旁白

使用清晰、自然、明亮的专业口吻。中文合成的一个可用起点是 `zh-CN-XiaoxiaoNeural`、语速 `+9%`、音高 `+2Hz`；按实际声音效果和用户偏好调整。

整段合成旁白，或按服务长度限制分为自然段，检查段落连接处的语气和停顿。为缩写、数字及公式确定读法；字幕使用论文中的规范术语。保留无损人声、讲稿及词边界/对齐数据。

以真实词边界或强制对齐结果安排字幕。长句按语义拆分，换页落在句间或明确的讲解转折。默认单行约40px字幕；双行版式相应扩大字幕区并重新安排图框。

## 配乐与混音

选择轻松愉快的无歌词器乐，节奏以100–115 BPM为起点。轻拨弦或键盘、温暖低音、轻打击适合论文讲解；108 BPM可作为默认尝试。

使用原创、用户提供或已有使用许可的曲目。音乐在开头淡入、跨页连续、片尾淡出；旁白出现时压低配乐，使术语、数字和句尾保持清楚。试听后调整人声与音乐的相对电平。

混音响度以−14至−16 LUFS为起点，true peak控制在−1 dBTP以内。保留独立人声、音乐与混音，便于后续替换。

## 修订与交付

以一份时间轴驱动画面、字幕和框选。修改讲稿后重新对齐声音；修改画面时沿用既有声音和时间轴。

为视频修订使用独立文件名，并记录源版本和最终文件哈希。重渲受影响镜头及相邻转场。使用分段缓存时，将代码、字体、图像、时间轴、尺寸、fps和渲染参数纳入缓存键，核对命中分段的帧数。

交付MP4、SRT、讲稿/镜头表、封面、工程ZIP和简短检查记录。工程收录当前源素材与来源、可编辑画面、时间轴、独立音轨、渲染及验证工具。使用包内相对路径；按素材许可保留署名或合法获取方式。
