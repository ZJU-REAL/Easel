# 成片验收

## 制作阶段

先预览开场、最密方法图、主要实验页和一处转场。每页查看开头、中段、结尾，再用短动态样片检查动作与讲解节奏。

| 项目 | 通过标准 | 检查方法 |
|---|---|---|
| 构图 | 视觉焦点明确、留白充足；主标题只出现一次，辅助文案提供补充信息 | 查看整页，核对页眉、侧栏与底部的文字分工 |
| 文字 | 字形完整，字号清楚，标题/正文/字幕位于各自区域 | 看全幅画面及实际播放尺寸 |
| 原图 | 子图、标签、图例、表格行列完整，比例正确 | 与论文原图对照 |
| 留白 | 白边外缘与字幕线≥32px（1080p） | 测量外框边界 |
| 框选 | 目标、模型行、指标列与旁白一致；边线避开字形 | 每个框取代表帧，与原图核对 |
| 时序 | 一个框退出后下一个出现，字幕随口播推进 | 看短动态预览 |
| 转场 | 图像连续擦入，前页文案退出后后页文案完整进入 | 看边界连续帧及淡入尾段 |
| 声音 | 术语与数字清楚，音乐低于人声，起止自然 | 试听并查看响度/峰值 |

## 最终编码文件

对最终MP4运行 `verify_video.py`，并从同一文件抽帧复核：

1. 核对分辨率、fps、时长和音轨。
2. 确认帧数为 `round(duration*fps)`，PTS间隔为 `1/fps`，全部帧成功解码。
3. 按时间点查看黑帧、纯色帧或闪烁标记，确认其属于设计中的画面或进行修复。
4. 用精确帧号与本次参考PNG比较，覆盖各页、框选、转场及本轮修改位置。
5. 核对字幕、配音和音乐的起止；记录LUFS与true peak，检查片尾完整性。

参考PNG使用与成片一致的分辨率和帧时间。自动比较用于确认编码内容与源渲染一致；视觉检查评估构图、语义和动画；试听评估发音及混音。

## 修订闭环

将问题记录为“时间/帧 → 现象 → 修改 → 复验结果”。修改对应源工程，重新编码受影响镜头和相邻转场，随后从新MP4复验这些位置。

需要独立审片时，提供最终MP4、原图、讲稿和本轮修改范围，集中检查目标定位、图文关系及转场节奏。各项达到标准后交付。
