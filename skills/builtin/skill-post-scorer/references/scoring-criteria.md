# 评分维度详细标准

五维评分体系，每维度 1-10 分，总分 50 分。

---

## 1. 钩子强度 (Hook Strength)

前 1-2 句话是否能在信息流中阻止用户继续滑动。

| 分数 | 标准 |
|------|------|
| 9-10 | 开头制造强烈的认知冲突或情感共鸣，让人无法不继续读。使用了被验证有效的钩子类型且执行精准 |
| 7-8 | 开头有明确的吸引力，但钩子力度或精准度有提升空间 |
| 5-6 | 开头尚可，能引起一定兴趣，但不够锐利或具体 |
| 3-4 | 开头平淡，像是在自言自语，缺乏对读者的拉力 |
| 1-2 | 没有钩子，直接开始叙述，容易被划过 |

### 高分钩子类型

- **反常识声明**："大多数人以为 X，其实 Y"
- **具体数据开场**："我花了 3 年 / 分析了 500 条帖子 / 损失了 10 万"
- **提问式**：直击痛点的问题，不是泛泛而问
- **故事开头**："去年有一天，我收到一条消息..."
- **列表预告**："以下 5 个方法，第 3 个改变了我的认知"
- **权威引用**：引用行业大佬或数据报告的惊人结论

### 低分信号

- 以自我介绍开头
- 以"今天想聊聊..."开头
- 开头超过 3 行才进入正题
- 使用陈词滥调

---

## 2. 声音匹配度 (Voice Match)

帖子是否契合账号一贯的语气、人设和表达习惯。

| 分数 | 标准 |
|------|------|
| 9-10 | 语气、用词、节奏完全像这个账号写的，粉丝一眼认出 |
| 7-8 | 大体匹配，个别表达略有偏离但不违和 |
| 5-6 | 能看出在模仿目标风格，但有时滑入通用写法 |
| 3-4 | 风格混乱，忽而专业忽而随意，缺乏一致性 |
| 1-2 | 完全不像这个账号的内容，像是别人代写 |

### 评判要素

- **语气一致性**：正式/随意、专业/亲切是否统一
- **标志性表达**：是否使用账号常用的句式、口头禅、比喻
- **人设契合**：内容立场是否与账号定位一致
- **阅读节奏**：句子长短交替是否符合账号风格

### 无 Profile 时的退化评估

没有 Profile 时，此维度退化为「通用可读性」：
- 语气是否前后一致
- 有没有突兀的风格跳跃
- 是否像真人写的（非 AI 味）

---

## 3. 价值密度 (Value Density)

每段话是否提供具体、可操作的洞察，而非空泛陈述。

| 分数 | 标准 |
|------|------|
| 9-10 | 几乎每句话都有实质内容，没有废话，读完有明确收获 |
| 7-8 | 核心段落价值高，有少量过渡句但不冗余 |
| 5-6 | 有一些好观点，但被空泛表述稀释了 |
| 3-4 | 多数内容是常识重复或空洞抒情，缺乏独特见解 |
| 1-2 | 通篇空话，读完什么都没记住 |

### 高价值信号

- 具体数字和案例
- 可直接执行的步骤
- 独特的个人经验或视角
- 反直觉的洞察
- 清晰的因果逻辑

### 低价值信号

- "大家都知道..."
- "这很重要因为它很重要"
- 大量没有支撑的形容词
- 同一观点用不同方式重复 3 次

---

## 4. 结构与格式 (Structure & Format)

排版和结构是否适配目标平台的阅读习惯。

| 分数 | 标准 |
|------|------|
| 9-10 | 结构清晰，视觉节奏舒适，完美适配目标平台的阅读场景 |
| 7-8 | 结构合理，格式基本适配，有小的排版优化空间 |
| 5-6 | 结构尚可，但有密集文本墙或格式不当 |
| 3-4 | 段落过长或过于碎片化，阅读体验差 |
| 1-2 | 没有结构可言，一整块文字或排版混乱 |

### 各平台格式要点

| 平台 | 关键格式要素 |
|------|-------------|
| 知乎 | 短段落、适当空行、结论前置、结尾引导互动（点赞/评论/关注） |
| 小红书 | emoji 标题、分点列表、封面标题吸引力、300-800 字 |
| 抖音/短视频 | 前 3 秒钩子、口语化、节奏快 |
| 微博 | 140 字内精炼、话题标签、首句钩子 |
| 微信公众号 | 长文结构、小标题分段、引用金句 |

### 通用结构原则

- 开头钩子 → 核心内容 → 行动号召
- 避免超过 3 行不换行
- 列表和编号提升可扫读性
- 关键信息不埋在中间

---

## 5. 发布就绪度 (Publish Readiness)

帖子是否可以直接发布，还是需要进一步润色或补充。

| 分数 | 标准 |
|------|------|
| 9-10 | 可以直接复制粘贴发布，无需任何修改 |
| 7-8 | 基本就绪，可能需要微调 1-2 处措辞 |
| 5-6 | 需要一轮润色，有明显可改进之处 |
| 3-4 | 需要较大修改，缺少关键元素（如 CTA）或有明显问题 |
| 1-2 | 只是粗糙草稿，距离可发布状态差距大 |

### 检查清单

- [ ] 无错别字和语法错误
- [ ] 有明确的行动号召（CTA）
- [ ] 长度适合目标平台
- [ ] Hashtag 使用合理（平台适用时）
- [ ] 没有未完成的占位符
- [ ] 开头和结尾都有力
- [ ] 敏感内容风险已考虑
