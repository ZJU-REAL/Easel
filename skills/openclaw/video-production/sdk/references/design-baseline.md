# 设计基线（design-baseline）

> 2026-09-16 定 · 来源：shot-composition／motion-art-direction／review-animations／花叔设计 四技能 + 卡片系统 v2 实战
> 用途：**起步基线**——每片由此起步并按内容换风格；不是模板（一眼像参照物＝返工）。

## 排版（网格）
- 1920×1080：外边距 **104px** 起、**8px 节奏**；主元素落三分位；**全画面只有一个焦点**（A 态=人物；B 态=hero 卡）
- **负空间是主动元素**：不许铺满；"所有东西都上"＝墙式拥堵＝不合格

## A 态三形态
- 头顶概念胶囊：**~920px / radius 999 / 微倾 ±1.5°**；胶囊内含概念小动画 + 流光（动态材质）
- 左无壳浮空大字：**88px 发光**（毛笔体可选）；右无壳数据件：**≥560px**、柱状 + count-up
- 两件**错落**（左高右低），不排同一水平线；禁矩形壳

## B 态舞台
- hero 中央卡：**640×400 起**（概念演出：扩散环/核心等，含流光）
- 侧卡：**560px 真卡 ×2**，**叠层入位**（±2° 微倾、往 hero 身后收 ~90px）——不要三卡平铺
- 底部 chips ×3、角落 data floaters、背景三层（光/尘/网格脉动）、顶部进度条、噪点 ≤0.06
- 玻璃配方：rgba(255,255,255,0.10→0.032) ＋ blur(16px) saturate(140%) ＋ 边 rgba(255,255,255,0.28) ＋ accent 光斑 ＋ 卡内动态材质

## 动效分级（hero / support / texture）
- **hero**（唯一主角）：最亮最大、只它配"哇"（扩散环、核心光球）；一帧只有一个 hero
- **support**（侧卡等）：降速降幅、ease-out 让位，永不抢戏
- **texture**（光尘/网格/噪点）：慢循环、低对比；入场**错峰**（hero → 侧 → chips → floaters），**禁一切同时入场**；只动 transform/opacity

## 空间融合（语义强制 · 详见 fx-usage）
- 台词/语义出现 3D·立体·弹出 → **FX-15 真透视 3D 卡**（透视容器 + 厚度背板 + 投影；禁平面加 skew 冒充）
- 出现 背后·穿过 → **FX-16 人物蒙版分层**（同源片 + 逐帧蒙版；禁元素压人、禁把人当贴图）
- 设计表必须显式裁决（用/不用 + 场次 + 理由）；交付前抽帧自查（3D 场看侧厚、背后场看裁切），不过=返工

## 硬红线
- **A 态真人不压暗**；任何压暗 ≤0.3（素材渐变底 ≤0.46）
- 卡片：≥560px（胶囊 920 / 中央 640+）；禁小卡、禁暗底压暗堆料
- 字幕一字不改（transcript 原文）；素材必须对应台词 + 入场前抽帧核验
- 空间融合语义场次：设计表吹了/写了就必做，**不许降级**（做不到就改设计表措辞）
- 参照物规约：只作验收标尺（并排对比只看"是否看得出是另一支片"）；不作出门脚手架
- 色彩：accent 家族（冰蓝/青/紫/粉/绿/暗橙红），禁铜金默认；每片色系由内容定
