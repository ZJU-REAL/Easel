# rm 线动效质量机制（草案 v1.4）

> 2026-09-16 · 质量机制备忘（已并入本 SDK 的机制层）

## 一、诊断：「拉跨」由三件事合成

1. **下限在飘**——有的场次画面偏「素」：包装薄、留白大，接近「真人＋背景＋字幕」就交卷；对比早期（6 月那批）满编排的密度，落差明显。
2. **上限是假的**——B 态堆得很满，但通用 HUD、模板动效、素材拼贴痕迹重：热闹，不精致（有「廉价科技风」风险）。
3. **两头摆动**——同一支片在「太空」和「太杂」之间晃，没有稳定气质。

**验收方点名（9.16，五条）**：

1. **抽象表意动效消失（最伤）**——以前能用各种动效配合口播「把意思演出来」，现在没有了：画面退化成「真人口播＋装饰卡」。格式的核心价值是「口播＋概念动画」——「概念动画」那半边丢了。
2. **卡片太小**——旧规范：宽 ≥560px（头顶胶囊 ~920 / B 中央卡 ≥640）；「禁止小卡片」8 月立过。
3. **转场不足**——旧规范：每次 A↔B 必转、6 种轮换、叠加 0.5-0.8 可感知。
4. **动画不能固定（原则重申）**——不同场景 / 不同视频要做不同风格的动画。这正是 #15「每部片独立定风格」＋ #6「全片禁重复」的原意：**机制（怎么动）可复用，风格（长什么样）不复用**——每场按内容、每片按主题，现做。
5. **素材必须对应台词（整套管线硬规）**——视频素材一定要能对应上验收方说的话：每个素材镜头必须语义对应它所在场的那句台词（观众看到镜头就懂这句在说什么）；素材清单逐条标注「对应台词」，交片前逐场核对；对不上就换素材，不硬凑不瞎编。

五条共性：**立过规矩又回归 = 执行位丢失**。本草案的核心就是给规矩加执行位。

机制层根因：①引擎复用被做成「换色换字」；②效果只加不减；③像素验证（底线）被当成了质量线；④弹药库很久没进新货；⑤**表达层退化**——最难、最费设计的部分（逐场设计表意演出）在最小阻力路径里第一个被丢，捡起来的都是便宜货（通用卡 / HUD / 转场模板）。

## 二、机制（十条，全部可检查）

**原则（验收方 9.16 重申）**：机制可复用、风格不复用；动画不固定——以下机制是「执行位」（管下限：不空 / 不省 / 不重 / 不降），**不是模板**；风格永远由内容现长。

1. **语义动效（概念演出制）**：每场至少 1 个「表达型」动效——用抽象 / 隐喻动画把本场核心概念演出来（不是装饰层；A 态可叠层演出，B 态在舞台上演）。流程：出稿后先列「每场概念清单」→ 设计表逐概念指定演出方案（抽象动画 / 具象梗 / 数据可视）→ 交付前逐场核对；概念没被「演」= 不通过。
2. **A 态不许空 ＋ 卡片尺寸**：渲前帧检新增——A 态代表帧里「头顶胶囊 / 左浮空大字 / 右数据件」至少 2/3 在画面；同时**测卡片宽度 ≥560px（1080p 基准）**。不达标 = 返工。
3. **查重表（两级）＋ 差异度定义**：①片内——每场每卡的画面 / 动画 / 卡位 形式×变体 / 转场公式唯一（原 #6 升级为对照表执行）；②片间——本片设计表对照上一部机制清单，逐项不同或显式豁免（写明理由），交片出对照表。**差异度定义：换色换字不算差异——必须差到构图 / 材质 / 运动语言级；达不到 = 返工。** **参照物使用规约（验收方 9.16 顾虑："给参考物品他直接照搬不设计风格"）**：样板/参照物只作**验收标尺**（气质门并排对比、尺寸与元素齐备核对），**不作起步模板**——执行者开工拿结构骨架（网格/状态机/时间轴/门）＋规范，不拿成品视觉工程当脚手架；交付必附「本片 × 参照物」对照表，逐条写明保留什么机制、换掉什么风格外壳；**反向判定：一眼像参照物（换色换字级）= 不合格返工**——验收问的不是"像不像"，而是"能不能看出这是另一支片的设计"；配合第 4 条（每片 ≥2 个首次使用机制 + 来源登记），让"设计风格"成为过门的必要条件。
4. **新机制配额**：每片至少 2 个「首次使用」的机制——新抄的引擎或实质改造（继续禁手搓几何；要求能口头说清「哪里不一样」）。来源：video-shotcraft / 81 库 / 设计站 / GitHub；入库留档。
5. **减法纪律**：每加一层必须同步砍一层；B 态叠加层数设上限（建议：素材罩 / 暗角 / 光扫 / 粒子合计 ≤4，逐片微调）；收到「太重、奇怪」类反馈 = 强制进减层流程。
6. **气质抽检门（人眼）**：渲全片前出「本片 vs 上一部」每场代表帧对比图（并排）——验收方先看气质；像素验证保留为底线，不替代这一关。
7. **弹药库常新**：每 1-2 部片往 remotion-libs 进一批新参考（设计站 / GitHub），来源记录留档；「库里有就直接套」继续禁止。
8. **工程归档**：每片完成后，工程目录固定归档（不随临时清理消失）。本轮排查中《大模型魔幻发展史》的 remotion 工程在盘上已找不到——只剩成片＋素材，想回改都没得改。
9. **转场检查**：全 A↔B 切点必须有转场、六种轮换（跨片同查重）；抽相邻帧差分验证转场「可感知」（全屏变化覆盖率阈值实测后定）；B→B 连续舞台内只切内容不转场（按规范）。
10. **素材对应台词**：素材清单逐条标注「对应台词」→ 交片前逐场核对（这句 ↔ 这个镜头）；语义对不上 = 换素材 / 问验收方要（不硬凑）；素材大屏场（B 态）优先按此执行。**素材入场前必须抽帧核验（验收方 9.16 立）**：候选素材先抽 2-3 帧 / contact sheet 亲眼核对——画面真的符合该句的语义情景（不是名字对上）；不合就换。

## 二·补、特效-背景融合（2026-09-16 实操成文）

特效禁「贴纸式」平叠——发光元素必须与背景发生光学关系。五刀（含在真片工程实测）：

1. **发光层混模式**：粒子 / 光晕 / 光环 / 光扫用 `mixBlendMode: 'screen'`（或 `plus-lighter`）叠进画面——光是「亮进去」的，不是浮一层半透明板。
2. **光影响环境**：元素辉光（大字光晕、光环 glow）以独立 screen 层打进背景；卡片透背景（`backdrop-filter: blur`）。
3. **全帧统一颗粒**：整片叠一层胶片颗粒（灰噪图 + `overlay` 混合 + 每帧位移抖动，opacity ~0.07），把实拍与合成绑进同一质感空间。
4. **遮挡与接触**（进阶，需人物蒙版）：前景人遮挡身后特效、浮空元素接地影——需 RVM / 媒体蒙版支持；无蒙版时宁可不做，别硬盖。
5. **同节奏微运动**：叠加组带呼吸级微移（±3px / 0.2% 缩放级），消静态贴片感。

坑（重要）：`transform`（含动画变换）会创建 stacking context——其内部元素的 `mix-blend-mode` 只与该组内内容混合、不再吃到底层视频；**混合层必须挂在无 transform 的父级下**（微运动包裹层里只放非混合元素）。

**已实做（2026-09-16）：** 人物蒙版分层（同源视频+逐帧 alpha 蒙版 PNG，文字/粒子从人身后穿过、人形窗口同基座）；真透视卡（`perspective` 容器 + 厚度背板 + 投影 + 扫光 + 视差浮动）。**本线方向定论：不换背景**——"替换现实"类合成感消不掉，全押"增强现实"类（光交互/信息空间化/运镜）。

**入仓（2026-09-16）：** FX-15 真透视 3D 卡 / FX-16 人物蒙版分层 → `assets/fx/`（生产验证件）；空间融合资产链 → `tools/rvm_matte.py`（抠像）+ `tools/make_masks.py`（交付蒙版）。**成组入场节奏**：一组元素（背后符号群式）逐项 stagger ≤4 帧/项，整组须在台词窗口前 1/3 内就位——过慢会出现"台词说到一半、东西还没冒出来"（实测翻车后定为规范）。

## 二·补二、执行层防退化（2026-09-17 真机实录新增）

- **门⑧ 分场时间轴 lint**（`gates/check_timeline.py`）：重叠 / 长间隙 / 过短场——舞台打架与闪切的机械防线（人眼发现、门来固化）。
- **人审包**（`tools/make_review_pack.py`，deliver 自动生成）：每场定格帧 + 核对表；执行者无视觉（多数 LLM 不看图）时，"看着不对"的瑕疵只能靠人眼——把关卡设在交付点。
- **语义强制规则**（`references/fx-usage.md`）：立体 / 穿越语义 → 必须 FX-15 / FX-16，禁止平面降级；设计表承诺与实现必须一致（抽帧自查）。

## 三、与「优化 → Easel」的关系

装进 Easel 的必须是「带防退化的产线」：这些机制随 rm 线一起进——对应到 Easel 的 produce 层技能（质量门 + 每片机制对照表协议 + 帧检脚本 + 素材↔台词对照）。**封装形态（验收方 9.16 定）**：流程化 SDK + 独立接口——自包含包（管线流 = 九步 SOP；接口 = 原片 + 文字稿 + 主题进、成片 + 对位表 + 核验报告出；质量门内置），不散件混入他们的管线，避免互相混掉。

## 四、本轮诊断依据

- 画面三代对比（6 月 Anthropic 片 / 8 月 night / 9 月《大模型魔幻发展史》）＋《大模型》代表帧逐帧看：偏素场次、模板感、「摆动」。
- 验收方 9.16 点名：抽象表意动效消失、卡片太小、转场不足、动画不能固定、**素材必须对应台词（已进规范 #17⑥）**。
- 历次纠正：2026.8.7「为什么这风格和上次一样」「清单固定=一直土」、2026.9.7「你不用调这么重的效果，现在看起来很奇怪」、8.8「A 态同样铁律」等。
- 既有禁令（半截动效 / 禁重复 / 禁「库里有就直接套」）＝旧的磨损记录，本机制是给它们加执行位。
