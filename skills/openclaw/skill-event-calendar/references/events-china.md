## 使用说明

1. **农历节日**：农历日期每年对应的公历日期不同，使用时需查询当年农历转换表
2. **电商大促**：具体日期以各平台当年官方公告为准，表中为往年惯例时间
3. **蹭点价值**：基于全民关注度评定，具体赛道的价值需结合创作者定位调整
4. **提前准备**：
   - 5星节点：提前 7-14 天开始策划
   - 4星节点：提前 3-7 天开始准备
   - 3星及以下：提前 1-3 天即可
5. **更新频率**：建议每年初更新农历对应日期和新增的电商节点
