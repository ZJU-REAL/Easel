## scripts/lunar.py — 农历↔公历换算算法来源（诚实标注）

`scripts/lunar.py` 为纯 Python 标准库实现，覆盖公历 1900-2100。核心是业界广泛流传的
**lunarInfo 十六进制年表算法**：每个农历年用一个约 20bit 的整数编码「闰月位置 / 闰月大小 /
12 个月的大小月」，配合基准锚点（农历 1900 年正月初一 = 公历 1900-01-31）做天数偏移计算。

| 要素 | 说明 |
|------|------|
| 数据表 | `_LUNAR_INFO`（1900-2100，201 个十六进制数）—— 该表在众多开源农历库中完全一致，属通用历法常量 |
| 算法 | 年天数累加 + 月序（含闰月）偏移，`l2s`/`s2l` 互为逆运算 |
| 基准 | 农历 1900-01-01 == 公历 1900-01-31 |
| 依赖 | 仅标准库 `datetime` / `argparse` / `json`，无任何第三方包 |

## 使用约定

SKILL.md 规定：涉及农历节日的公历日期一律调用 `scripts/lunar.py` 换算，不靠 LLM 估算。
