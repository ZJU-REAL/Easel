# 通用基准数据与评分卡模板

当无法获取账号历史表现数据时，使用以下通用基准。

---

## 长文平台头部创作者基准

来源：知乎 / 微信公众号 等国内长文平台头部创作者公开表现区间综合估算
（无账号历史数据时的兜底参考，实际因赛道差异较大）。

| 指标 | 数值 |
|------|------|
| 平均互动分 | 1,800 |
| 平均点赞数 | 800 |
| 平均评论数 | 330 |
| 平均转发/分享数 | 约 50-80 |
| Top 10% 互动分门槛 | > 4,500 |
| Top 10% 点赞数门槛 | > 2,000 |
| Top 10% 评论数门槛 | > 800 |

### 互动分计算公式

```
互动分 = 点赞数 + (评论数 x 3)
```

评论权重 x3 的理由：评论代表深度互动，平台算法给予更高权重。
计算由 `scripts/score.py` 确定性完成，本表仅提供无历史数据时的门槛兜底。

### Top 10% 帖子共性特征

| 特征 | Top 10% 模式 |
|------|-------------|
| 开头类型 | 反常识声明或具体数据开场 |
| 文本长度 | 150-300 词（中等长度，非长文） |
| 段落结构 | 1-2 句一段，大量空行 |
| CTA 类型 | 提问式结尾（邀请评论） |
| 主题类型 | 个人经验教训 > 行业分析 > 操作指南 |
| 句式节奏 | 长短交替，短句结尾制造节奏感 |
| Emoji 使用 | 克制，0-3 个，用于结构分隔 |

钩子强度        ████████░░  8/10
声音匹配度      ███████░░░  7/10

发布就绪度      ██████░░░░  6/10

2. 声音匹配度 (7/10)
   [对该维度的具体分析和依据]

   [对该维度的具体分析和依据]

   [对该维度的具体分析和依据]

### 进度条生成规则

每分对应一个方块字符：
- 得分部分用 `█`
- 剩余部分用 `░`
- 总共 10 格

示例：7/10 → `███████░░░`

### 判定结论措辞

| 总分区间 | 判定措辞 |
|----------|----------|
| 40-50 | 优秀，直接发布 |
| 35-39 | 值得发布，小幅优化即可 |
| 30-34 | 值得发布，建议优化 [最弱维度名] |
| 25-29 | 需要修改，重点改进 [最弱维度名] 和 [次弱维度名] |
| 20-24 | 需要较大修改，建议重写 [最弱维度名] 部分 |
| < 20 | 建议整体重写 |
