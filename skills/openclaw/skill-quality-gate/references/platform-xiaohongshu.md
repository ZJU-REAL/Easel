# 小红书平台合规规则

小红书特有的合规检测维度，在通用规则之上叠加。

## 导流外站

小红书严格限制将用户引导至站外：
- 出现其他电商平台名称或链接
- 展示或提及二维码、外部群号、个人联系方式
- 使用谐音或变体绕过检测（如用 emoji、拼音缩写暗示外站入口）
- 评论区引导私信获取外部链接

**判定原则**：任何引导用户离开小红书生态的行为均为高风险。

## 软广未标注

商业推广内容需明确标注：
- 收费合作内容未使用平台"合作"标签或未声明利益关系
- 以个人分享口吻发布但实为品牌推广
- 赠品、试用装体验未说明获取方式
- 含有返利、佣金等利益关联但未披露

**判定原则**：存在任何形式的商业利益交换时，必须显著标注。

## 敏感词与限流风险

小红书存在内容限流机制，以下模式易触发：
- 涉及竞品对比的攻击性措辞
- 平台已知限流词汇（需结合时效性判断）
- 过度营销感的表述（"买它"、"冲"、"闭眼入"等刷屏式话术）
- 涉及价格对比、折扣信息的过度堆砌

**判定原则**：即使内容本身不违规，但可能触发平台算法降权的表述也应标记为中风险并给出替代建议。
