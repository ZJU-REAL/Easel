# 三级审核结论

## ✅ 通过 — 直接交付

产物基本满足要求，可能有小瑕疵但不影响使用。

直接把产物交付给用户。

```
审核结论：✅ 通过
产物：outputs/xxx.md
摘要：<一句话概括产物内容>
亮点：<如有>
小建议：<如有，非阻塞性建议>
```

## ⚠️ 有瑕疵但可接受 — 交付并附建议

产物整体可用，有一些可以改进的地方。

交付给用户，附上改进建议，让用户决定是否需要修改。

```
审核结论：⚠️ 有瑕疵但可接受
产物：outputs/xxx.md
问题：<列出瑕疵>
建议：<改进方向>
```

## ❌ 不达标 — 需要返工

产物有明显的质量问题，直接交付会让用户失望。仅在以下情况判定不达标：

- 完全跑题（产出内容与用户需求不符）
- 严重残缺（缺少关键部分）
- 格式混乱（无法阅读或使用）
- 与用户要求有重大偏差

```
审核结论：❌ 不达标
产物：outputs/xxx.md
严重问题：<具体问题>
返工要求：<重新产出时要修掉的具体问题>
```
