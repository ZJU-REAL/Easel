# 差异化定位框架库

> 供 skill-positioning-analysis 按需读取。定义方法与模型，不绑定具体品牌案例。

## 一、赛道扫描

先看清"大家都在做什么"，才知道差在哪：
- **主流打法共性**：这个细分赛道头部/腰部普遍的选题、形式、人设、调性。
- **同质化点**：哪些做法已经烂大街（用户审美疲劳的地方 = 差异化机会）。
- **用户未被满足处**：评论区抱怨、"有没有人做…"、反复出现的疑问（结合 skill-comment-insights）。
输出：赛道共性清单 + 同质化点 + 潜在缺口。

## 二、定位坐标法（二维图）

选**两个能区分竞品**的关键维度画坐标，把竞品摆上去：
- 常用维度对：专业↔娱乐、高端↔平价、硬核↔小白、理性↔情感、垂直↔泛化、
  颜值↔实用、快节奏↔慢生活、大众↔小众。
- 看图找 **聚集区（红海，别扎堆）** 与 **空白区（机会，但需验证有需求）**。
- 维度要有区分度：如果所有竞品在某维度上都一样，这个维度无用，换一个。

## 三、蓝海机会识别

空白区不等于机会，要区分真空白与伪空白：
| 类型 | 判断 |
|------|------|
| 人群空白 | 某类人群没被专门服务（如"给 XX 人群的 YY"）——有需求即机会 |
| 场景空白 | 某使用场景没人切（如"通勤时/带娃时的 YY"）——高频场景更佳 |
| 价值空白 | 同品类但主打不同价值（别人讲效果你讲体验/情绪）——差异价值 |
| 形式空白 | 内容形式创新（别人图文你做实测视频/连载）——形式易被模仿，需叠加其他维度 |
| **伪空白** | 没人做是因为**没需求/做不动/平台不推**——排除 |
验证：这个空白处有没有搜索量/评论诉求/竞品尝试痕迹？完全没有信号要警惕。

## 四、差异化五维

逐维找差异点，选 1-2 个**最可持续、最难被模仿**的做主差异：
1. **人群**：更细分的目标人群（越具体越易占位，但别小到没市场）。
2. **场景**：绑定具体使用场景/时刻。
3. **价值**：主打的核心价值（功能/情绪/身份/效率…）与别人不同。
4. **形式**：内容形式/结构的独特性。
5. **人设**：创作者人格、风格、表达方式（最难被模仿，护城河最深）。
护城河排序：人设/独特经历 > 人群+场景组合 > 价值主张 > 内容形式（形式最易抄）。

## 五、一句话定位公式

`为 [具体人群] 在 [具体场景] 提供 [独特价值] 的 [品类/角色]`

要求：
- **具体**：人群、场景、价值都要具体到能想象出画面。
- **可记**：一句话说清，用户能复述。
- **可验证**：能被内容证明，不是自封。
反面（拒绝）：包含"更好/更专业/更用心/高品质"等无差异空话，或大而全"什么都做"。

## 六、落地与验证

- **落地**：定位要体现在 选题（选什么不选什么）、风格（怎么表达）、视觉（统一识别）、
  人设（一致人格）上，且**持续可感知**——用户看三条内容就能感到"这号不一样"。
- **验证信号**：目标人群是否被吸引（粉丝画像匹配）、是否有人主动用你的定位标签描述你、
  同质竞品是否难以复制你的核心差异。
- **迭代**：定位不是一次定死，据数据（audience-profiler / data-tracker）与市场变化微调。

## 七、常见坑

- 只追求"不同"忽略"有需求"→ 小众自嗨。
- 定位太宽（什么都做）→ 没有心智占位。
- 差异点在形式层（易被抄）→ 没护城河。
- 脱离自身优势硬凹定位 → 做不长久、不真实。
- 空话定位（更专业/更用心）→ 用户无感、无法验证。
