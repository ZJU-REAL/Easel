# 平台适配（论文解读）

> 同一份 asset-library，不同平台的形态、深度、语气不同。按目标平台调整。

## 微信视频号（主场景）

- **形态**：2–4 分钟中视频口播讲解，配图/信息图。
- **受众**：泛知识人群 + 部分同行。深度取"大众能懂 + 同行不觉得水"。
- **风格**：正经但不高冷；开头钩子要强（视频号完播率敏感）。
- **画幅**：16:9 或 9:16 均可；封面用钩子大字。
- **发布**：skill-channels-upload。可配一段图文简介。

## B站

- **形态**：可做更长（5–15 分钟）深度解读，容得下更多方法细节和推导直觉。
- **受众**：学生/研究者/技术爱好者，吃干货、能接受一定门槛。
- **风格**：可保留关键公式+直觉解释；三连引导；可做系列（某方向连续讲）。
- **画幅**：16:9。章节目录用 video-chapters 生成时间戳。
- **发布**：biliup（知识区 tid）。

## 知乎（图文/回答）

- **形态**：结构化长文或回答，逻辑链清晰，配图。
- **受众**：专业度较高，重逻辑与信息量、忌注水和标题党。
- **风格**：problem→method→results→takeaway 逻辑推进；关键结论配图佐证；术语给解释但可略专业。
- **排版**：doc-convert 转排版；发布 skill-zhihu-publisher。

## 微信公众号（文章）

- **形态**：成篇文章，有起承转合和阅读节奏。
- **风格**：比知乎更"讲故事"，用类比和案例降低门槛；配图精。
- **排版/长图**：doc-convert（MD→HTML/长图）；发布 skill-wechat-publisher。

## 小红书（可选轻量版）

- **形态**：把 asset-library 的 one_liner + contributions + 一张关键图，做成 3–6 张竖版卡片"论文速览"。
- **风格**：更轻、更"划重点"，适合"1 分钟看懂一篇顶会论文"这类选题。
- 交 card-xiaohongshu / xhs-note-creator。

## 通用建议

- **深度分层**：同一篇论文可产「大众科普版（视频号/小红书）」+「同行深度版（B站/知乎）」，asset-library 复用，只调讲解深度与术语密度。
- **系列化**：按方向/顶会/作者做成系列，利于起号沉淀垂直标签。
- **忠于原文 + 合规**：结论不夸大、区分解读与原文、遵守 Profile `preferences.md` 红线。
