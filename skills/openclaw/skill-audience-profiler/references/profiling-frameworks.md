# 受众画像框架详解

> `skill-audience-profiler` 的领域知识库。SKILL.md 保留步骤骨架，具体框架模板在此按需加载。

---

## 一、受众画像框架

```
人口统计
  年龄段 / 性别 / 城市层级（一线~下沉）/ 人生阶段（学生/职场新人/宝妈/已婚已育/退休）/ 收入水平

心理特征
  价值观（深层在意什么）/ 自我认同 / 向往 / 焦虑 / 影响源（KOL/朋友/家人/专家）

行为特征
  活跃平台 / 内容消费（图文/短视频/中长视频/直播/播客）/ 活跃时段
  消费习惯（冲动型/研究型/比价型/品牌忠诚）/ 互动方式（点赞/收藏/评论/转发/私信）
```

---

## 二、痛点与需求

### 痛点结构
```
痛点: [具体问题]
  严重度: [1-10] | 频率: [每天/每周/每月]
  当前解决方式 / 不解决的代价 / 情绪影响（焦虑/迷茫/自卑/烦躁）
  代表性声音: "[评论区/私信中的原话]"
```

**痛点分类**：技能型（不会做）、认知型（不知道）、资源型（找不到）、情感型（焦虑/不自信）、社交型（怕丢面子/跟不上潮流）。

### 需求
```
核心需求: [#1 期望] | 衡量指标: [怎么算满足] | 时间预期: [多久]
次要需求: [2-3 个补充需求]
终极期望: [一切顺利想达到什么]
JTBD: "当我 [场景]，我想要 [行动]，这样我就能 [结果]。"
```

## 三、内容偏好

```
内容类型偏好
  最爱看 / 容易收藏 / 容易评论 / 容易转发（分别是哪类内容）

格式偏好
  小红书: [图文卡片 > 图文笔记 > 视频笔记]
  抖音: [15秒 > 60秒 > 3分钟]
  B站: [5-10分钟 > 3分钟以下 > 10分钟以上]
  微博: [图文 > 短视频 > 长文]

触达方式
  发现路径（搜索/推荐/关注页/话题/热搜）/ 关键搜索词 / 竞品账号
```

- [点菜的评论："能不能出一期XX"/"想看XX教程"]

## 七、验证清单

- [ ] 基于真实数据（后台/评论区/私信），不只是假设
- [ ] 基于足量真实样本（后台数据/评论/私信），样本越多越可信
- [ ] 画像能解释为什么某些内容爆了、某些扑了
- [ ] 通过已知渠道能触达这些人
- [ ] 足够具体能指导选题，又不至于太窄
- [ ] 能直接用于内容策划、文案撰写和推广投放

**何时更新**：每涨粉 1 万、每次变现模式调整、每次转赛道、每季度至少一次。
