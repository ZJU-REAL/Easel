# 蓝海选题评分模型（社媒语境）

每个候选选题按加权评分排序。评分依据全部来自**社媒真实信号**（搜索联想 / 热搜 / 评论区），不用搜索引擎月搜索量、KD、用户旅程等 SEO 指标。

## 加权评分

| 因素 | 权重 | 评分 1-10 依据 |
|------|------|---------------|
| 需求度 | 30% | 搜索联想词出现频次、评论区追问的点赞数、热搜相关度——信号越强越普遍分越高 |
| 竞争度 | 25% | 现有内容供给（反向：竞争弱=高分）。搜索结果少、质量参差、无头部覆盖、内容陈旧 = 高分 |
| 账号匹配度 | 20% | 与用户定位、专业优势、受众的契合度。直接契合10分，需要跨界或超出能力的低分 |
| 制作成本 | 15% | 能否用现有素材/能力快速产出（反向：易=高分）。可复用已有内容 = 高分 |
| 时效价值 | 10% | 是否有热点借势窗口或季节性机会。正处上升窗口 = 高分 |

**优先级评分 = 加权平均**

## 优先级分级

- **🔵 高优先**：评分 ≥ 7，需求强 + 竞争弱，本周可动手
- **🟢 中优先**：评分 5–7，需求明确 + 竞争适中，值得投入
- **⚪ 观察池**：评分 < 5 或需求信号不足，待验证后再做

## 评估提示

- **需求度与竞争度要交叉验证**：搜索结果少 ≠ 蓝海，可能是伪蓝海（没人做也没人要）。必须有评论区/联想词的需求信号背书。
- **竞争弱 ≠ 没人做**：有人做但做得差（评论区吐槽多）比完全空白更好——需求已被验证，只差更好的表达。
- **逐平台评分**：同一选题在小红书是红海、在 B站可能是蓝海，竞争度按平台分别打分。
- **账号匹配度是硬门槛**：需求再强，超出账号能力范围也拉低总分，避免推荐做不了的选题。
- **多个选题指向同一母题**时，考虑做成系列/合集一次覆盖，提升制作成本项得分。
