# Web Material Sourcing

## 目标

从网上找到可用、可追溯、适合当前主题和版式的素材，并把它们放进对应内容项目的 `assets/` 目录。搜索结果不等于可以直接使用；每个下载文件都要留来源、原始 URL、作者（如有）、许可证或使用限制、抓取日期和使用备注。

## 工作流程

1. 先确认主题、用途（PPT/卡片/视频）、画幅、数量、时效性和是否需要可商用。不明确时按公开发布、仅供参考分类，不把它当作可商用。
2. 用 WebSearch 搜索，用 WebFetch 读取原页，优先原创者、政府/机构、Wikimedia Commons、NASA、公开数据和明确声明许可的库。不从搜索引擎缩略图直接取图，不绕过登录、验证码、反爬和付费墙。
3. 对候选素材记录标题、URL、来源站点、作者、许可证和筛选理由，优先下载原图或原文件；无法确认许可时只保留 URL 与摘要，不下载。
4. 在项目创建 `outputs/<具体主题>/assets/` 后，用 `scripts/download_material.py` 下载已确认的直接 URL；脚本会限制大小、检查 HTTP 状态、记录 SHA-256，并写 `materials.json` 清单。
5. 把网页文本、图表、图片和下载文件分开记录；不把网页缩略图当成原图，不把受限素材归类为可商用素材。
6. 交付时告知使用限制、归属和未确认项；给 PPT 或卡片制作 Skill 时只传递已下载并经追溯的文件。

## 两种输出

- **参考搜索**：只保留 `reference/` 中的网址、摘要和许可证信息，适合论文解读和主题调研。
- **可用素材包**：将已验证的文件放在项目 `assets/` 中，并写 `materials.json`；适合后续 PPT、卡片、海报和视频制作。

## 边界

- 不代替版权法律判断；许可不明或仅“网络传播”的资料只做参考，不默认可公开发布。
- 下载前先检查 URL与清单中的源站点一致；不下载可疑重定向、需登录或绕过保护的资源。
- 下载后使用相对路径引用，不在文案、PPT 或卡片里暴露内部绝对路径。

## 相关参考
