# 各平台推荐图片尺寸与比例

> 图像处理适配参考。像素为常用推荐值，比例是硬约束；不确定时优先按比例（`pad`/`crop`）处理。

## 小红书（RED）
- 竖版图文卡片：**1080×1440**（3:4）— 首选，信息密度高
- 竖版海报/视频封面：**1080×1920**（9:16）
- 方图：1080×1080（1:1）
- 单帖最多 18 图，常用 ≤9 张

## 微信
- 朋友圈单图：**1:1**（1080×1080）推荐，避免被裁
- 朋友圈多图：正方形宫格，统一 1:1 拼接最整齐
- 公众号头图：**900×383**（约 2.35:1）
- 公众号正文配图：宽 ≥ 900px，比例不限

## 抖音 / 视频号 / 快手
- 竖版封面/画面：**1080×1920**（9:16）
- 部分横版：1920×1080（16:9）

## 微博
- 配图：**1:1**（1080×1080）或 4:3
- 长图文：宽 ≥ 1080px

## 知乎 / 公众号横图
- 文章封面：**16:9**（1920×1080）
- 卡片金句：16:9

## X / Twitter
- 单图：**16:9**（1600×900）
- 多图：并排显示，1:1 或 16:9

## 通用比例速查
| 比例 | 典型像素 | 场景 |
|------|----------|------|
| 1:1  | 1080×1080 | 朋友圈/微博/头像 |
| 3:4  | 1080×1440 | 小红书图文 |
| 9:16 | 1080×1920 | 竖版海报/短视频封面 |
| 16:9 | 1920×1080 | 横版封面/金句卡 |
| 4:3  | 1440×1080 | 传统横图 |

## 处理策略
- **保全画面**（不裁不变形）→ `pad --ratio X:Y`：补边到目标比例
- **满版无边**（可裁掉边缘）→ `crop --width W --height H`：居中裁到目标尺寸
- **仅缩小体积/像素** → `resize` + `compress --max-kb`
- 头像/圆形素材 → `round --radius-percent 50`
