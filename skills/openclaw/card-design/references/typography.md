# 字体层级与中文排版

## 铁律：字越大越细

反直觉但决定成败：**字号越大，字重越轻；只有小字才用重字重。**
大标题上 700-900 粗黑体 = 瞬间掉到"廉价落地页 / 信息图 banner"。高级排版的大标题是 w200-500。

## 字体族

- **杂志系**：标题+正文都用**衬线**（Noto Serif SC / Source Han Serif；英文 Playfair Display / Fraunces）。副标/金句可斜体。
- **瑞士系**：**无衬线**（Noto Sans SC / Inter / Helvetica）。
- **kicker / meta / label / 序号**：等宽 mono（IBM Plex Mono / JetBrains Mono），大写 + 字距 `+0.18~0.22em`——这一条最出"设计感"。
- 本机中文字体：`/usr/share/fonts/truetype/wqy/wqy-microhei.ttc`（无衬线）。要衬线感可用系统 Noto Serif CJK（若无，退无衬线也行，但走瑞士立场）。

## 字号层级（1080×1440 竖版）

**杂志系**（衬线）：
- Display 大标题 `110-124px` / w500 / 字距 +0.02em
- 章标题 `80-88px` / w500；中标题 `52-56px` / w500
- 金句 `60-64px` / w500 斜体
- 导语 `28px` / 正文 `24-26px`（都用衬线）
- kicker/meta/label `20px` mono 大写

**瑞士系**（无衬线）：
- Hero 巨标题 `180-240px` / **w200**
- 章标题 `100-120px` / w300；巨型数字 `180-200px` / w200
- 导语 `30px` / 正文 `26px` / w400
- 分类标签 `22px` / w600；meta `20px` mono

## 最小字号死线（手机可读）

- 正文 **≥28px**、导语 ≥30px、caption/label/水印 **≥20px**，绝对死线 18px。
- **放不下就删字，绝不缩字号**。缩到 <18px 的小字在手机上根本看不清 = 白做。

## 中文标题分档（越多字越小，但优先删字）

| 标题字数 | 字号 |
|---|---|
| ≤6 字 | 120-132px |
| 7-10 字 | 96-108px |
| 两行各 ≤8 字 | 88-96px |
| 有行 9-12 字 | 80-84px |

- 3:4 画幅硬顶 **2 行 × 每行 ≤8 字**。要 3 行 → 改用"封面型"骨架让标题当主角，别把标题缩到 80px 以下（小又粗 = Web1.0 廉价）。
- **中英混排**：中文 Noto Sans/Serif SC，英文 Inter/Playfair；在语义处手动 `<br>` 断行，别让 CJK 自动断出难看的孤字行。
- 行距：标题 1.15-1.25，正文 1.6-1.75（中文正文行距要宽）。字间距：中文标题可 +0.02em，正文 0。

## 层级对比

高级 = **强层级**：Display 与正文字号比 ≥4:1；用**字号 + 字重 + 颜色（ink vs muted）** 三者拉开层级，而不是靠加粗一切。次要信息用 muted 色 + 小字 + mono，主信息用大字。
