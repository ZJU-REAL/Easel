# 布局法则：填满画幅（治死空白）

> 社媒卡是一张张**单独滑看**的，不像杂志靠对开页吸收留白——**欠填的卡直接被读作"PPT 缺了个元素"**。
> 这是小红书卡片最常见、最刺眼的廉价感来源。本文件是硬门禁。

## 硬规则

- **内容必须覆盖 ≥75% 画高**（≥1080px / 1440px）。
- **任何无理由的纯空白带 >15% 画高（>216px）即判失败。**
- 渲染后必须跑 `card_audit.py`（见 SKILL.md 第 5 步）验证，全 PASS 才交付。

## 4 带密度自检（渲染后，也是 card_audit 的判据）

把成图纵切 4 条各 360px 的带（0-25% / 25-50% / 50-75% / 75-100%），逐带看是否有内容：
- **通过**：① 底部带（75-100%）有实质内容（不能近空）；② 相邻两带不同时为空；③ 整体填充 ≥75%。
- **典型失败**（SwanTale 卡就是）：内容堆在上 2 带，第 3-4 带近空 → 头重脚轻 + 底部死空白。

## ⭐ 内容少时怎么办（直接解决"底部死黑"）

**绝不做**：
- ❌ `<div style="flex:1"></div>` 把内容顶到垂直居中（下面留死空白）——这是最常见的错误做法。
- ❌ 加装饰性 blob / 圆圈 / 水滴 / 贴纸 / 无关插画来"填空"（那是另一种廉价）。
- ❌ 无脑放大标题到占满（标题该多大有 typography 规矩）。

**要做**（欠填修正阶梯，从上到下依次尝试）：
1. **扩内容**：把要点写透——加一行"为什么"、加一个例子/类比、加数据、加一条边栏注解(marginalia)、把 3 条要点补到 4-5 条。知识卡永远有更多可讲的。
2. **加结构化承载**：账本行(带副行的列表)、时间线、管线步骤、对比表、矩阵格——这些天然吃高度且有信息量。
3. **换更省高度或更高容量的骨架**（见 card-recipes 的最小密度线）。
4. **真内容就是少** → **换 1:1 画幅（1080×1080）**，别硬撑 3:4。
5. 若确实是"呼吸型"骨架（金句/单句陈述，允许 ≤60% 内容）→ **必须补三个锚点**：顶部 kicker/日期 + 底部来源/出处行(20px mono) + 其上一条发丝线，否则空白读作"缺内容"而非"呼吸"。

## 垂直节奏（rhythm）

- 首尾各留 ~8% 边距（约 80-110px），作为有意的呼吸，不算死空白。
- 主标题下留 ≥28px、局部小标题下 ≥16px。
- **均匀分布内容块**：多个要点/卡片之间用相等的间距（用 8/12/16/24/32/40/48/64px 这套 token，别随手写 px），让它们从上铺到下（`justify-content: space-between` 或均等 gap），而不是挤在顶部。
- 每种结构的高度预算参考：账本每行 100-140px；管线每步(标题42+描述26+间距28)≈96px，5 步≈480px；矩阵 3×2 每格约 380px。据此让内容恰好铺满 1440。

## 溢出修正阶梯（反向：防"改过头"或内容太多溢出）

- 超 1-40px → 上移/收一处间距；40-90px → 压局部间距 + 缩一块；90-160px → 略缩标题/压一段；160px+ → 换高容量骨架或有意删内容。
- 改完再查底部空白别反弹（别为了不溢出又把内容顶上去留出底部空白）。

## 网格

- 瑞士系：严格 12 栏、**左对齐**、非对称留白，标题坐左上（**不是居中**）。
- 杂志系：单栏/双栏，衬线正文，用细线(1-2px)和账本行分隔，不靠卡片浮起。
- 间距 token（全站只用这些值）：8 / 12 / 16 / 24 / 32 / 40 / 48 / 64 / 80 / 96 px。
