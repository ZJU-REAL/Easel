# 内容策略框架详解

> `skill-content-strategy` 的领域知识库。SKILL.md 只保留步骤骨架，具体框架在此按需加载。

---

## 一、受众路径四阶段

将内容映射到受众与创作者的关系阶段，每阶段配不同内容类型与指标。

### 阶段 1：认识你（曝光期）— 占比 35-40%
- 心态："偶然刷到，觉得有点意思。"
- 内容：热点观点、干货合集、争议话题、数据盘点
- 指标：曝光量、完播率、新增关注

### 阶段 2：信任你（种草期）— 占比 30-35%
- 心态："这人确实懂行，经常来看。"
- 内容：深度教程、个人经验、避坑指南、真实测评、幕后过程
- 指标：收藏率、互动率、回访率

### 阶段 3：选择你（转化期）— 占比 15-20%
- 心态："需要这方面的服务/产品，找他。"
- 内容：用户案例、效果对比、产品体验、限时活动、咨询引导
- 指标：私信咨询、链接点击、成交量

### 阶段 4：推荐你（裂变期）— 占比 10-15%
- 心态："我要推荐给朋友，太有用了。"
- 内容：可转发的工具帖、模板合集、社群活动、UGC 征集
- 指标：转发率、@好友数、社群增长

## 二、90 天三阶段节奏原则

| 阶段 | 时间 | 重心 | 关键动作 |
|------|------|------|---------|
| 基建期 | Day 1-30 | 建立内容支柱，跑通流程 | 每个支柱各出 3-5 条，测试数据 |
| 优化期 | Day 31-60 | 放大有效支柱，砍掉低效方向 | 按数据调整支柱比例和格式 |
| 加速期 | Day 61-90 | 系列化、矩阵化、跨平台复用 | 打造标志性系列，开始转化动作 |

> 这里只给**节奏原则**。具体到某月某周的排期表由 `skill-content-calendar` 产出；发布频率见 `../../../shared/pillar-and-cadence.md`。

## 三、分发渠道策略模板

为每个目标平台制定差异化策略：

```
平台: [名称]
  定位: [该平台角色——主阵地/辅助曝光/长尾沉淀/私域引流]
  核心格式: [该平台最有效的内容格式]
  发布节奏: [频率 + 最佳发布时段]
  流量逻辑: [推荐机制/搜索优化/话题借势]
  跨平台复用: [哪些内容可从其他平台改编，如何改编]
```

### 一鱼多吃
一条核心内容改编为多平台版本：
```
1 条深度内容（B站中长视频 / 公众号长文）
  -> 小红书图文笔记（提炼核心观点 + 图文卡片）
  -> 抖音短视频（提取 1 个最强钩子，60 秒口播）
  -> 微博话题帖（观点 + 互动问题）
  -> 知乎回答（补充数据和论证）
  -> 视频号（竖版剪辑 + 评论区引导）
```

## 四、KPI 指标体系（按受众路径阶段）

| 阶段 | 核心指标 | 辅助指标 | 月度目标 |
|------|---------|---------|---------|
| 认识你 | 曝光量、新增关注 | 完播率、点赞率 | [据现状设定] |
| 信任你 | 收藏率、互动率 | 回访率、评论深度 | [据现状设定] |
| 选择你 | 私信咨询量、转化率 | 链接点击、客单价 | [据现状设定] |
| 推荐你 | 转发率、裂变系数 | UGC 数量、社群增长 | [据现状设定] |

每月复盘一次，调整支柱比例和内容方向。
