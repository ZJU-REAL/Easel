# 声音分析维度

跨所有样本寻找模式，不依赖单篇特征。每个维度的发现都需要标注样本证据。

## 1. 声音信号 (Voice Signals)

从样本中提取：

- **平均句长** — 统计各样本句子长度，给出范围和均值
- **段落节奏** — 单行换行 vs 空行分段、短促 vs 流畅
- **开头风格** — 反常识、提问、数据点、故事、自白、观察
- **人称视角** — 第一人称、第二人称、旁观者
- **语调** — 冷面、温暖、直白、俏皮、临床式
- **标志性短语** — 在多篇样本中重复出现的用词或短语
- **CTA 风格** — 结尾行动号召的方式

## 2. 结构信号 (Structural Signals)

- **长度范围** — 各样本字数/段落数的最小值和最大值
- **列表 vs 散文** — 偏好哪种表达方式
- **开头模式** — 如何开篇（直接陈述、场景设定、数据引入）
- **结尾模式** — 如何收尾（CTA、总结、开放式）
- **过渡手法** — 段落之间如何衔接

## 3. 主题信号 (Topic Signals)

- **高频主题** — 跨多篇样本出现的主题
- **隐含受众** — 样本中假设的读者是谁
- **作者立场** — 作者在行业中的定位和态度

## 4. 缺失信号 (Absence Signals)

这是最关键的维度。记录所有样本中从未出现的模式：

- **从未出现的词汇/标点** — 例如：em dash 在 0/5 篇样本中出现、从不用感叹号、从不加 emoji、从不带话题标签
- **从未使用的开头类型** — 例如：从不用反问句开头
- **从未触及的语调** — 例如：从不卖惨式、从不说教式、从不制造焦虑
- **从未出现的结构** — 例如：从不使用"不是 X，而是 Y"句式
- **从未出现的词汇集** — 例如：从不使用职场黑话、从不用"家人们/宝子们"

每项缺失必须标注"X/Y 篇样本"的证据。仅在全部样本一致缺失时列入。

## voice.md 模板结构

```
# 我的声音画像

## 我听起来像谁
[2-3 句描述整体声音风格]

## 语气基调
[3-5 个一致命中的调性 + 1-2 个从未命中的调性]

## 句子节奏
[平均句长、节奏、段落结构 + 回避模式]

## 开头钩子
[3-5 种观察到的 Hook 类型，每种附一个样本例子 + 缺失的 Hook 类型]

## 我怎么开头
[1-2 句 + 回避的开头方式]

## 我怎么收尾
[1-2 句，含 CTA/互动引导风格 + 回避的结尾方式]

## 标志性表达
[样本中的重复用词、口头禅、emoji 习惯、标点习惯]

## 内容禁区
[全部样本中一致缺失的词汇、标点、结构，附 X/Y 证据]

## 这个声音从不做的事
[3-5 个具体行为，源自样本缺失分析]
```
