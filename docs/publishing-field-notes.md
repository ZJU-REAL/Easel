## 一、各平台「原创标识」现状（核查日期 2026-10-13）

投稿时或发布后想给内容打「原创」标，各平台能力差异很大。实测结论：

| 平台 | 是否可标原创 | 入口 / 说明 | 核查方式 |
|------|--------------|-------------|----------|
| 小红书 | ✅ 有「原创声明」 | 笔记编辑页 → 打开「原创声明」开关 → 弹《原创声明须知》→ 勾选同意 → 点「声明原创」→ 发布保存 | 编辑页回读开关状态 |
| B站 | ✅ 投稿类型即「自制(原创)」 | 投稿参数 `--copyright 1`（biliup 默认值）；`2` 为转载 | member 稿件 API 回读 `copyright` |
| 微信视频号 | ✅ 有 | 发布页可选 | 用户确认 |
| 微信公众号 | ✅ 有 | 发布时可选原创声明 | 用户确认 |
| 抖音 | ⛔ 无「原创」项 | 编辑页只有「自主声明」：内容由AI生成 / 内容为个人观点或见解 / 内容为转载信息 / 内容含营销推广信息 / 虚构演绎仅供娱乐 / 无需添加自主声明 | 编辑页展开下拉逐项核对 |
| 快手 | ⛔ web 端无入口 | 创作服务平台的发布页与作品管理页都没有原创声明；官方发布流程也未包含该步骤（通常仅 APP 端可选） | 发布页/管理页全文检索 + 发布流程复盘 |
| 知乎 | ⛔ 无「原创」项 | 编辑页只有「内容类型声明」：包含剧透 / 医疗建议 / 虚构创作 / 理财内容 / AI 辅助创作 / 无声明 | 编辑页展开下拉逐项核对 |

**注意**：抖音的「自主声明」里最接近的是「内容由AI生成」，属**反向**合规披露，不要误勾成原创。

**另注**：已发布作品想补标原创，前提是平台提供「编辑已发作品」入口。
- 抖音：作品管理 → 编辑作品（有次数上限，页面提示「每个作品最多修改 5 次」）。
- 快手：web 端作品管理未提供编辑入口，故已发布内容无法回补。
- 小红书：笔记管理 → 编辑，可回到发布器修改。

## 二、知乎专栏正文：必须走「富文本粘贴」

**症状**：用脚本发布/更新知乎文章后，正文把 `### 一、…`、`**加粗**` 这类 Markdown 标记**原样显示**成文字，没有转成标题和加粗。

**根因**：知乎专栏正文是 **Draft.js** 富文本编辑器。粘贴 `text/plain` 时 Draft.js 不会解析 Markdown，只会把源码当纯文本插入；而粘贴 `text/html` 会按 HTML 结构正常转换（标题/加粗/有序列表/引用都能识别）。

**修复**：`skills/shared/scripts/web_publisher.py` 新增 `paste_md` 动作——
把 Markdown 转成 HTML（`_md_to_html`）后连同纯文本兜底一起写入剪贴板 `DataTransfer`，再向当前可编辑元素派发 `paste` 事件；知乎发布流程的正文步骤由 `type` 改为 `paste_md`。

**已验证**：转换后 DOM 富文本计数 H3×5 / 有序列表×2 / 引用×1 / 加粗×11，残留 Markdown 标记 0。

> 修已发布文章同理：进 `/p/<id>/edit` → 全选正文 → 粘贴 HTML 富文本 → 校验 DOM → 点「更新」。

## 三、小红书「原创声明」操作路径（含两个坑）

完整路径（编辑已发布笔记）：

1. 打开 `creator.xiaohongshu.com/publish/update?id=<note_id>&noteType=normal`
2. 打开 `.original-wrapper` 下的「原创声明」开关
3. 会弹出《原创声明须知》弹窗（`.d-modal.d-modal-centered`）：先勾选「我已阅读并同意」，**否则「声明原创」按钮是 disabled 状态**
4. 点「声明原创」→ 开关置为开
5. 点发布保存

**坑 1：发布按钮在闭合 Shadow DOM 里。**
编辑页的提交按钮是自定义元素 `<xhs-publish-btn>`（shadow root 为 closed，`querySelectorAll('button')` 看不到它）。要按 host 的包围盒点击：**发布按钮在 host 水平约 50% 处**（实测品牌红像素落在 host 宽度的 41%–59%），点 host 中心即可；单纯 `element.click()` 或点错比例会落在按钮外，什么都不会发生（页面不跳转、无 toast，容易误判成成功）。

**坑 2：弹窗遮罩会吃掉点击。**
原创声明须知弹窗未关闭时，遮罩 `d-modal-mask` 会拦截后续点击——必须先勾选同意并关掉弹窗，再点发布。

**判断是否真的保存成功**：更新页保存成功后 URL 会离开 `/publish/update`（跳回笔记管理页）；仅凭「点了按钮」不能算成功，要回读编辑页确认开关仍为开。

## 四、封面/落版署名按平台区分

同一条内容分发到多平台时，**封面落版署名要用该平台对应的账号名**，不要跨平台套用同一个名字（曾有封面沿用了另一个平台的账号名而返工重渲染）。
渲染封面时把占位名替换为该平台账号名后再出图，并在放行前 OCR 抽检一次落款。
