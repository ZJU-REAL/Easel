Problem

通用 AI 对创作者
是半成品

今天一个博主想用 AI 做内容，要在蝉妈妈找热点、ChatGPT 写脚本、剪映剪视频、Canva 做封面，然后手动适配小红书竖屏、B站横屏、抖音 15 秒节奏——每个环节断开，每次从零开始。GPT Work 和 Claude Cowork 确实强大，但它们是通用 Agent，不知道你的账号是什么风格、受众喜欢什么、哪些词在小红书会被限流。Easel 把这些通用能力特化到社媒场景，用用户画像把所有环节串起来。

Solution

用户画像 × 五层能力
× 成品交付

核心是一个用户画像系统——一个人设一个完整档案，横切所有能力层。不是通用热点，是「这个账号能做的热点」；不是模板脚本，是「这个风格的脚本」；不是文字建议，是直接交付可发布的素材包。

Scenes

创作者的一天

🔥
「今天做什么内容？」
根据画像从平台热榜里筛出你能做的选题，给三个方向，每个都贴合账号定位和受众偏好。不是 100 个热点丢给你选——是 3 个你真正能做的。
📝
「写个脚本」
30 秒短剧，自动带上你的标志性开场和受众喜欢的反转。出来的东西像你写的。
🎬
「出成片」
脚本→视频生成→配音→字幕→拼接→成片。直接交付可发布的素材包。
✅
「发之前帮我查一下」
自动检测绝对化用语、医疗承诺、导流外站、软广未标注——按小红书/抖音/B站各自的规则检测，告诉你哪里有风险、怎么改。不是通用法律检查，是平台特化的内容合规。
Differentiation

为什么不是现有工具能做的

vs 剪映 AI
可编程 vs 黑盒
剪映不可编程，不知道你是谁。Easel 是可编程管线 + 账号记忆——同样做一条视频，Easel 做出来的像你的风格。
vs GPT Work / Cowork
社媒专精 vs 通用
通用 Agent 不知道小红书禁什么词。Easel 把社媒 know-how 编码进 SKILL，这是通用 Agent 做不了的事。
vs 蝉妈妈
洞察→行动 距离为零
蝉妈妈帮你看数据，Easel 帮你用数据。「对比表格收藏率高」不是一个数字，是下次脚本里自动多加一张表格。
Moat

不造轮子
壁垒在别的地方

LLM 用 Claude / GPT，视频生成用 Runway / Pika / 可灵，编排用 OpenClaw——基建全用现成的。壁垒来自三个别人复刻不了的东西：领域 know-how 编码进 SKILL（短剧 SKILL 内化了钩子结构和悬念节奏；合规 SKILL 内化了三大平台审核逻辑）；账号特化数据资产（画像是创作者持续沉淀的资产，用得越久越精准）；跨层整合深度（五层闭环的组合价值远超单点堆叠）。整体框架开源。

Vision

每个创作者身边的内容搭档

Easel 的终局不是一个工具，是每个创作者身边的内容搭档。它了解你的风格、知道你的受众、记得你的成功和失败、跟踪平台的变化。创作者不需要学 AI、不需要写 prompt，只需要说「帮我做下一条」。真正为自媒体博主设计的产品——不是通用 AI 加个皮肤，是从第一天就只为创作者服务的。
