# 技能目录与外部服务

Seal V3 将 113 项产品能力内置在一个 Codex Skill 中。Codex 技能列表只应出现 `Seal 私人运营顾问 V3`；工作台技能库负责展示 113 项能力的中文名称、副标题、用途、权限和配置状态。

## 公开数据能力

支持公开账号、笔记、搜索、榜单、评论洞察、视频转写和竞品研究。RedFox Key 通过 Seal 配置界面录入，运行时临时注入；脱敏显示，不写入 URL、命令参数、日志、任务状态、报告或对话。高成本查询先提示用途与预计消耗并请求确认。

## 外部服务清单

Codex 登录态用于推理；六个平台网页用于登录、只读数据和经确认后的发布；RedFox 用于小红书公开数据；图片、视频、音乐、配音、通知和公众号能力按具体卡片配置对应 Key；热点/RSS 通常无需 Key；本地转录与编码使用 Python 模型及 FFmpeg。调用前必须说明服务、用途、Key 要求、成本和隐私边界，调用后记录时间、范围和结果限制。

## 安全

不保存或回显密码、验证码、Cookie、Token、二维码或任何第三方 Key。失败应可恢复；公开数据不得推导本人曝光、涨粉、观看时长、成交或收入。
