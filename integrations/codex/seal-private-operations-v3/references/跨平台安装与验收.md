# 跨平台安装与验收

## 系统要求

- macOS 13+ 或 Windows 11。
- Python 3.10+、Node.js 22+、FFmpeg（含 FFprobe）。
- 已登录可用的 Codex 桌面版或 Codex CLI。工作台通过 `codex exec --json` 建立可恢复对话；未调用任何其他 Agent 运行时。
- 约 8 GB 可用磁盘空间。Playwright Chromium、本地转录模型和媒体依赖会占用较多空间。

## 安装

macOS：

```bash
bash scripts/install-macos.sh
```

Windows PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1
```

Windows 脚本使用 `winget` 补齐 Python、Node.js 和 FFmpeg，不依赖 Git；Codex 命令不存在时通过官方 npm 包 `@openai/codex` 安装。安装内容全部留在 V3 Skill 内，系统级工具只有上述基础运行依赖。

## 启动

macOS：`bash scripts/start-macos.sh`

Windows：`powershell -ExecutionPolicy Bypass -File .\scripts\start-windows.ps1`

默认地址为 `http://127.0.0.1:7862/`。通过 `SEAL_HOST` 和 `SEAL_PORT` 可覆盖监听地址与端口。

## 验收

1. 运行 `runtime/.venv/bin/seal doctor`（Windows 为 `runtime\.venv\Scripts\seal.exe doctor`）。
2. 确认 Python、Node.js、FFmpeg、FFprobe、Codex、Playwright Chromium、前端和 113 项能力全部为 OK。
3. 运行 `python scripts/verify_install.py --runtime`。
4. 打开 `/api/status`，应返回 `runtime: true` 且 `skills` 数组长度为 113。
5. 新建一项不绑定真实发布的测试运营任务，分别验证对话、选题、日历、内容库的任务归属与全局视角。
6. 六端登录必须在对应平台真实页面完成。验证码、扫码和平台风控不能用模拟测试代替。

macOS 测试只能证明 macOS 实现与 Windows 兼容分支的静态/模拟正确性。最终“Windows 完整可用”必须在 Windows 11 真机按以上六步复验。
