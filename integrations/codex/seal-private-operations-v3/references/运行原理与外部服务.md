# 运行原理与外部服务

## 运行链路

浏览器访问 FastAPI 工作台；页面通过本地 API 读写账号状态、画像、选题、日历、运营任务和内容项目。需要智能处理时，后端启动本机 `codex exec --json`，注入当前运营任务、画像、附件清单和所选内置能力。Codex 在 V3 `runtime/` 内调用确定性脚本，将结果写入 `outputs/`。会话映射采用文件锁持久化，macOS 使用 POSIX 锁和进程组，Windows 使用 `msvcrt` 锁与 Windows 进程组。

113 项能力不会作为独立 Skill 安装。工作台读取 `bundled-skills/` 中的 `CAPABILITY.md` 建立私有能力注册表，Codex 只在执行某项任务时读取相应能力规范。内部文件故意不命名为 `SKILL.md`，避免被 Codex 递归发现为 113 个独立 Skill。

小红书登录由 V3 的 Playwright 持久化上下文完成。登录成功后，同一上下文把必要 Cookie 同步到 `runtime/browser-profiles/redbook/cookies.json`，Redbook 分析能力通过 `REDBOOK_COOKIE_FILE` 复用；Cookie 与 Redbook 缓存都留在 V3 内，不写入用户主目录，也不需要第二次登录。

## 本地依赖

- Python/FastAPI/Uvicorn：工作台后端。
- Playwright Chromium：六端网页登录、登录态核验和网页发布。
- Node.js：小红书公开数据 CLI 等 JavaScript 工具。
- FFmpeg/FFprobe：视频与音频探测、裁切、转码、字幕、混音、合成和质量验证。
- Pillow、OpenCV、pandas、matplotlib、faster-whisper、rembg 等：对应的本地图片、数据、转录和抠图能力。

## 外部服务与 Key

| 服务 | 用途 | 是否需要 Key | 何时调用 |
|---|---|---:|---|
| Codex | 对话、路由、推理和工具编排 | 使用 Codex 登录态 | 工作台对话或执行智能能力时 |
| 小红书、抖音、快手、视频号、知乎、B站 | 登录、账号数据、发布 | 通常使用浏览器登录态；部分官方 API 另需凭证 | 用户主动登录、查询或确认发布时 |
| RedFox | 小红书公开账号、笔记、评论和竞品数据 | `REDFOX_API_KEY` | 选择公开数据研究能力时 |
| OpenAI-compatible 图片服务 | 生图与电商配图 | Base URL、API Key、模型名 | 用户确认可能计费的生图请求后 |
| 视频生成服务 | 文生视频/图生视频 | 对应供应商 Key 和模型 | 用户确认可能计费的视频生成后 |
| 音乐与云配音服务 | 音乐、TTS、声音克隆 | 对应供应商 Key；声音克隆还需授权 | 用户确认调用后 |
| 微信公众号/通知/Webhook | 发布或结果通知 | App 凭证、Token 或 Webhook | 用户明确授权写操作后 |
| 热点榜与 RSS | 热点和资讯 | 多数公开源不需要 Key | 用户打开热点或运行资讯能力时 |

### 安装与首次运行的网络调用

这些调用只用于安装依赖或下载本地模型，不属于 Seal 的业务数据接口：

| 服务 | 用途 | 是否需要 Key | 调用时机与失败影响 |
|---|---|---:|---|
| PyPI | 安装 V3 的 Python 依赖 | 否 | 执行 macOS/Windows 安装脚本时；不可访问会使安装中止 |
| npm Registry | 安装 Codex CLI、Redbook 和前端依赖 | 否 | 安装或重建前端时；不可访问会使对应步骤中止 |
| Playwright 浏览器下载源 | 下载 Chromium | 否 | 首次安装时；不可访问则六端登录、网页登录和网页渲染不可用 |
| Homebrew | macOS 安装 Python、Node.js 或 FFmpeg 的兜底来源 | 否 | 仅本机缺少合格依赖时；V3 已带可用媒体工具时不会重复安装 FFmpeg |
| winget | Windows 安装 Python、Node.js 和 FFmpeg | 否 | 仅缺少合格依赖时；失败会明确中止，不静默降级 |
| Hugging Face Hub | 下载 faster-whisper 本地 ASR 模型 | 否 | 首次使用某个模型时；失败自动尝试 ModelScope |
| ModelScope | faster-whisper 国内镜像回退，并逐文件校验 SHA-256 | 否 | Hugging Face 不可用时；两者都失败才中止 ASR |
| rembg/U2Net 模型源 | 下载本地去背景模型 | 否 | 首次使用指定模型时；下载完成后离线推理 |
| Microsoft Edge TTS | 无 Key 在线配音兜底 | 否 | 用户选择 Edge TTS 时；需要可访问微软在线语音服务 |

安装脚本不会安装或启动 OpenClaw，也不会访问 OpenClaw 网关。运行时唯一的智能编排入口是本机 Codex 登录态；FFmpeg/FFprobe 只在本机处理媒体文件。

Key 通过工作台技能卡配置并写入 V3 的 `runtime/.env`，接口响应只返回是否已配置和脱敏值。Key 不进入 URL、命令参数、任务文件、对话正文或日志。`.env`、Cookie、浏览器 profile、二维码和运行产物都不包含在可分发 Skill 包中。

## 数据与权限

- 全局数据与无任务对话可同时使用；进入任务只改变当前页面的任务范围，不锁死全局能力。
- 选题、日历和内容项目都有 `task_id` 或全局归属；退出任务后可切回全局视角。
- 对外发布、评论、回复、通知和付费生成必须在执行前确认。
- 测试默认只做本地读写与 dry-run，不触发真实发布或计费接口。
