> 避免各处维护副本漂移。定义公式与原则，用 `{}` 占位，不写死具体产品/行业案例。
> 引用方式（CWD=项目根）：`skills/shared/references/hook-title-formulas.md`。

首行 / 首图 / 前 3 秒决定 90% 的表现。**每次只用一个公式**，保持首行清晰有力。

## 二、标题公式（变量用 `{}` 占位）

### 利益型
- `{达成理想结果}，不用{付出的代价/痛点}`
- `{时间/场景}就能{结果}`
- `把{输入}变成{理想结果}`

### 痛点型
- `还在{糟糕做法/困扰}吗？`
- `别再{无效行为}了`
- `{人群}最容易踩的{数字}个坑`

### 人群/身份型
- `{人群}专属的{品类}` / `{人群}闭眼入的{品类}`
- `{身份标签}必备！{核心功能}`
- `谁懂啊，{人群}的{需求}终于有救了`

### 反差/悬念型
- `我一开始也不信，直到{反差结果}`
- `{低成本/低门槛}也能{高价值结果}`
- `原来{反常识观点}`

### 数字/证据型
- `{数字}{人群}都在用的{品类}` / `{数字}天/次，{可量化结果}`
- `亲测{时长}，{具体变化}`

### 清单/干货型
- `{数字}个{主题}，建议收藏`
- `关于{主题}，我踩过的坑都在这`

### 提问/发现型（小红书常用）
- `有没有那种{功能}的{产品类型}？`
- `我发现了个宝藏！{核心价值}`
- `{热点词}爆火后，我用它做了{场景}`

## 五、使用指南

1. **匹配平台** — 小红书重利益点/共鸣、语气软；知乎重反常识/结论前置；抖音重悬念/挑战；微博重情绪/观点；公众号重痛点/悬念。
2. **匹配调性** — 按账号调性选公式；专业号避免过度挑衅，个人号可更大胆。
3. **具体优于空泛** — "3 个月涨 5 万粉" 优于 "涨粉很快"。
4. **每次只用一个公式** — 不混合多个钩子。
5. **出海兜底** — X 适合大胆断言和清单，LinkedIn 适合个人故事和数据，可译为英文使用。
