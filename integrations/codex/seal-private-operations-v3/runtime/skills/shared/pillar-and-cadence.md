# 内容支柱比例与发布频率

> Easel 策划层关于"支柱比例"和"发布频率"的**唯一数据源**。`skill-content-strategy`（定义支柱理论时引用比例基线）、`skill-content-calendar`（排期时套用比例和频率）共同引用本文件，避免各写一份、数字打架。

---

## 一、内容支柱比例（按创作者类型）

作为排期和策略的起点比例，再根据月目标和历史数据调整。

### 个人 IP / 知识博主
| 支柱 | 占比 | 说明 |
|------|------|------|
| 干货教程 / 经验分享 | 30% | 核心价值。专业知识、方法论、实战经验。 |
| 个人故事 / 成长历程 | 25% | 建立连接。失败、转折、成长故事。 |
| 用户案例 / 数据证明 | 20% | 社会证明。学员/客户成果、数据展示。 |
| 热点观点 / 争议话题 | 15% | 引发讨论、涨评论和关注。 |
| 推广 / 引流 | 10% | 课程、服务、合作。控制在 20% 以下。 |

### 好物推荐 / 测评博主
| 支柱 | 占比 | 说明 |
|------|------|------|
| 产品测评 / 对比 | 35% | 核心内容。真实体验，有数据有对比。 |
| 使用教程 / 技巧 | 20% | 降低购买犹豫，教怎么选、怎么用。 |
| 开箱 / 好物分享 | 20% | 激发兴趣。新品开箱、好物清单。 |
| 个人日常 / 真实生活 | 15% | 建立信任。展示真实的人。 |
| 促销 / 合作 | 10% | 优惠码、限时活动。 |

### 美食 / 生活方式博主
| 支柱 | 占比 | 说明 |
|------|------|------|
| 食谱教程 / 生活技巧 | 30% | 核心价值。步骤清晰、可复制。 |
| 探店 / 好物推荐 | 25% | 拓展内容面。探店视频、厨具推荐。 |
| 日常生活 / Vlog | 20% | 建立陪伴感。真实的生活切片。 |
| 节日/节气/时令 | 15% | 蹭自然热点。时令食材、节日特辑。 |
| 互动 / 投票 | 10% | 你们想看什么？哪个更好吃？ |

### 穿搭 / 美妆博主
| 支柱 | 占比 | 说明 |
|------|------|------|
| OOTD / 妆容教程 | 35% | 核心内容。搭配方案、化妆步骤。 |
| 好物推荐 / 测评 | 25% | 转化导向。护肤品、服装品牌推荐。 |
| 趋势解读 / 灵感 | 15% | 时尚趋势、季节穿搭灵感。 |
| 个人风格 / 故事 | 15% | 展示个人审美和生活态度。 |
| 合作 / 福利 | 10% | 品牌合作、粉丝福利。 |

### 职场 / 副业博主
| 支柱 | 占比 | 说明 |
|------|------|------|
| 职场技能 / 工具教程 | 30% | 核心价值。AI 工具、效率方法、职场技能。 |
| 收入分享 / 案例拆解 | 25% | 数据驱动。月报、案例、成果展示。 |
| 个人成长 / 心态 | 20% | 建立共鸣。焦虑、选择、坚持的故事。 |
| 行业洞察 / 趋势 | 15% | 展示前瞻性。行业变化、新机会。 |
| 推广 / 课程 | 10% | 训练营、课程、咨询服务。 |

### 按月目标调整比例
| 目标 | 调整 |
|------|------|
| 涨粉 / 扩大曝光 | +10% 教程, +5% 热点观点, -10% 推广, -5% 日常 |
| 促进转化 / 咨询 | +10% 案例证明, +5% 推广, -10% 日常, -5% 教程 |
| 推新品或活动 | +15% 推广（活动内容）, 其他三个支柱各 -5% |
| 提升互动 / 社区感 | +10% 互动内容, +5% 日常, -10% 推广, -5% 案例 |
| 建立专业权威 | +15% 教程/行业洞察, -10% 推广, -5% 日常 |

**通用约束：** 推广类支柱占比不超过 15-20%；每个支柱每周至少出现 1 次。

## 二、发布频率参考（按平台 × 成长阶段）

| 平台 | 起步期 | 成长期 | 成熟期 | 单条构成参考 |
|------|--------|--------|--------|------|
| 小红书 | 3-4 次/周 | 5-7 次/周 | 每日 | 2-3 图文 + 1 视频笔记 |
| 抖音 | 1 次/天 | 2 次/天 | 2-3 次/天 | 短视频为主 |
| B站 | 1 次/周 | 2 次/周 | 3 次/周 | 中长视频 |
| 微博 | 3-5 次/周 | 每日 | 2-3 次/天 | 图文/短视频混合 |
| 公众号 | 1 次/周 | 2 次/周 | 3 次/周 | 长文 |
| 视频号 | 2-3 次/周 | 每日 | 每日 | 短视频 |

**原则：** 起步期重"跑通流程 + 测数据"，宁精勿滥；成长期放大有效格式；成熟期系列化、矩阵化、跨平台复用。
