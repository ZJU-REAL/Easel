# 洗稿模式与原创度评估清单

> 供 skill-risk-scanner 在文本原创度评估时参考。均为定性判断依据，不产生相似度分数。

## 一、洗稿模式识别

逐段扫描文案，识别以下洗稿特征。对发现的每个特征，引用具体段落文本并说明判断理由；未发现时明确说明"未检测到明显洗稿模式"。

### 1. 机械性同义替换

- 整段文字用同义词替换但论证结构完全相同（如"提升→增强"、"方法→方式"的批量替换）。
- 判断标准：替换后的表达是否不自然、是否存在同义词堆叠。

### 2. 句式变换但论点复刻

- 主被动语态互换、长短句拆合，但核心论据和论证顺序与常见内容高度一致。
- 判断标准：论点排列顺序是否与典型公开内容雷同。

### 3. 段落搬运重排

- 多个段落的信息组合与某类常见内容完全一致，仅调换段落顺序。
- 判断标准：整体信息覆盖面和信息选取是否缺乏独立判断。

## 二、内容独特性评估

判断文案是否包含原创成分：

1. **个人经验/案例** — 是否有"我做了/我试过/我们团队"等第一人称实践描述。
2. **独家数据** — 是否有自行采集的数据、实验结果、独家调研。
3. **原创观点** — 是否提出了非公知的判断、独特视角、反常识论点。
4. **具体细节** — 是否有搬运者通常不会有的操作细节（如具体参数、踩坑经历、时间线）。

评估结论：

- 包含 2 项以上原创成分 → 原创度较高。
- 包含 1 项原创成分但占比低 → 原创度一般，建议补充更多个人经验。
- 全文无任何原创成分，纯通用信息拼凑 → 原创度低，高风险。

## 三、引用规范检查

1. **观点引用** — 引用他人观点、金句时是否标注了出处（作者名、来源）。
2. **数据引用** — 统计数据、行业报告数据是否注明了数据来源和时间。
3. **截图引用** — 引用其他创作者的截图时是否标注原作者。
4. **转述充分度** — 如果用户提供了参考来源文本，对比本文与来源的差异：
   - 是否仅做了表层改写（换词不换意）。
   - 是否加入了自己的分析、评论、延伸。
   - 是否改变了文章结构和论证逻辑。
