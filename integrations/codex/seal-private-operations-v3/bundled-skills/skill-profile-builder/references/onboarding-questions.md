# 首次引导提问清单

按维度提问，一次问一组，别一口气抛全部。用户已答的跳过，缺的才问。目标是拿到能填 6 维 Profile 的最小必要信息。

## A. 基础与平台（对应 identity / platforms）

1. 想建的画像叫什么？（一个人设 = 一个画像，可跨多平台）
2. 主要在哪些平台运营？（小红书 / 抖音 / B站 / 微博 / 知乎 / 公众号 / 视频号）
3. 每个平台的主页链接？账号名和粉丝量级（大概即可）？
4. 现在是全新起号，还是已有一定内容/粉丝？

## B. 运营意图（对应 identity）

5. 想做什么方向/领域的内容？（越具体越好，如"平价护肤测评"而非"美妆"）
6. 为什么做这个方向？你的优势/资源/独特经历是什么？（差异化来源）
7. 运营目标是什么？（涨粉 / 变现 / 个人品牌 / 引流私域 / 兴趣分享）

## C. 内容偏好与风格（对应 style / audience）

8. 你自己喜欢看什么类型的内容？平时收藏/点赞什么？
9. 想产出什么形式？（图文 / 短视频 / 中长视频 / 长文）
10. 有对标/参考的账号吗？喜欢它们哪一点？
11. 期望的调性？（专业严谨 / 轻松幽默 / 亲切日常 / 犀利吐槽 / 治愈…）
12. 目标受众是谁？（年龄/性别/职业/他们的痛点）——不确定也没关系，可由链接分析和对标推断。

## D. 红线与偏好（对应 preferences）

13. 明确不想做的内容/话题/合作方式？
14. 有没有必须守的合规底线？（如不接医疗功效、不做虚假宣传）

## 提问原则

- 分组问、给例子降低回答门槛；用户说"不知道"时，用链接分析或对标账号帮他推断，再让他确认。
- 能从社媒链接分析出来的（风格、题材、受众），先分析再拿结论跟用户对齐，而不是干问。
- 允许留白：拿不到的信息标 `[待补充]`，不要逼问也不要编造。
