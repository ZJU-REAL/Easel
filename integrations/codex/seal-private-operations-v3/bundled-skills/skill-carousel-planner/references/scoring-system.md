# 轮播图互动评分体系

6 个维度的加权评分，用于评估轮播图/多图笔记的互动潜力。

---

## 评分维度

### 1. Hook 强度（权重 25%）

封面页能否在 1 秒内打断滑动。

| 分数 | 标准 |
|------|------|
| 9-10 | 封面文字 ≤8 字，使用经过验证的 Hook 公式，在缩略图尺寸下清晰可读，好奇缺口强烈 |
| 7-8 | 封面文字 ≤12 字，有明确的好奇缺口或情绪触发，缩略图下基本可读 |
| 5-6 | 封面有 Hook 意识但力度不足，文字偏多或缺乏悬念 |
| 3-4 | 封面像标题而非 Hook，没有制造打开的冲动 |
| 1-2 | 封面是纯 logo / 纯文字标题 / 无吸引力 |

### 2. 翻页节奏（权重 20%）

读者是否有持续翻到下一页的动力。

| 分数 | 标准 |
|------|------|
| 9-10 | 每页都制造了明确的翻页动力，信息递进感强，完读率预期高 |
| 7-8 | 大部分页面有翻页动力，偶有信息断裂但不影响整体节奏 |
| 5-6 | 翻页动力时有时无，中段有走神风险 |
| 3-4 | 信息堆砌，缺乏递进，读者可能在第 3-4 页流失 |
| 1-2 | 页面之间无逻辑关联，可任意打乱顺序 |

### 3. 价值密度（权重 20%）

每页是否提供具体、可操作的信息。

| 分数 | 标准 |
|------|------|
| 9-10 | 每页都有独立的具体要点，没有水页，读者能带走可执行的知识 |
| 7-8 | 大部分页面有实质内容，个别页面偏过渡性但不冗余 |
| 5-6 | 有价值但稀释，存在 2-3 页可以合并或删除 |
| 3-4 | 内容空泛，缺乏具体性，多为"正确的废话" |
| 1-2 | 几乎没有可操作信息，纯感受性/口号性内容 |

### 4. CTA 有效性（权重 15%）

末页行动号召能否驱动收藏、分享或评论。

| 分数 | 标准 |
|------|------|
| 9-10 | CTA 与内容类型精准匹配，表达具体、有行动门槛低，预期转化率高 |
| 7-8 | CTA 明确且与内容相关，但表达可以更具体 |
| 5-6 | 有 CTA 但偏泛（如"关注我"），与内容匹配度一般 |
| 3-4 | CTA 模糊或放错位置，与内容脱节 |
| 1-2 | 无 CTA 或 CTA 是"点击主页"这类无效引导 |

### 5. 视觉统一性（权重 10%）

全篇视觉风格是否一致、专业。

| 分数 | 标准 |
|------|------|
| 9-10 | 统一的配色、字体、排版风格，像一个完整的作品而非拼凑 |
| 7-8 | 整体统一，个别页面风格略有偏差但不突兀 |
| 5-6 | 风格基本一致但缺乏设计感，排版较随意 |
| 3-4 | 风格不统一，多种字体/颜色混用 |
| 1-2 | 每页像独立的图片，毫无整体感 |

### 6. 配文质量（权重 10%）

配文是否与轮播图互补并驱动互动。

| 分数 | 标准 |
|------|------|
| 9-10 | 配文独立成文，提供轮播图未覆盖的额外价值，CTA 与末页呼应 |
| 7-8 | 配文与轮播图互补，有个人视角，标签精准 |
| 5-6 | 配文基本合格但偏复述轮播图内容 |
| 3-4 | 配文敷衍，仅堆砌标签或简单描述 |
| 1-2 | 无配文或配文与轮播图无关 |

---

## 计算方式

```
加权总分 = Hook强度 x 0.25 + 翻页节奏 x 0.20 + 价值密度 x 0.20
         + CTA有效性 x 0.15 + 视觉统一性 x 0.10 + 配文质量 x 0.10
```

## 判定标准

| 分数区间 | 判定 | 行动 |
|----------|------|------|
| 8.0-10.0 | 优秀 | 直接进入制作 |
| 7.0-7.9 | 合格 | 可以制作，建议优化标注的弱项 |
| 5.0-6.9 | 需修改 | 修改最弱的 1-2 个维度后重新评分 |
| < 5.0 | 需重做 | 重新构思结构或更换 Hook 策略 |

**最低通过分：7.0**

低于 7.0 时，必须定位最弱维度、给出具体修改建议并修改后重新评分。
