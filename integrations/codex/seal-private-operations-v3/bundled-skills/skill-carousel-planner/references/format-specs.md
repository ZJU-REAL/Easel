# 轮播图尺寸与格式规范

各平台多图/轮播图的尺寸、页数和排版规范。

---

## 小红书 多图笔记

| 参数 | 规范 |
|------|------|
| 推荐比例 | 3:4（竖版，首选） |
| 推荐尺寸 | 1080 x 1440 px |
| 备选比例 | 1:1（正方形） |
| 备选尺寸 | 1080 x 1080 px |
| 最少页数 | 2 页 |
| 最多页数 | 18 页（建议 6-12 页） |
| 最佳页数 | 8-10 页 |
| 图片格式 | JPG / PNG |
| 文件大小上限 | 20 MB / 张 |

### 文字排版

| 元素 | 规范 |
|------|------|
| 封面标题字号 | ≥ 60pt，加粗 |
| 正文字号 | 36-48pt |
| 安全区域 | 上下左右各留 80px |
| 最大行数 | 3-5 行 / 页 |
| 字体推荐 | 思源黑体、阿里巴巴普惠体、站酷快乐体 |

### 注意事项

- 第一张图即封面，在发现页以 3:4 缩略图展示
- 封面缩略图尺寸约 260 x 347 px，文字在此尺寸下必须可读
- 所有图片比例必须一致，混用比例会被裁切

## 通用规则

1. **同一组内所有页面比例一致**，不混用竖版和方形
2. **封面是流量入口**，文字/画面在缩略图尺寸下必须清晰
3. **页数与内容匹配**：干货教程 8-12 页，故事/情绪 5-8 页，清单 6-10 页
4. **颜色对比度**：文字与背景对比度 ≥ 4.5:1（WCAG AA）
5. **不用纯白背景**：在 feed 中会与界面融合，失去边界感
