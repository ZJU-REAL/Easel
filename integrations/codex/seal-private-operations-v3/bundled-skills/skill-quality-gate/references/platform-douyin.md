# 抖音平台合规规则

抖音特有的合规检测维度，在通用规则之上叠加。

## 诱导互动

抖音限制显式索要互动行为：
- 直接请求点赞、关注、转发、收藏（"双击点赞"、"关注不迷路"）
- 用利益诱导互动（"点赞抽奖"、"关注领福利"，除非通过官方活动工具）
- 在视频开头或结尾过度堆叠互动引导
- 利用悬念、恐吓等手段强迫互动（"不转发就会……"）

**判定原则**：自然的内容引导可接受；机械式、重复性、利诱式的互动索取为违规。

## 版权音乐与素材

抖音对音视频版权有严格管控：
- 使用非平台曲库中的背景音乐
- 搬运其他创作者的原创视频片段
- 使用影视剧、综艺等未授权片段
- 录屏其他平台内容并发布

**判定原则**：建议使用平台内置曲库；引用他人素材时需确认授权或符合合理使用范围。

## 挂人与引战

抖音禁止针对个人的攻击性内容：
- 未经同意公开他人个人信息（照片、姓名、联系方式）
- 针对特定个人的嘲讽、侮辱、人身攻击
- 故意挑起群体对立或制造争议以获取流量
- 恶意剪辑他人言行以扭曲原意

**判定原则**：基于事实的公共讨论可接受；针对个人的攻击、未脱敏的隐私暴露为高风险。
