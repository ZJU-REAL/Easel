# 网页/博客 SEO 模式（可选）

> **仅当内容会被搜索引擎（百度/谷歌）抓取时才用这套**：独立站/博客、被外部收录的公众号长文、要冲搜索引擎排名的知乎回答。纯站内内容（小红书/抖音/B站/微博）不适用，别套。

这是原 web SEO 校验能力，作为可选模式保留。判断内容有搜索引擎抓取价值后，按下列清单叠加校验。

---

## 技术 SEO 校验清单

| 检查项 | 规则 | 状态 |
|--------|------|------|
| **标题标签（title）** | 含核心关键词且前置，长度适配搜索结果展示不被截断 | ✅/❌ |
| **Meta 描述** | 概括正文、含关键词、有点击诱因，长度适配摘要展示不被截断 | ✅/❌ |
| **标题层级** | 仅一个 H1，层级不跳级（H1→H2→H3） | ✅/❌ |
| **URL/Slug** | 含关键词、简短、纯小写+连字符、无冗余参数 | ✅/❌ |
| **内链** | 若干条相关内链，锚文本有描述性 | ✅/❌ |
| **外链** | 权威来源外链，无死链 | ✅/❌ |
| **Open Graph** | og:title / og:description / og:image 齐全（影响社交分享卡片） | ✅/❌ |
| **图片** | 每张有 alt 文本、含关键词变体 | ✅/❌ |
| **首段** | 开头即出现目标关键词 | ✅/❌ |
| **关键词密度** | 自然覆盖、不堆砌 | ✅/❌ |
| **可读性** | 段落短、句子不冗长、结构化便于抓取 | ✅/❌ |

每项输出 ✅ PASS / ❌ FAIL + 具体修复建议。

---

## E-E-A-T 内容质量评估

搜索引擎（尤其谷歌）用 E-E-A-T 判断内容质量，YMYL（健康/金融/法律等影响用户重大利益的）话题要求更严。

**「Who / How / Why」三问：**

| 问题 | 检查点 |
|------|--------|
| **Who** | 是否有署名、作者简介、专业资质 |
| **How** | 是否披露制作方式、含原创研究或第一手证据 |
| **Why** | 是否为帮助用户而写，而非纯为搏搜索流量 |

**四维评分（各 1-10）：**

| 维度 | 高分标志 |
|------|---------|
| **Experience 体验** | 原创案例、亲身经历、过程记录、Before/After |
| **Expertise 专业** | 术语准确、深度分析、澄清常见误区 |
| **Authoritativeness 权威** | 被引用记录、行业认可、机构背书 |
| **Trustworthiness 可信** | 来源标注、数据准确、必要免责声明、可联系 |

**薄弱内容检测：**
- 拼凑式内容（多来源缝合、无原创观点）
- 关键词堆砌为主、用户价值为辅
- 缺第一手经验或原创数据
- YMYL 话题无专业背书
