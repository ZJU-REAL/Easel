# 平台原生搜索规则

各国内平台站内搜索的信号与关键词布局规则。定义规则与判断维度，不写死具体行业/产品案例。

---

## 通用：搜索流量 vs 推荐流量

- **推荐流量**：算法根据钩子、完播、互动、账号标签主动分发，爆发快但不精准、不可累积。
- **搜索流量**：用户主动搜关键词命中，精准、长尾、可长期累积（老内容仍持续被搜到）。
- 一条内容可同时吃两种流量。搜索优化的目标：在不牺牲推荐所需钩子/可读性的前提下，让关键词进入平台搜索索引。
- **反推关键词的方法**：谁在搜（人群）→ 想解决什么（需求）→ 会用什么词说（真实搜索用语，含长尾、口语、错别字变体）。可参考平台搜索框下拉联想词、相关搜索、热榜。

## 小红书

**搜索入口**：站内搜索框（用户带明确需求来搜），是小红书第二大流量来源。

**关键搜索信号（按权重）：**
1. **标题关键词** — 核心词放前段；标题是搜索匹配权重最高的位置。
2. **正文关键词** — 首句与前几行含核心词；自然覆盖同义词/长尾词。
3. **话题标签（#）** — 直接进搜索索引，选高搜索量且相关的标签；数量适度（避免堆砌被判营销）。
4. **封面文字** — 系统会 OCR 封面文案，封面大字含关键词有助被搜。
5. **收藏量** — 高收藏是"有用"信号，提升搜索排序。

**校验维度：**
- 标题是否前置核心搜索词、是否含长尾词
- 正文关键词密度是否自然（覆盖到位不堆砌）
- 标签是否踩中真实搜索热词而非泛词/自造词
- 封面文字是否含可搜关键词
- 是否规避违禁/限流词（限流会同时打掉搜索与推荐）

## 抖音

**搜索入口**：搜索页 + 视频信息流里的"搜索关键词卡位"（视频关联热搜词，用户搜时被顶上来）。

**关键搜索信号：**
1. **视频标题/文案关键词** — 标题与文案含用户会搜的词；核心词前置。
2. **话题词（#）** — 关联高搜索量话题，卡位相关搜索。
3. **完播率与互动** — 搜索排序也吃内容质量信号，完播高的更容易排前。
4. **字幕/口播关键词** — 语音与字幕会被识别，口播中自然带关键词。
5. **热点词卡位** — 蹭当下搜索热词，抢搜索流量窗口。

**校验维度：**
- 标题/文案是否含明确搜索词而非纯情绪钩子
- 话题词是否兼顾搜索量与相关性
- 前 3 秒钩子是否兼容关键词露出（搜索来的用户需快速确认相关）
- 是否卡位了相关热搜词

## 知乎

**搜索入口**：站内搜索 **+ 百度/谷歌收录**（知乎内容在搜索引擎权重高，这是知乎独有优势）。

**站内信号：**
1. **问题匹配** — 回答挂在高流量、高关注、持续有人搜的问题下；问题本身的搜索量决定天花板。
2. **回答质量信号** — 赞同、收藏、专业度、完读，影响回答在问题页与搜索页的排序。
3. **关键词覆盖** — 回答正文自然覆盖问题相关长尾词。

**搜索引擎信号（web SEO 在此适用）：**
- 知乎问题页会被百度/谷歌收录，回答里的关键词、结构化表达、权威引用都影响外部搜索排名。
- **此时可叠加 `web-blog-seo.md` 的 web SEO 校验**（关键词密度、标题层级、权威外链、E-E-A-T 内容质量）。

**校验维度：**
- 是否选中高搜索量且匹配的问题
- 回答是否覆盖问题的长尾变体
- 内容质量是否支撑站内排序（专业、证据、结构）
- （冲搜索引擎时）是否满足 web SEO 基本项

## 公众号

**搜索入口**：微信"搜一搜"（微信生态内搜索，也部分被搜索引擎收录）。

**关键搜索信号：**
1. **标题关键词** — 搜一搜主要匹配标题；核心词前置、含用户会搜的说法。
2. **原创标** — 原创内容在搜一搜权重更高，防止被抄袭稀释。
3. **账号权重与历史** — 账号在该领域的持续输出与被搜历史影响排序。
4. **正文关键词** — 正文覆盖相关词，辅助被搜一搜及外部收录。
5. **摘要** — 摘要含关键词，影响搜一搜结果展示与点击。

**校验维度：**
- 标题是否含明确搜索词（很多公众号标题只玩悬念，牺牲被搜）
- 是否声明原创
- 摘要是否含关键词
- 正文关键词是否自然覆盖

## B站

**搜索入口**：站内搜索。

**关键搜索信号：**
1. **标题关键词** — 核心词前置。
2. **标签（tag）** — B站 tag 直接进搜索与分区索引，选相关高搜索量 tag。
3. **简介关键词** — 视频简介覆盖相关词。
4. **播放/完播/互动** — 质量信号影响搜索排序。
5. **分区选择** — 选对分区提升垂直搜索命中。

**校验维度：**
- 标题、tag、简介三处关键词是否协同
- tag 是否兼顾搜索量与相关性
- 是否选对分区

## 微博

**搜索入口**：话题、超话、热搜。

**关键搜索信号：**
1. **话题词（#话题#）** — 带话题词才进话题聚合页，是被搜的前提。
2. **超话** — 垂类超话内的沉淀与搜索。
3. **时效性** — 微博搜索强时效，蹭热搜/热点词抢窗口。
4. **互动量** — 转发/评论/赞影响话题页与搜索排序。

**校验维度：**
- 是否带相关话题词（双 # 包裹）
- 是否蹭到相关热搜/热点
- 是否加入合适超话
