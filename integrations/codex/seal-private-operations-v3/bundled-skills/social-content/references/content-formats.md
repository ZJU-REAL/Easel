# 内容格式

> 主线是国内平台原生格式。X thread / LinkedIn carousel 作为出海次要兜底放文末。

## 小红书图文笔记

| 卡片 | 用途 | 内容 |
|------|------|------|
| 1（封面） | 钩子 | 大字标题 + 利益点/悬念，决定点击。必须让人想点进来。 |
| 2-3 | 背景 | 痛点共鸣或场景代入，"我也遇到过"。 |
| 4-8 | 价值 | 每张一个要点，短句 + emoji，视觉清爽。 |
| 末张 | 收尾 | 总结 + 收藏引导（"码住"、"姐妹们冲"）。 |

**规则：** 1080×1440 竖版；口语化闺蜜感；每段 1-3 行；封面首图独立成立；正文末尾 5-10 个 #话题。
（做整套小红书笔记优先用 `xhs-note-creator`，本 SKILL 只出通用图文骨架。）

## 短视频脚本（抖音 / B站竖屏 / 视频号）

```
[0-3s]  钩子 — 一句话/一个画面抓住注意力，前置结论或悬念
[3-10s] 背景 — 快速铺垫为什么值得看
[10-50s] 正文 — 核心内容，每 3-5 秒一个节奏变化，配大字幕
[尾]    CTA — "关注"、"评论区聊聊"、"看到最后"
```

**规则：** 9:16 竖版；字幕必备；完播率优先；热门 BGM 加持。
（要专业分镜/口播稿优先用 `video-script`，本 SKILL 只出脚本骨架。）

## B站中视频结构（16:9）

```
开头 15s：这期讲什么 + 为什么值得看（留住观众）
主体：分章节展开，每节一个小标题
中段：埋前向钩子（"后面还有更炸的"）防跳出
结尾：总结 + 一键三连引导 + 下期预告
```

## 公众号长文结构

```
标题：双标题制造点击（≤64 字）
开头 3 段：抛出痛点/悬念/结论，留住读者
主体：一个核心观点，小标题分段 + 重点加粗 + 留白
结尾：金句收尾 + 在看/分享引导 + 互动话题
```

## 微博 / 知乎

- **微博**：140 字精华，情绪或观点前置，带 1-3 个 #话题#，引导转发评论。
- **知乎**：前 3 行给结论或反常识，分点论述 + 数据案例，结尾引导赞同收藏。

## 内容复用：一稿多平台

从一篇长文/一个主题，可拆出：

| 平台 | 复用产物 |
|------|---------|
| 小红书 | 1 套图文笔记（核心要点做成卡片组） |
| 抖音 | 1 条 30-60s 讲解视频脚本（取最抓人的 1 个点） |
| B站 | 1 条中视频脚本（完整展开 + 章节） |
| 微博 | 3-5 条短博（每条一个洞察，分散发布） |
| 公众号 | 1 篇深度长文（完整逻辑） |
| 知乎 | 1 篇回答/文章（专业角度 + 数据） |

**复用流程：**
1. **提取** — 从原素材拉出 5-7 个关键洞察
2. **重构** — 每个洞察适配目标平台的原生格式和受众预期
3. **重写** — 不复制粘贴，为每个平台原生写作（小红书口语、知乎专业、抖音短促）
4. **排期** — 分散到 1-2 周发布，最大化曝光

## 次要兜底：出海格式

**X / Twitter Thread：** 推文 1 钩子 → 2-3 背景 → 4-N 编号要点 → 末推 CTA。每条独立可读，钩子不放链接。

**LinkedIn Carousel：** 封面钩子 → 背景 → 每页一要点（≤30-40 词）→ 总结 → CTA。PDF 上传，标页码，封面能独立成帖。
