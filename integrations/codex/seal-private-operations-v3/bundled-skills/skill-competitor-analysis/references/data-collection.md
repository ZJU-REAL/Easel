# 账号数据采集与反爬降级

竞品拆解的数据全部来自**平台公开信息**。不做逆向、不承诺抓到后台精确数据（播放完播、粉丝增量等创作者中心数据外部拿不到）。默认工具链：`web_fetch`（抓主页/笔记页）+ `web_search`（补全公开信息）。

## 能采到什么 vs 采不到什么

| 数据 | 来源 | 可得性 |
|------|------|--------|
| 账号昵称 / 简介 / 定位标签 | 主页 | ✅ 公开 |
| 粉丝量级 / 获赞与收藏总量 | 主页 | ✅ 公开（多为量级，非精确值） |
| 作品列表 / 标题 / 封面 / 发布时间 | 主页信息流 | ✅ 公开 |
| 单篇点赞 / 收藏 / 评论数 | 内容页 | ✅ 公开（部分平台需登录态，外部常缺失） |
| 评论区内容 / 高赞评论 | 内容页 | ⚠️ 部分可得，翻页常受限 |
| 播放量 / 完播率 / 粉丝增量 / 转化 | 创作者中心 | ❌ 外部不可得，**不要编造** |

**原则**：拿不到的数据如实标注"无公开数据"，用可观测的替代指标（如点赞/收藏比、评论热度）推断，绝不虚构精确数字。

## 采集顺序（逐级降级）

1. **主页直取** — `web_fetch` 账号主页链接，提取简介、粉丝量级、近期作品标题与互动量级。
2. **搜索补全** — 主页被反爬拦截（返回验证码/空内容）时，改用 `web_search`：
   - `{账号昵称} {平台}` — 找账号介绍、第三方榜单收录
   - `site:xiaohongshu.com {账号昵称}` / `{账号昵称} 爆款` — 定位代表作
   - `{账号昵称} 数据 / 粉丝` — 从第三方数据站的公开报道取量级
3. **样本抽取** — 无法拉全量作品时，抽取近期 10–20 篇代表内容手动归类，标注"基于样本，非全量统计"。
4. **热点交叉** — 借势分析走热搜 API，参照 [hotlist-apis.md](../../shared/hotlist-apis.md)，不在本文件复制端点。

## 各平台反爬现状与降级

| 平台 | 主页 web_fetch | 降级方案 |
|------|---------------|---------|
| 小红书 | ⚠️ 常需登录态，易返回空 | 改 `web_search site:xiaohongshu.com`，取搜索摘要与第三方收录 |
| 抖音 | ⚠️ 视频页反爬强 | 用抖音号搜索 + 第三方榜单（如新抖类公开报道）取量级 |
| B站 | ⚠️ 服务器 IP 返回 -352 / 验证码 | **不要 fetch 视频页**；用 `web_search` 取 UP 主公开数据、三连量级 |
| 微博 | ✅ 相对宽松 | 主页多可直取，翻页受限时用搜索补全 |
| 公众号 | ⚠️ 文章可读，账号页难取 | 搜索文章标题聚合，推断更新频率与选题 |
| 知乎 | ✅ 相对宽松 | 主页/回答页多可直取 |

## 降级时的表述规范

反爬导致数据缺失时，报告里明确写清：

- 标注数据来源与可信度：`（来源：主页直取）` / `（来源：公开搜索，量级估算）` / `（无公开数据）`
- 缺失精确值时给区间或量级，例如"粉丝 10w+ 量级"而非编造"粉丝 112,384"
- 样本分析注明覆盖范围："基于近 20 篇样本，非全量"
- 绝不把推断包装成抓取结果——诚实比精确更重要
