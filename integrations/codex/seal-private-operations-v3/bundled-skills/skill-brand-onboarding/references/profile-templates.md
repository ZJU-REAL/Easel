# Profile 输出模板

Phase 4 生成画像时，按以下模板写入 `profiles/<name>/` 各文件。

## identity.md

```markdown
# [品牌名] — 账号定位

## 基本信息
- **名称：** [品牌名 + logo 格式]
- **昵称：** @[各平台昵称]
- **Slogan：** [标语]
- **简介：** [简介文案]
- **所在地：** [地区]
- **定位：** [一句话定位]

## 核心产品/服务
[主推产品/服务列表]

## 差异化
[用户自述的核心差异点]

## 内容方向
[内容支柱和主题方向]
```

## style.md

```markdown
# [品牌名] — 风格指南

## 语气调性
- **[特征]** — [描述]

## 内容节奏
[开头结构、段落节奏、互动引导]

## 视觉风格
- 主色调：[色值和用途]
- 字体风格：[字体信息]
- 封面风格：[描述]
- 滤镜/调色：[描述]

## 标志性内容格式
[分步描述标志性帖子格式]

## 文案示例
> [示例 1]
> [示例 2]

## Do / Don't
### DO
- [规则]
### DON'T
- [规则]
```

## audience.md

```markdown
# [品牌名] — 受众画像

## 目标人群（ICP）
[用户画像描述]

## 用户语言
[用户常用词汇和表达习惯]

## 痛点与需求
[目标用户关心什么、需要什么]

## 互动特征
[用户互动偏好和行为模式]
```

## platforms.md

```markdown
# [品牌名] — 平台运营

## 小红书（如适用）
- 账号：[昵称/ID]
- 粉丝：[数量] | 获赞与收藏：[数量] | 笔记数：[数量]
- 内容形式：[图文/视频比例]
- 发布频率：[频率]
- 常用标签：[标签列表]

## 抖音（如适用）
[同上结构]

## B站（如适用）
[同上结构]

## 微博（如适用）
[同上结构]

[未运营的平台删除对应段落]
```

## preferences.md

```markdown
# [品牌名] — 内容偏好与红线

## 内容支柱
1. **[支柱名]** — [描述]

## 主推产品/服务
[重点展示的产品/服务]

## 禁区
- [绝对不做的内容]

## 合规底线
- [硬性规则]

## 运营目标
- **主目标：** [目标]
- **次目标：** [目标]
- **当前基线：** [现状描述]
```

## memory.md

```markdown
# [品牌名] — 运营记忆

> 此文件由归因层根据发布效果和用户反馈持续更新。初始为空。

## 内容洞察
[待积累]

## 踩坑记录
[待积累]
```

## 标记规则

- 未获得的信息统一标记为 `[待补充]`，不编造
- 从截图估算的信息标注 `(估算)`
- 用户直接提供的信息标注来源平台
