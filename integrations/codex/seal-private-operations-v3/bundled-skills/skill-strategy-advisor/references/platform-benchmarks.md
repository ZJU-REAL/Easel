## 使用说明

1. **互动率** = (点赞+评论+收藏+转发) / 阅读或播放量
2. 数据低于基线下限 → 内容质量或定位可能有问题
3. 数据在基线范围内 → 正常水平，关注趋势变化
4. 数据高于基线上限 → 表现优异，分析可复用因素
5. 增粉率持续低于基线 → 需审视内容是否产生关注动力
