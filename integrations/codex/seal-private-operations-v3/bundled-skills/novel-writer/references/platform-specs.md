# 平台适配（网文连载）

> 不同平台读者、篇幅、付费机制、题材偏好差异很大。写前先按目标平台定「单章字数 / 更新频率 / 题材调性」。
> 以下为常见区间与套路，具体以平台当期规则为准（会变，别写死）。

## 知乎盐选

- **形态**：短篇/中篇故事为主（几万字一个完整故事），走盐选会员付费解锁。
- **单章**：2000–4000 字，节奏比传统网文快。
- **开局**：知乎读者吃「反转 + 真实感 + 信息量」。**第一人称经历体**（"我"的亲历）代入最强。
- **题材**：悬疑、情感、职场逆袭、家庭伦理、脑洞现实向。忌纯升级流爽文。
- **钩子**：知乎问答基因强，标题/开头常以「问题/反常事件」切入（"我妈临终前，把房子留给了保姆")。
- **收尾**：短篇要有完整闭环 + 一个余味反转，不像长篇留大坑。

## 番茄小说

- **形态**：超长连载（几十万到几百万字），免费阅读 + 广告/全勤分成。
- **单章**：**建议 ≥2000 字**（部分活动要求），日更多章。
- **开局**：极致爽文节奏，黄金三章必须打脸/逆袭/金手指前置，前 10 章定生死。
- **题材**：都市、玄幻、系统流、赘婿逆袭、战神归来、甜宠。下沉市场偏好强。
- **节奏**：爽点密度高，几乎每章一个小爽点，忌拖沓/大段设定。

## 起点中文网

- **形态**：长篇连载，订阅付费，读者更「老白」（资深），对套路和逻辑要求高。
- **单章**：2000–4000 字，均订看质量。
- **开局**：仍重黄金三章，但容得下更精细的世界观与人物；忌逻辑硬伤、金手指太随意。
- **题材**：玄幻、仙侠、科幻、历史、游戏。世界观完整度、脑洞、文笔都被在意。
- **节奏**：爽点 + 布局并重，可埋长线伏笔，但要持续给正反馈。

## 小红书图文连载（改编产线）

- **形态**：把章节拆成 3–9 张竖版卡片（1080×1440），一「集」一帖，评论区追更。
- **每卡**：一个情绪节点/一个画面，文字精炼（每卡 1–3 句），末卡强钩子引导「关注追更」。
- **题材**：情感、悬疑、脑洞短故事最适配；长篇取高光片段做「名场面」引流回长文平台。
- **产线**：正文写好后交 card-xiaohongshu / xhs-note-creator 排版；配图走 ai-image-gen 或统一模板。

## 通用建议

- **单章字数达标用脚本判定**：`wordcount.py check --target <平台目标> --tolerance 0.15`，不靠估算。
- **更新频率**：连载最忌断更；能日更就日更，起号期尤其。排期交 skill-content-calendar / skill-publish-scheduler。
- **合规**：各平台对暴力/软色情/政治/未成年题材红线不同，写前按 Profile `preferences.md` 与平台规则过滤，拿不准先问。
