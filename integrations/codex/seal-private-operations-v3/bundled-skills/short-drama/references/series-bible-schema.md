# 剧集圣经 Schema（series bible）

> series bible 是整部剧的「总账本」，跨集追踪角色、剧情、悬念。是多集一致性的源头。
> `drama_ops.py scaffold` 会生成模板，据题材填满。

## 必填板块

### 1. 一句话卖点
- 用一句话说清「谁 + 遇到什么 + 有多爽/多虐/多反转」。这是选题能不能爆的第一关。
- 例：「被赶出家门的赘婿，其实是隐藏的商业帝国继承人。」
- 先读 `genre-hooks-handbook.md` 选定**题材 + 核心爽点**，再落这句。

### 1.5 核心矛盾（一句话）
- 全剧**主冲突**：谁和谁、为了什么、对抗到底。微短剧必须单一主矛盾。
- 例：「赘婿隐忍复仇 vs 欺压他的岳家豪门」。

### 1.6 戏剧承诺（必填，写角色/剧情前先过）
按 `story-engine.md` 压成一句可测的承诺，并过其"承诺自检"：
> 当【主角】用【惯常策略】追求【当前目标】时，【对抗机制】迫使其付出【核心代价】；系列反复兑现【观众回报】，直到【终止性转变】发生。
- 四要素（主体/追求/昂贵阻力/反复回报）缺一即退化成题材标签，重写。
- 过 `drama-review-rubric.md` A 门（swap-test / 阻力有筹码 / 主角能动性 / 中段有回报）。

### 2. 世界观 / 设定
- 时代、场景、规则、金手指（若有）。竖屏微短剧世界观要极简，别喧宾夺主。

### 3. 角色表（一致性 + 人物深度关键）
每个角色定死两类信息——**外貌一致性**（喂参考图）+ **人物深度**（决定选择与台词，治扁平）：

| 字段 | 用途 |
|------|------|
| 姓名 + 编号 | 对应 ref_index 的 C 编号 |
| **外貌关键词** | **直接喂参考图 prompt**：年龄/发型/脸型/服装/气质，越具体越稳（"28岁男性，短寸黑发，冷峻，深灰西装"） |
| **行动模型（8 字段）** | **治扁平的核心**，按 `story-engine.md`：表层目标/保护对象/自我解释/惯常策略/筹码/盲区/底线与越线/可变事实。**只写"性格"预测不了选择。** |
| **want / need / wound / flaw** | 外在目标(want) vs 内在需要(need) + 创伤(wound)与由此生的错误信念 + 缺陷(flaw)。三者冲突处即戏。 |
| **弧光（arc）** | 从头到尾**变化**了什么（成长/黑化/和解）——主角必填；反派也可有。 |
| **可跟随四问** | ep1 内可见地答出其一（承受的具体不公 / 替谁扛 / 共同渴望 / 想借的本事），见 `story-engine.md`。 |
| **关系（双向）** | 不写"母女"标签，写双向：A 需要 B 什么 / 怕 B 看见什么 / 用什么约束 B（反向亦然）。 |
| **voice sheet** | 词汇/口头禅/句长/语气/回避词——保证台词有区分度（过 swap-test），见 `dialogue-craft.md`。 |
| **音色档案** | 喂选角：**性别 · 年龄段 · 气质 · 身份 · 语速**。据此按 `voice-casting.md` 定音色落 `cast.json`。**别只写「男声」——要具体到能选出唯一音色。** |

### 4. 剧情主线
- 全剧的核心冲突与走向：起点 → 主要矛盾 → 高潮 → 结局。
- 微短剧节奏极快，主线要单线清晰，忌多线并进。

### 4.5 情绪曲线 & 爽点节奏表
- **情绪曲线**：全剧观众情绪的起伏走向（憋屈→释放→甜→揪心→大爽），别一路平或一路爽。
- **爽点节奏表**：列出每集的**主爆点**（打脸/反转/揭示/甜点），确认「先抑后扬」且密度够（见 `causal-beats.md`「爽点密度」）。

| 集 | 主爆点（爽/虐点）| 情绪 |
|---|---|---|
| 1 | 主角被踩到底 + 第一次亮底牌 | 憋屈→初爽 |

### 4.6 反派阶梯（治「反派工具人 / 爽点通胀」）
按 `satisfaction-and-villain.md` 列出**分层反派**，确认层层升级（不是反复打同级）：

| 层 | 角色 | 出场 | 筹码 / 威胁 | 三段式安排（中反派） |
|---|---|---|---|---|
| 小反派 | | 前15% | | 速败退场 |
| 中反派 | | 15–45% | | 小胜→受挫低谷→翻盘 |
| 大反派 | | ~45%+ | | 高潮对决 |

- 每层"可恨/可信/递进"，下一层出场**前有伏笔**、代价更高。

### 5. 分集大纲（每集一行）

| 集 | 剧情（一句话）| 本集反转点 | 集末钩子 cliffhanger |
|---|---|---|---|
| 1 | 建立人物 + 抛出核心冲突 | 身份/局势的第一个翻转 | 一个让人必须看下一集的悬念 |
| 2 | 冲突升级 | … | … |

- **每集必有：一个反转点 + 一个集末钩子**（钩子类型见 `genre-hooks-handbook.md`）。
- **集间因果咬合**：本集钩子应是下集目标/阻碍的「因」（见 `causal-beats.md`）。
- 分集节奏建议：**前 3 集定生死**（快速立人设 + 抛冲突 + 第一个爽/虐点），中段升级，结尾反转+爽点释放。

### 6. 统一视觉风格前缀（一致性关键）
- 一条会**追加到所有生图/生视频 prompt** 的风格描述，锁定全剧画面统一。
- 含：**风格**（都市港风/古装武侠/校园清新/悬疑冷调）+ **画幅**（9:16竖屏）+ **色调**（冷/暖/高对比）。
- 例：「都市港风，9:16 竖屏，冷色调，电影质感，浅景深」。

## 与其他文件的关系

- 角色表 → 决定 `ref_index.json` 要建哪些 C 编号参考图；「音色档案」→ `cast.json` 选角（`dubbing.py`）。
- 分集大纲 → 每集展开成 `episodes/epNN/script.md`（因果节拍四幕剧本）→ 抽 `lines.json` 配音。
- 统一风格前缀 → 抄进每个 `shots.json` 的 `style_prefix`，逐镜 prompt 都带上。
