# 因果节拍法（causal beats）——让剧情「有逻辑地上头」，不是流水账

> 剧情简单/散，多半是「然后…然后…」的流水账。好剧本是**因果链**：每个节拍都由上一个
> **导致**，主角的选择推动下一步。本文给单集的因果节拍模板 + 爽点密度要求，配合
> `genre-hooks-handbook.md`（选题材/钩子）与 `four-act-drama.md`（四幕结构）使用。

## 一、核心原则：用「因为/所以」串，不用「然后」

- ❌ 流水账：他去公司，**然后**遇到前妻，**然后**吵架，**然后**回家。
- ✅ 因果链：他被诬陷丢了项目（**因为**）→ **所以**去公司对质 → 对质中前妻反咬一口（**因为**要保自己）→ **所以**他被迫亮出隐藏身份（转折）→ 全场震惊（钩子）。
- 自检：把相邻节拍之间的连接词换成「**因为/所以/但是**」还成立 = 因果扎实；只能用「然后」= 散，要重写。

## 二、单集因果节拍模板（15–30s）

每集是一个**完整的因果小闭环**，四个节拍：

1. **目标（起，前3s）**：主角这一集**想要什么**（+ 用 3 秒钩子抛出）。目标要具体、可视——「他要在董事会上夺回控制权」。
2. **阻碍（承）**：**因为**有人/有事挡路，目标受阻，矛盾升温。阻碍要来自**对手的主动**，不是巧合。
3. **转折（转，爆点）**：主角**做出关键选择/亮出底牌**，局势翻转——**这是本集爽/虐的释放点**。转折必须是主角**主动促成**，不是天上掉的。
4. **钩子（合，集末）**：闭环刚合上，**因为**这个转折又**引出**新危机/新悬念（集末 cliffhanger），逼观众看下一集。

> 关键：本集的「钩子」应当是下一集「目标/阻碍」的**因**——集与集之间也要因果咬合，不是各写各的。

## 三、爽点密度（微短剧的命）

- **每 15–30 秒一个「情绪事件」**：小反转 / 打脸 / 揭示 / 甜点 / 危机。别让情绪走平超过半分钟。
- **先抑后扬**：爽点前先给「憋屈/被踩」，落差越大越爽。打脸戏尤其要先让对方嚣张到顶。
- **一集一个主爆点**：所有节拍向这个爆点汇聚，别平均用力。

## 四、人物动机自检（防「工具人」）

- 每个角色（含反派）这一集的行为，都要能回答「**他为什么这么做**」，且动机符合 series-bible 人设。
- 反派不能只为推剧情而坏——他要有自己的目标。反派越合理，主角逆袭越爽。
- 对白要**推进因果**（带出信息/逼出选择），不是闲聊。

## 五、把节拍落成剧本

单集因果节拍 → 写进 `script.md`（对白 + 动作 + 情绪标记）→ 抽成 `lines.json`（逐行 speaker+text+emotion，喂 `dubbing.py`）→ 拆成 `shots.json`（5–6 镜，见 `shot-prompt-format.md`）。

一般：**目标→1 镜（开场钩镜）；阻碍→1–2 镜；转折→1–2 镜（爆点镜给足）；钩子→1 镜（结尾悬念镜）**。

## 六、写完必做

用 `drama-review-rubric.md` 逐项自评：**因果是否断裂 / 反转密度 / 人物动机 / 钩子强度 / 追剧欲**。任一项弱 → 重写，别凑合。
