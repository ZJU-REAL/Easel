# 台词技法（dialogue craft）——治「台词功底差 / 像 AI」

> 写 `script.md` 的对白、抽 `lines.json` 前必读。目标：台词像"偷听到的人话"，不像"AI 在互相念说明书"。

## 一、AI 台词为什么平（先认清病根）

AI 默认追求**清楚**，而清楚是张力的敌人。三种典型病：

1. **直给（on-the-nose）**：角色把心里话直接说出口。真人是绕着说、话里有话、说东指西。AI 爱这样，因为直给最"合逻辑、最完整"。
2. **雷同（uniform）**：每个角色都一个腔——作者的腔。检验：把两个角色的台词对调，若没有任何地方崩 → 雷同。
3. **过满（too-complete）**：语法工整、信息密集、情绪透明，像在"发表演讲"。真人说话是碎的、有停顿、有省略。

**根因**：潜台词需要"在藏什么"这条信息，而它在你的 series-bible 里、不在模型的默认输出里。**所以模型编不出潜台词，你必须把"在藏什么"喂给它。**

## 二、七个可套用的修法

1. **把"在藏什么"写进节拍指令**：写台词前，在该场景先写一行舞台说明——
   "A 在藏 X；B 怀疑 X 但因为 Y 不敢直问。写一段两人**从不说破 X、却句句都在绕 X** 的对话。"
2. **争 A、吵 B（表里分离）**：表层在争一件小事（要不要养狗），内里在吵另一件（没被听见/不被尊重）。**谁都不点破**，情绪由一个**具体物件**承载（那只杯子、那句"又一次")。
3. **曝光转冲突**：绝不让一个角色"讲设定"。让 **2 个以上角色对同一信息做出不同反应** → 既交代了信息、又制造了一个冲突节拍。信息要**碎着给**，可借一个新人角色让观众"跟着一起才知道"。
4. **每角色一张 voice sheet**：词汇量/口头禅/句长/语气/回避词。喂 prompt 时给**角色特写**而非场景描述——"姐姐是回避冲突型、习惯用钱的逻辑掩盖愧疚" 远胜 "两姐妹为遗产吵架"。
5. **每人都有"想要 + 想藏"**：场景里再加一个**时限或权力落差**，潜台词会自动出现。
6. **禁情绪标签、改 physical beat**：把"她愤怒地说"换成一个动作/一次打断/一句说到一半的停顿。（`lines.json` 的 emotion 字段是给配音引擎的，不是让角色把情绪念出来。）
7. **三遍过（高压锅法）**：① 给每人设对立目标；② 删掉所有情绪形容词、换成 physical beat；③ 加一处感官锚（气味/触感/声音）。然后**砍掉 20–30%**，用一个手势/停顿/画面替代。

## 三、短剧专属约束（竖屏 1–2 分钟）

- **单行 ≤ 15 字**，一口气能说完；**单集有效台词 200–300 字**。
- **大白话，不加修饰语**——"用最简单的台词攻击对方，用最简单的手段打脸对方"。
- **每集至少 1 句记忆点金句**（能被截图转发的狠话/名台词）。
- 短剧重**冲突性 > 逻辑性、情绪性 > 故事性**：打脸的那句**应该**落得干脆利落。
  → 所以平衡点是：**在不拖慢节拍的前提下**做潜台词与区分度。慢热文艺腔在短剧里是错的。

## 四、金句怎么造（每集 1 句）

- 短、狠、可截图；从**人物盲区/筹码/关系**里长出来，不是硬凑鸡汤。
- 三种常见形：**原话奉还**（把对方羞辱他的话反扣回去）/ **反差宣言**（弱势者说出压场的一句）/ **一刀见血**（一句话戳破对方伪装）。
- 反面：网络热梗堆砌、正确的废话、翻译腔。

## 五、台词门自检（写完对白 / 抽完 lines.json 逐条过，见 rubric E 门）

- [ ] **swap-test**：任意两角色台词能互换而不崩？→ 腔调雷同，按 voice sheet 重写。
- [ ] 有没有直接说出情绪的句子（"我很生气/我好难过"）？→ 换成动作或潜台词。
- [ ] 设定/前情是靠一个人"讲"出来的？→ 改成 2+ 人不同反应带出。
- [ ] 每个场景里每个说话人都有"想要 + 想藏"吗？
- [ ] 有 ≥1 句记忆点金句吗？每行 ≤15 字吗？单集有效台词 200–300 字吗？
- [ ] **念出来**：像"偷听到的"还是"被解释的"？后者 → 收紧冲突、重写。
