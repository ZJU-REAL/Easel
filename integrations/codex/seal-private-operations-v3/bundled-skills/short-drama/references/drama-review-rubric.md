# 短剧评审门禁（review gates）——写完/做完必过，且必须举证

> 借鉴 worldwonderer 的 `reviewed_invariant` 纪律：**评审必须引用具体节拍/字段/台词，不许说「不够抓人」这种空话。**
> 每一项打分 1–10，**任一 ≤6 就重写**；标 ⛔ 的是硬伤，**必须修**、不接受"宽进"。
> 顺序：写 bible → 过 A、B；写每集 script/lines → 过 C、D、E；出片 → 过 F、G。

## A. 故事引擎门（写完 series-bible，逐项引证）

| 项 | 通过标准 | ⛔ 硬伤信号 |
|---|---|---|
| 戏剧承诺完整 | 含 主体/追求/昂贵阻力/反复回报 四要素 | ⛔ 缺任一 → 退化成题材标签或事件流水账 |
| swap-test | 换掉人名/职业后前提仍独特 | ⛔ 换了就和别的剧没区别 → 独特矛盾不具体 |
| 阻力有筹码 | 反派能真挡、有资源 | ⛔ 一句话解释就让反派收手 |
| 主角能动性 | 主角行动才有结果 | ⛔ 主角不动、结果也到（靠救/靠巧合） |
| 中段有回报 | 每集兑现一种情绪回报 | ⛔ 只有大结局才回报 → 中段必空 |

## B. 人物可跟随门（每个主要角色，引 bible 字段）

| 项 | 通过标准 | ⛔ 硬伤信号 |
|---|---|---|
| 行动模型完整 | 8 字段齐（表层目标/保护对象/自我解释/惯常策略/筹码/盲区/底线/可变事实） | ⛔ 只有年龄外貌性格 |
| 可跟随四问 | ep1 内**可见地**答出其一（具体不公/替谁扛/共同渴望/想借的本事） | ⛔ 一条都答不出 → 结构对但没人看 |
| 关系双向 | 每对关键关系写了双向的需求/恐惧/约束 | ⛔ 只有"母女/上司"标签 |
| 反派可信 | 有合理动机、非为恶而恶 | ⛔ 为使坏而使坏 / 工具人 |

## C. 反转揭示门（每集，引具体反转）

| 项 | 通过标准 | ⛔ 硬伤信号 |
|---|---|---|
| 因果一句话测试 | 每个反转能填「因为X→原计划失效→只能在代价A/B间选」 | ⛔ 填不出 → 空降反转 |
| 公平揭示 | 观众先见可解释线索、证据为**剧内理由**此刻浮现 | ⛔ 作者需要时凭空冒出 |
| 状态改变 | 每次升级命名改了哪个状态（权力/知识/关系/暴露/资源/物理/道德） | ⛔「更生气/更吵」而无新能力/知识/代价 |
| 反转密度 | 一集 ≤1 大反转、全剧 ≤3 核心大反转 | 一集堆 3–4 个 → 情绪散、观众丢线 |

## D. 节奏门（每集）

| 项 | 通过标准 | ⛔ 硬伤信号 |
|---|---|---|
| 开场钩 | 0–3s 直接上冲突/反差/悬念 | ⛔ Logo/慢铺垫/背景旁白 |
| 信息就位 | 0:10 前交代 谁/在哪/什么麻烦/想要什么 | 前 10s 还在铺 |
| 情绪节点密度 | 每 20–30s 一个情绪事件（台词/动作/信息冲突） | 中段走平一大段 |
| 憋屈→释放 | 有压有放，压够再爆 | 长段虐主角无反打 / 无蓄力就爽 |
| 集末钩 | 力度 > 本集所有冲突，情绪最高点黑屏 | ⛔ 平淡收场 |

## E. 台词门（每集，念出来逐条过 · 最被忽视的一块）

| 项 | 通过标准 | ⛔ 硬伤信号 |
|---|---|---|
| swap-test | 两角色台词不可互换（各有腔调） | ⛔ 能互换而不崩 → 全员一个腔 |
| 无直述情绪 | 情绪靠潜台词/动作，不靠"我很生气"念出来 | 直接把心里话说出口（on-the-nose） |
| 曝光转冲突 | 设定/前情由 2+ 人不同反应带出 | 一个人"讲设定"/大段旁白 |
| 想要+想藏 | 每场每说话人都有想要与想藏 | 闲聊、无目的对话 |
| 金句+字数 | ≥1 记忆点金句；单行 ≤15 字；单集有效台词 200–300 字 | 冗长、修饰堆砌、无金句 |
| 偷听感 | 念出来像"偷听到的人话" | 像"被解释"/念说明书 → 收紧冲突重写 |

## F. 成片门（assemble 出片后）

| 维度 | 看什么 |
|---|---|
| 画面一致性 | 同角色跨镜跨集长相稳（参考图 + I2V） |
| 音画同步 | 配音/字幕/画面节奏对齐 |
| 画幅/时长 | 9:16 竖屏、单集时长合平台 |
| 合规 | 暴力/软色情/价值观红线（拿不准先问） |

## G. 配音/选角门（配音后）

- ⛔ **声线区分**：不同角色明显不同声线、旁白独立（`dubbing.py cast check` 拦同音色）。
- ⛔ **像人不像机器**：不是全剧一个声音、不是平读机器音（配音引擎见 SKILL Step6；阶段二上 CosyVoice2 表现力引擎）。
- **贴人物**：音色符合角色性别/年龄/气质/身份。
- **情绪匹配**：台词情绪与语气一致（怒读得怒、悲读得悲）。
- 字幕对齐：voice.srt 时间轴对得上、带角色名。

## 返工原则

- 任一门项失败 → **引具体节拍/字段/台词**重写，别泛泛说"加强一下"。
- 一般项最多返工 1 轮，之后交付并如实说明残留弱点（宽进）。
- 但 ⛔ 硬伤（无 ep1 钩 / 腔调雷同 / 空降反转 / 全剧一个声音 / 反派工具人）**必须修，不将就**（严出）。
- 弱在哪 → 回对应文件：引擎/人物→`story-engine`；台词→`dialogue-craft`；爽点/反派→`satisfaction-and-villain`；反转→`genre-hooks-handbook`；因果节拍→`causal-beats`。
