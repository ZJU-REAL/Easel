# 爽点与反派（satisfaction & villain）——治「没爽点 / 反派工具人」

> 短剧的引擎是**情绪价值**。爽点烂 90% 是因为反派太弱、或"越打越同级"。写 series-bible 的爽点曲线 + 反派阶梯时读本文。
> 方法论借鉴 0xsline/short-drama（satisfaction-matrix / villain-design）。

## 一、爽点的本质：压抑 → 释放

**压抑越深，释放越爽。** 全剧情绪曲线：**憋屈 — 小爽 — 更憋屈 — 大爽**，跨集切分。
早期要**蓄气**（让观众替主角憋着难受），后期爽点间隔拉大、单次更猛。

## 二、五类爽点公式（每个爽点对号入座，写清情绪链）

| 类型 | 情绪公式（节拍） | 子模式 |
|---|---|---|
| **身份碾压** | 轻视/侮辱 → 蓄力 → 身份揭露 → 碾压 → 跪地求饶 | 军衔/证件/电话/财富/能力/关系 |
| **打脸复仇** | 被欺负/被陷害 → 隐忍蓄力 → 反击 → 恶人当众出丑受罚 | 原话奉还/证据反杀/局中局/以牙还牙/群众审判/实力碾压 |
| **逆袭翻盘** | 跌入谷底 → 绝望 → 转机 → 一步步翻盘 → 站上巅峰 | 绝境翻盘/实力进阶/逆风翻盘/连环翻盘/复仇翻盘 |
| **情感爆发** | 误会/隐忍 → 情感积累到极限 → 爆发/告白/和解 → 泪目 | 告白/真相告白/误会冰释/久别重逢/牺牲揭露/爆发哭诉 |
| **悬念揭秘** | 谜题建立 → 线索积累 → 真相逼近 → 终极揭秘 → 恍然大悟 | 身份/阴谋/关系/动机/历史揭秘 |

**爽感放大器 = 围观者反应**：永远写出旁观者的震惊 + 冒犯者的下场（跪地/开除/痛哭）。没有围观反应，碾压就没有回响。

## 三、爽点通胀警告（中段变平的头号原因）

**反复打"同级"反派 ≠ 升级**，只会审美疲劳。中段必须**升级对抗层级**，而非增加事件数量：
- 小反派 → 核心反派 → 结构性压迫（个人恩怨 → 制度/家族/势力）。
- 每个爽点的**代价/风险都要比上一个高**（赌得更大、输了更惨）。
- 判据：这次爽点若失败，主角会失去的东西，比上次更贵吗？不是 → 通胀了。

## 四、反派设计：三原则

1. **可恨**——观众必须对他产生强烈负面情绪（愤怒/厌恶/恐惧）。
2. **可信**——行为有合理动机，**不能为恶而恶**（否则观众觉得假）。
3. **递进**——层层升级，每层比上层更难对付。

## 五、反派四层阶梯

| 层 | 角色 | 出场 | 作用 |
|---|---|---|---|
| 1 | **小反派**（炮灰） | 前 15% | 练手靶子，速败，1–2 个即可，干净退场 |
| 2 | **中反派**（主要对手） | 15%–45% | 有真资源，需 2–3 回合，**必须先赢主角一次**制造低谷 |
| 3 | **大反派**（终极 BOSS） | ~45% 起 | 高潮对决 |
| 4 | **隐藏反派**（幕后） | 结局 | 可选的最终反转，非必需 |

**中反派三段式**：① 主角小胜/平手（试探）→ ② 中反派反击、主角受挫（低谷）→ ③ 主角以智慧/实力翻盘（高潮）。
**升级衔接**："你以为赢了？我后面还有人"/"他不过是我的一颗棋子"——但**下一层必须前有伏笔**，不能空降；高层可"利用"低层试探主角。

## 六、反派致命坑（避开）

- 没动机、为恶而恶 → 假。
- 太弱、主角轻松碾压 → 没紧张感。
- 太强、主角靠运气赢 → 观众不服。
- 所有反派一个模子 → 审美疲劳。

## 七、卡点 / 留存点放置

- 付费/留存点是**浪尖**，前面必须是蓄势的波谷；卡点前先建**信息差**（观众知道、反派不知道 → 掉马打脸）。
- 集末钩子的力度**必须大于本集所有冲突**，在情绪最高点黑屏。
- 免费平台（红果/抖音）："付费坎"变"留存坎"，技法相同但密度要更高、目标转向完播率。
