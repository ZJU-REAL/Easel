# 角色 / 画面一致性（短剧最难的技术点）

> 本文件只管**外貌/画面一致性**（同一角色跨镜跨集长相不崩）。
> 角色的**内在深度**（行动模型 / want·need·wound·flaw / 弧光 / 可跟随四问 / 台词区分度）见
> `story-engine.md` + `dialogue-craft.md`——那才是治「人物扁平」的地方，别混淆。
>
> AI 生成的最大痛点：同一角色在不同镜头/不同集里长相会变。业界共识的解法是
> **「先定角色参考图，再图生视频(I2V)，而非纯文生视频」** + 统一风格前缀 + 剧集圣经。
> 本文件规定 Easel 短剧的一致性纪律。

## 一、为什么必须先定参考图

- 纯文生视频（text2video）每次从文字重新想象角色 → 长相每镜都不同，无法成剧。
- 正确做法：**每个角色先生成一张（或多角度）定妆参考图**，之后每个镜头都：
  1. 先用 **ai-image-gen 图生图**，把该角色参考图作为输入 → 生成本镜首帧（长相锁定）。
  2. 再用 **ai-video-gen image2video**，把首帧作为起始帧 → 生成动态片段。
- 这样长相由「参考图」这一固定锚点决定，跨镜跨集都一致。

## 二、ref_index：一致性的账本

- 每个角色/场景/道具登记进 `ref_index.json`（`drama_ops.py ref add` 自动分配 C/S/P 编号）。
- 分镜 `shots.json` 里每镜的 `refs` 引用这些编号；`shots validate` 会检查引用是否已登记。
- **同一角色永远引用同一个 C 编号的同一张参考图**——这是"同一部剧"的物理保证。

## 三、统一风格前缀

- series-bible 定一条风格前缀，抄进每集 `shots.json` 的 `style_prefix`，逐镜 prompt 都带上。
- 锁定：画风 + 画幅 + 色调 + 质感。让不同镜头看起来是同一部剧、同一个摄影师拍的。

## 四、跨镜 / 跨集连贯（画面级续接）

在「参考图锁长相」的基础上，再叠画面续接，让镜头之间不跳：

- **尾帧 → 下一镜首帧**：每镜 `tail` 描述尾帧；生成下一镜首帧时以上一镜尾帧为起点（延续姿势/机位/光线）。
- **视频延长**（部分生视频服务支持）：把上一镜片段作为输入，指令「延长 Ns 并继续某动作」，天然衔接。
- **跨集**：下一集第一镜沿用上一集最后的场景/角色状态图作参考，保住"接着上集"的观感。

## 五、多角度参考（进阶，可选）

- 一个角色可生成正面/侧面/半身多张参考图，按镜头机位选用最合适的角度作图生图输入，减少"正脸变侧脸就崩"。
- 起号测试阶段可先单张正面参考图跑通链路，量产再补多角度。

## 六、降级策略

- **没有生视频 API key**：退化为「关键帧图 + slideshow/assemble 图片模式」做**图片短剧**（静帧 + Ken Burns + 字幕 + 配音），一致性反而更稳（图片不会动着变形）。起号早期这是高性价比选择。
- **一致性仍不满意**：优先换更强的图生图/图生视频 provider，或增加参考图角度；不建议上模型级 LoRA（太重，超出本 SKILL 范围）。

## 纪律清单（每镜生成前自检）

- [ ] prompt 带了 `style_prefix`？
- [ ] `refs` 至少引用一个已登记的编号？
- [ ] 角色镜头用了图生图（引用参考图）而非纯文生？
- [ ] 需要连贯的镜头用了上一镜尾帧作起点？
