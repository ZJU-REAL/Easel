# 风格库（用户选一个，agent 按其 spec 制作）

> 卡片没有"唯一正确的美"——**先让用户挑一个风格**（没挑就列这份菜单让 ta 选，或按内容/平台/Profile 推荐 2-3 个），
> 然后**严格按选定风格的 spec** 渲染整套卡片（全程只用这一套）。每个风格是**与主题无关、可复用**的视觉系统。
>
> 字体已装 **Noto Sans CJK SC**(Thin/Light/DemiLight/Regular/Medium/Bold/Black) + **Noto Serif CJK SC**(ExtraLight→Black)。
> CSS 直接 `font-family:"Noto Sans CJK SC"; font-weight:100`(细)~`900`(黑)；衬线用 `"Noto Serif CJK SC"`。
> 英文标题可配 Latin：无衬线 `Inter/Helvetica`，衬线 `Playfair Display/Georgia`（无网络则退系统默认，仍比 WQY 好）。

## 怎么给用户选

给用户看下面**风格名 + 一句话 + 适用**，让 ta 说一个名字（或"第 3 个"）。若用户没主意，按内容品类推荐：
科技/产品→瑞士极简 或 极客终端；知识/深度→杂志编辑；国风/文化→新中式墨韵；生活/情感/护肤→奶油温柔 或 植物清新；
年轻/潮流/消费→多巴胺 Y2K；高端/影视/游戏→高奢黑金；学习/清单/日常→手账贴纸。有 Profile 则再叠 `style.md` 的品牌色微调点缀。

## 1. 瑞士极简 Swiss Minimal
- **一句话**：白底黑字、克制点缀、大留白网格——冷静、专业、高级。**适用**：科技/AI/产品/干货/数据。
- **字体**：`Noto Sans CJK SC`；大标题 **weight 100-300（字越大越细）**，正文 400，标签/kicker 用等宽大写+字距 .2em。
- **配色**：底 `#fafaf8`、字 `#0a0a0a`、次要 `#737373`、发丝线 `#d8d8d4`、点缀**只一个**（克莱因蓝 `#002FA7` 默认 / 柠檬黄 `#FFD500` / 安全橙 `#FF6B35`）。
- **版式**：左对齐、12 栏、非对称留白。**零圆角、零阴影、禁渐变**。靠色块 + 发丝线 + 序号。
- **装饰**：一个实心小方块作 kicker 前缀；巨大细体序号/字母当视觉锚。

## 2. 杂志编辑 Editorial Magazine
- **一句话**：暖纸 + 衬线 + 电子墨水质感——像高级读书笔记/生活方式刊物。**适用**：知识/深度/书评/生活方式/观点。
- **字体**：`Noto Serif CJK SC`；Display 标题 weight 300-500 大字，正文衬线 400；kicker 用等宽大写。英文 `Playfair Display` 斜体做副标/金句。
- **配色**：暖纸 `#f3f0e8`/`#f5f1e8`、深墨 `#0a0a0b`/`#16251b`、次要 `#68625a`、点缀稀用 `#315d93`/`#9b5a2e`。
- **版式**：单/双栏，账本行 + 细线分隔，**不靠卡片浮起**——层级全靠字号/字重/线。小圆角(4px)。
- **装饰**：极淡纸纹 `.grain`(opacity .1, mix-blend multiply)、径向墨晕氛围层；截图给极柔阴影。

## 3. 新中式墨韵 Chinese Ink
- **一句话**：宣纸墨色 + 朱砂印章 + 竖排点睛——东方留白与气韵。**适用**：国风/文化/茶/诗词/传统/节气/非遗。
- **字体**：`Noto Serif CJK SC`（宋体感），标题 weight 500-700，可竖排(`writing-mode:vertical-rl`)做点睛标题。
- **配色**：宣纸 `#f3efe4`/`#efe9dd`、墨 `#1a1a1a`、次要 `#6b6357`、**朱砂 `#a8322d`**（印章/点缀）、可加淡金 `#b08d57`。
- **版式**：大留白但**内容仍铺满**（用竖排标题 + 长段 + 印章块占位），细墨线分隔。
- **装饰**：朱砂方印（一个红色方块内写 1-2 字，如"论"/"新"）、水墨晕染角、竖排小标题。

## 4. 奶油温柔 Cream Soft（莫兰迪）
- **一句话**：奶油底 + 莫兰迪柔色 + 圆润——温暖、治愈、亲切。**适用**：生活/情感/护肤/美食/家居/治愈。
- **字体**：`Noto Sans CJK SC`，标题 weight 500-700(圆润饱满)，正文 400；字色用深棕 `#7A6A5C` 不用纯黑。
- **配色**：奶油 `#FAF6EF`/`#F5F0E8`、燕麦 `#EDE4D3`、莫兰迪点缀（绿 `#A3B0A0` / 蓝 `#8CA3AD` / 粉 `#C9A9A6` / 紫 `#9B8AA0`，选一）。
- **版式**：这是**允许圆角**的风格（卡片圆角 20-28px、柔和），块间大间距、居中或左对齐皆可。
- **装饰**：柔和圆角色块、极淡投影(shadow-soft)、小圆点/短波浪线强调关键词。

## 5. 多巴胺 Y2K Dopamine
- **一句话**：高饱和撞色 + 粗黑字 + 大色块——年轻、张扬、抓眼。**适用**：潮流/穿搭/消费/娱乐/校园/Gen Z。
- **字体**：`Noto Sans CJK SC` **Black(900)** 粗标题(这是少数该用粗黑的风格)，正文 Medium。
- **配色**：大色块底（柠檬黄 `#FFD500` / 荧光绿 `#C5E803` / 亮粉 `#FF5CA8` / 克莱因蓝 `#002FA7`），黑字 `#0a0a0a` 或白字；**撞色但不超过 3 色**。
- **版式**：大色块分区、贴纸标签、粗描边(3-4px black)、可轻微倾斜；填满、饱满、有冲击。
- **装饰**：粗黑描边框、星形/圆形贴纸、大号数字、高亮马克笔块。

## 6. 高奢黑金 Luxe Noir
- **一句话**：近黑底 + 暖白 + 细金线——克制的高级与神秘。**适用**：高端/影视/珠宝/夜景/游戏原画/发布。
- **字体**：`Noto Serif CJK SC` **ExtraLight/Light** 细衬线大标题(优雅)，正文暖白。
- **配色**：底 `#0e0d0c`/`#121014`、字 `#ece2cf`(暖白)、次要 `#9a8c75`、**金 `#d4a04a`**(点缀/细线,面积极小)。
- **版式**：大量深色留白 + 细金发丝线 + 居中或左对齐大标题；**深底上正文用暖白高对比**(绝不深底蓝字)。
- **装饰**：金色细线框/分隔、小金色几何点、字距拉开的英文 kicker。

## 7. 手账贴纸 Journal / Scrapbook
- **一句话**：奶白纸 + 胶带色块 + 手写便签——随性、亲和、像手帐拼贴。**适用**：学习/清单/日常/复盘/干货整理。
- **字体**：`Noto Sans CJK SC` 400-500(亲和)，标题可稍大；关键处用高亮块。
- **配色**：奶白 `#FBF7F0`、胶带色（鹅黄 `#F3D9A4`/薄荷 `#B8D8C8`/藕粉 `#E8C4C4`/天蓝 `#Bcd3E8`，多色但柔和低饱和）。
- **版式**：便签块(轻微旋转 ±2°)、胶带条(色块两端斜切)、虚线分隔、清单勾选框；块状拼贴但**对齐到网格**别乱。
- **装饰**：胶带条、便利贴、手写下划线/圈注、□ 勾选框。

## 8. 极客终端 Terminal / Mono
- **一句话**：深色终端 + 等宽绿字 + 代码感——极客、硬核、技术教程。**适用**：编程/技术/命令行/AI 工程/教程。
- **字体**：等宽 `"Noto Sans Mono CJK SC"` / `JetBrains Mono`；标题也用 mono，靠字号分级。
- **配色**：底 `#0d1117`/`#0a0e14`、主字 `#c9d1d9`、强调**终端绿 `#3fb950`** 或 **琥珀 `#e3b341`**、注释灰 `#6e7681`。
- **版式**：像终端窗口：顶部三个圆点/路径行、`$` 提示符、代码块背景 `#161b22`、行号；左对齐、等宽网格。
- **装饰**：`>` 提示符、代码块、光标方块、标签用 `[TAG]` 形式。

## 9. 植物清新 Botanical Fresh
- **一句话**：米白 + 鼠尾草绿 + 陶土——自然、清爽、有呼吸感。**适用**：健康/园艺/户外/轻食/瑜伽/可持续。
- **字体**：`Noto Sans CJK SC` 300-500，或衬线 `Noto Serif` 做标题；轻盈。
- **配色**：米白 `#f6f4ee`、鼠尾草绿 `#7d9b76`/`#a7bda0`、陶土 `#c08457`、墨绿字 `#2f3b2c`。
- **版式**：大呼吸留白 + 细线 + 植物线描点缀；左对齐、清爽。
- **装饰**：单线叶片/枝条线描(SVG stroke)、细圆点、自然色标签。

## 通用铁律（不管选哪个风格，都遵守）

- **填满画幅**：内容纵向跨度 ≥80%、任何空白带 ≤15%（见 `layout-laws.md`），渲染后 `card_audit.py` 必须全 PASS。
- **一套卡片一个风格一套色**：全程不换风格、不换配色。
- **点缀克制**：除多巴胺外，高饱和点缀面积都要小。
- **去 AI 味**：见 `anti-ai-slop.md`——除非风格明确要求(多巴胺的粗黑字/奶油的圆角/黑金的深底)，否则默认禁渐变文字、禁 emoji 当图标、禁玻璃拟态。
- **可读**：正文 ≥28px。
