# 卡片骨架库（按卡型选，按最小密度线填满）

> 每种骨架给：用途、结构、**最小密度线**（低于此必然死空白）。选定立场(杂志/瑞士)后套用。
> 一套卡片（封面 + N 正文 + 收尾）全程用同一套配色、同一种立场。

## 封面卡（cover）

**结构**（左对齐，非居中）：顶部 kicker(mono 大写，如 `PAPER · 2026` / 分类) → 主标题(Display，1-2 行) → 副标题(一句钩子) → 底部一条信息行(来源/作者/序号) + 发丝线。
- **瑞士**：白底、巨标题 w200、一个点缀色只用在标题里一个关键词或一条下划线。
- **杂志**：暖纸底、衬线大标题、极淡纸纹背景层。
- **最小密度线**：封面允许相对空(标题当主角)，但**必须**有顶 kicker + 底信息行 + 中间标题+副标共三层，且底部信息行压在 ~88% 处（不能让下半整片空）。标题区 + 副标要占到画高 40-55%，底信息锚定底部，中间靠一条细线或一个大序号/大字母充当视觉锚，避免中段 >15% 空洞。

## 正文卡（content，最常用）

一张一个核心观点。**别只写一句话然后留大空白**——用下列承载之一填满：

### 骨架 A：账本行 / 要点列表（吃高度、信息密）
- 4-6 行，每行：**主行(标题 40-44px)** + **副行(说明 24-26px muted)** + 可选右侧数据/标签。行间用发丝线分隔。
- **最小密度线：≥4 行带副行 + 一个收尾块**（3 条光秃短行必死空白）。每行吃 100-140px，5-6 行正好铺满。

### 骨架 B：管线 / 步骤（流程类）
- 竖向 N 步，每步：序号(mono) + 标题(42px) + 描述(26px)，步距 28px，步间可加连接线。
- **最小密度线：≥4 步**；5 步(每步≈96px + 头部)≈填满 1440。

### 骨架 C：对比表 / 双栏（A vs B）
- 左右两栏对照，顶部各一个标题，逐行对比项。适合优劣/前后/我们vs别人。
- **最小密度线：≥5 个对比行**，两栏等宽，行高一致。

### 骨架 D：矩阵 / Bento 格（并置多个点）
- 网格卡，3:4 里 **3×2 = 6 格是甜点**，最多 8 格(4×2)。每格：一个小标题 + 一句 + 可选大数字。
- **最小密度线：6 格**（<6 格留大空）。格子等大、间距一致(24px)、最多一格用 accent 底。

## 数据卡（data）

- 一个**巨型数字**(瑞士 180-200px w200 / 杂志衬线)当主角 + 上 kicker(这数字是什么) + 下 context(对比基准/来源)。
- 多个数字 → 用矩阵格(骨架 D)每格一个数。
- **最小密度线**：单数字卡必须有"kicker + 巨数 + 单位 + 一句解读 + 底部来源"五层，否则空。

## 金句 / 陈述卡（quote，唯一允许较空）

- 一句话金句(60-64px 斜体/大字) + 出处/作者(mono) + 上下发丝线。
- 允许 ≤60% 内容，但**必须补三锚点**：顶 kicker/日期 + 底出处行 + 一条细线。绝不整片空。

## 收尾卡（CTA / summary）

- 回顾 3-5 个要点(小账本行) + 一句行动号召(关注/收藏/评论) + 账号水印。
- **别只放一句"关注我"**——补要点回顾填满。

## 品类 → 立场 → 骨架 速查

| 内容品类 | 立场 | 封面 | 正文骨架 |
|---|---|---|---|
| 论文解读 / 科研 | 瑞士(克莱因蓝) 或 杂志(Indigo Porcelain) | 封面 | 账本(贡献点) + 管线(方法) + 数据(结果) + 矩阵(应用) |
| AI 工具 / 产品干货 | 瑞士(克莱因蓝) | 封面 | 账本 + 对比表 + 数据 |
| 知识科普 / 干货清单 | 杂志(Ink/Dune) 或 瑞士 | 封面 | 账本 + 管线 |
| 生活方式 / 读书 / 情感 | 杂志(Kraft/Dune 暖纸) | 封面 | 金句 + 账本 |
| 数据报告 | 瑞士 | 数据封面 | 数据 + 矩阵 + 对比表 |

> 论文解读示例(修 SwanTale 那类)：**瑞士 + 克莱因蓝**。封面(标题+一句话贡献,填到底) → 论文速览(账本:问题/贡献/方法/结果 4 行带副行) → 方法(管线 4-5 步,铺满) → 结果(1-2 个巨型数字 + 对比行) → 应用+总结(矩阵 6 格 或 账本 + CTA)。每张 card_audit 必须 PASS。
