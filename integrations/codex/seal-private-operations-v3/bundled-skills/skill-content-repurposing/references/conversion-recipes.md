# Conversion Recipes

> 源内容 → 目标格式的转换配方。每个配方定义提取逻辑、格式模板和质量要求。
> Recipe 1–7 面向海外平台（Twitter/LinkedIn/Newsletter 等），Recipe 8–12 面向国内平台（小红书/抖音/微博/知乎/B站）。按目标平台选对应配方。

## Recipe 1: Blog → Twitter/X Thread

**适用场景**：将博客长文拆成推文串

**提取规则**：
- 开头推文 = 核心论点 + hook（提问/反直觉声明/数据点）
- 中间推文 = 每个关键要点一条，每条 ≤ 280 字符
- 结尾推文 = 总结 + CTA（关注/转发/链接）
- 推文数量：5–12 条

**格式模板**：
```
🧵 1/ [Hook — 核心论点的悬念版]

2/ [要点一：用最简洁的语言表述]

3/ [要点二：可附带数据或案例]

...

N/ [总结 + CTA]
如果你觉得有用，转发给需要的人 ↓
原文链接：[URL]
```

**质量要求**：
- 每条推文独立可读
- 避免"接上条"式的依赖表述
- 第一条必须有 hook，最后一条必须有 CTA
- 保留原文关键数据，不虚构

## Recipe 2: Blog → LinkedIn Carousel

**适用场景**：将博客核心观点转为轮播图文案

**提取规则**：
- 第 1 页 = 标题页（问题/痛点，吸引划停）
- 第 2–8 页 = 每页一个要点，大字标题 + 简短说明
- 最后一页 = 总结 + CTA（关注/评论/保存）
- 页数：8–12 页

**格式模板**：
```
[页1 - 封面]
标题：{引发好奇的问题或陈述}
副标题：{补充说明}

[页2–N - 内容页]
大标题：{要点关键词}
正文：{2–3 行解释}
（可选）配图建议：{简述}

[末页 - CTA]
总结一句话 + "觉得有用？点赞+收藏"
```

**质量要求**：
- 每页文字 ≤ 50 字（排版需要留白）
- 要点之间有逻辑递进
- 视觉节奏：标题大 → 正文小

## Recipe 3: Blog → Newsletter Section

**适用场景**：将博客内容浓缩为 Newsletter 的一个版块

**提取规则**：
- 标题：简洁有力，≤ 15 字
- 导语：1–2 句，交代"为什么读者应该关心"
- 正文：3–5 段精华摘要，保留核心论据
- 末尾：原文链接 + 一句推荐语

**格式模板**：
```
### {标题}

{导语：为什么这篇值得读}

{正文摘要段1}

{正文摘要段2}

{正文摘要段3}

👉 [阅读原文]({URL}) — {一句推荐语}
```

**质量要求**：
- 总字数 150–300 字
- 不是原文缩写，而是面向 Newsletter 读者重新组织
- 保留原文最有力的数据点或金句

## Recipe 4: Blog → Video Script (60–90s)

**适用场景**：将博客内容改编为短视频口播脚本

**提取规则**：
- 开头 3 秒：hook（反问/惊人事实/痛点共鸣）
- 中段 40–60 秒：3 个核心要点，口语化表述
- 结尾 10–15 秒：总结 + CTA
- 总时长控制在 60–90 秒（约 200–280 字中文口语）

**格式模板**：
```
[0:00–0:03] HOOK
"{开场一句话，制造悬念}"

[0:03–0:20] 要点一
"{口语化解释，举例}"

[0:20–0:40] 要点二
"{口语化解释，举例}"

[0:40–0:55] 要点三
"{口语化解释，举例}"

[0:55–1:10] 总结 + CTA
"{一句话总结} 如果觉得有用，点个关注不迷路。"

[画面建议]
- 全程面对镜头口播
- 要点切换时可加文字弹幕强调关键词
```

**质量要求**：
- 口语化，不能读起来像文章
- 每个要点有具体例子或数据
- 节奏紧凑，无废话

## Recipe 5: Podcast → Blog Post

**适用场景**：将播客对话转录稿改写为结构化博客文章

**提取规则**：
- 标题：从对话核心话题提炼
- 导语：用 2–3 句交代背景和核心收获
- 正文：按话题分段，每段一个子主题
- 引用：保留嘉宾原话作为 blockquote
- 结尾：关键收获总结 + 播客链接

**格式模板**：
```
# {标题}

{导语段落}

## {子主题一}

{改写段落，从对话中提炼结构化观点}

> "{嘉宾原话}" — {嘉宾姓名}

## {子主题二}

{改写段落}

...

## Key Takeaways

1. {收获一}
2. {收获二}
3. {收获三}

🎙️ [收听完整播客]({URL})
```

**质量要求**：
- 不是逐字转录，而是重新组织结构
- 保留 2–4 条嘉宾原话作为亮点引用
- 文章独立可读，不依赖听过播客

## Recipe 6: Podcast → Quote Cards

**适用场景**：从播客中提取金句制作语录卡

**提取规则**：
- 从转录稿中挑选 5–8 条最有力的金句
- 每条金句 ≤ 30 字（中文）/ 15 词（英文）
- 附上发言人和上下文说明

**格式模板**：
```
[语录卡 1]
金句："{金句内容}"
发言人：{姓名} / {身份}
上下文：{1句话说明这条金句的背景}
视觉建议：{背景色/字体风格建议}

[语录卡 2]
...
```

**质量要求**：
- 金句脱离上下文仍有冲击力
- 不篡改原意，可做轻微语序调整
- 每条风格可独立发布

## Recipe 7: Video → GIF Clips + Social Posts

**适用场景**：从长视频中提取精华片段作为 GIF + 配文

**提取规则**：
- 识别视频中 3–5 个高光时刻（情绪高点/关键操作/趣味瞬间）
- 每个片段 3–8 秒
- 为每个 GIF 写配套的社交文案

**格式模板**：
```
[Clip 1]
时间段：{MM:SS – MM:SS}
描述：{这个片段展示了什么}
配文（Twitter）："{配合GIF的推文}"
配文（LinkedIn）："{更专业语气的版本}"
标签：#tag1 #tag2

[Clip 2]
...
```

**质量要求**：
- GIF 时间段标注精确
- 配文与画面内容呼应，不脱节
- 不同平台的配文语气有区分

## Recipe 8: 长文/公众号 → 小红书笔记（卡片组）

**适用场景**：把一篇深度长文/公众号文章拆成 3-9 张竖版卡片笔记

**提取规则**：
- 封面卡 = 痛点/好处 + 数字 + emoji 的钩子标题（叠在图上）
- 每张内容卡只讲一个论点，从长文中提炼要点，口语化改写
- 末卡 = 总结 + 互动引导（"你觉得呢？评论区聊"）
- caption 100-300 字，闺蜜语气；文末 10-15 个话题标签

**格式模板**：
```
封面：{数字}个{痛点}，第{N}个我踩过坑😭
卡2-N：{要点标题} + 2-3 句口语化说明
末卡：{一句总结} + {互动问题}
caption：{hook} … {关键信息} … {CTA}  #{话题}…
```

**质量要求**：素人感、真实体验，去广告腔；避免导流外站；数据不虚构（详见 skill-xhs-note-creator）。

## Recipe 9: 长文/视频 → 抖音口播脚本

**适用场景**：把内容改成 30-60 秒竖版口播短视频脚本

**提取规则**：
- 前 3 秒 hook（悬念/冲突/反常识/利益点）——决定完播
- 主体 = 3-5 个要点，每点一句话，配画面提示
- 结尾 = 一句记忆点 + 弱引导（避免"点赞关注"显式话术，易限流）
- 标题 ≤ 55 字，激发好奇

**格式模板**：
```
[0-3s] Hook：{一句抓人的话}
[3-Xs] 要点1｜画面：{提示}
       要点2｜画面：{提示}
[结尾] {记忆金句}
标题：{≤55字} #{2-5个热门话题}
```

**质量要求**：口语、短句、强节奏；字幕覆盖层标配；一条视频一个核心信息。

## Recipe 10: 长文 → 微博（短博 + 长图/话题）

**适用场景**：把内容压成微博传播

**提取规则**：
- 核心观点压到 ≤ 140 字，情绪化/话题感表达
- 结合当日热搜话题，嵌 2-3 个 `#话题#` 到正文
- 长内容用长图或"长微博"承载，正文做导语
- @ 相关账号或引导转发放大

**格式模板**：
```
{观点/情绪化钩子，≤140字} #{热点话题}# #{垂类话题}#
（附长图 / 长微博链接）
```

**质量要求**：蹭热点要与内容真相关，不硬蹭；观点鲜明可转发。

## Recipe 11: 长文/经验 → 知乎回答

**适用场景**：把干货沉淀为知乎回答/专栏

**提取规则**：
- 开头先给结论/亮明观点（避免劝退），再展开
- 结构化：分点 + 小标题 + 关键结论加粗
- 论据充分：数据/案例/引用；理性专业不标题党
- 绑定精准话题，长尾问题靠站内搜索长期获量

**格式模板**：
```
{一句话结论/观点}
## {论点一}
{论据 + 案例}
## {论点二}
…
{总结 + 温和引导（赞同/收藏）}
```

**质量要求**：先抛钩子后论证；专业可信；同一深度长文可同时产"回答 + 专栏"两份。

## Recipe 12: 视频/直播 → B站图文动态 / 专栏

**适用场景**：把视频/直播内容复用为 B站图文

**提取规则**：
- 动态：核心看点 + 图，引导看正片（附视频链接/时间线章节）
- 专栏：把讲解整理成图文长文，配分段小标题
- 保留"梗"和社区语感，适度玩梗
- 恰饭内容标注"商业合作"

**格式模板**：
```
动态：{一句看点} + 图 + {正片链接}
专栏：{标题} → {分段小标题} + {配图} + {章节时间线}
```

**质量要求**：社区语感、有梗不尬；引导评论/弹幕互动。
