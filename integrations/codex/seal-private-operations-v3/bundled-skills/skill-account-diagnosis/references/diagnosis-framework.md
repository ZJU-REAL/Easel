# 账号诊断框架

对着**具体画像**做诊断，不是通用打分。每一维都要落到"离该账号自己的定位有多远"。

## 一、垂直度

账号内容标签是否集中、能否被平台正确识别。

| 现状 | 判据 |
|------|------|
| 高 | 近 10 条内容题材集中在 1-2 个方向，标签一致 |
| 中 | 主线清晰但夹杂无关内容（>30% 偏离定位） |
| 低 | 题材发散、平台难以打标，推荐不精准 |

**证据来源**：近期内容题材分布 vs identity 里的"内容方向"。偏离越多，垂直度越低，冷启动越难。

## 二、定位清晰度

能否一句话说清"这个账号是干嘛的、对谁有用"。

- 清晰：主页简介 + 内容能让新用户 3 秒 get 到价值主张与差异化。
- 模糊：定位泛（如"分享生活"）、无差异化、跟大号同质。
**证据**：identity 的"我是谁/差异化" + 主页信息。模糊 → 关注转化低。

## 三、限流 / 降权信号自检（逐项过）

- [ ] 近期播放/曝光断崖式下跌（对比历史均值）
- [ ] 内容含搬运/二次剪辑未二创
- [ ] 触发违禁/敏感词、极限词（可交给 quality-gate 复检）
- [ ] 营销过重（硬广、频繁挂链接/导流）
- [ ] 互动率异常低（曝光有但赞藏评极少 → 内容质量或标签错配）
- [ ] 短时间频繁发布 / 批量搬运账号特征
- [ ] 带违规外链、第三方平台引流

命中项越多，限流可能性越大。**注意**：平台不通知限流，只能从信号推断——结论要说"疑似"，并给自查/申诉方向（可指向 risk-scanner / 申诉流程）。

## 四、流量池阶段判断

结合粉丝量级 + 近期互动率定位当前档，不同档打法不同：

| 阶段 | 特征 | 核心任务 |
|------|------|----------|
| 0-500（冷启动） | 无稳定推荐 | 打磨垂直度、跑通"能被推荐"的基础内容、明确定位 |
| 500-5k（起量） | 偶有小爆 | 找到可复制的内容模型、稳定更新节奏、强化钩子 |
| 5k-1w（放大） | 有稳定推荐 | 批量复制爆款结构、做系列化、提升关注转化 |
| 1w+（沉淀） | 有粉丝基本盘 | 私域/变现、矩阵、粉丝深度运营 |

## 五、内容-受众匹配

内容是否打中 audience 里定义的人群与痛点。

- 高互动内容的题材/情绪 vs audience 痛点是否吻合。
- 错配信号：自认为的受众与实际互动人群不一致（评论区画像 ≠ 目标画像）。

## 处方原则（病因 → 证据 → 处方）

- **病因**：诊断出的具体问题（如"垂直度低"）。
- **证据**：用数据/内容佐证（如"近 10 条有 5 条偏离定位"）。
- **处方**：具体可执行动作（如"接下来 10 条只做 X 方向，砍掉 Y"），**不要写"多互动、坚持更新"这类正确的废话**。

## 分阶段起号动作（示例锚点，按画像调整）

- **0-500**：定位收窄到一个细分 → 对标 3 个同层账号拆结构 → 用统一选题方向发 10 条测试 → 观察哪类进小流量池。
- **500-5k**：把测试出的高互动模型固化成模板 → 固定更新节奏 → 每条强化前 3 秒钩子。
- **5k-1w**：系列化 + 爆款结构复用 → 主页/结尾优化关注转化 → 开始沉淀选题库。
- **1w+**：私域引流 / 变现路径 / 矩阵铺号。
