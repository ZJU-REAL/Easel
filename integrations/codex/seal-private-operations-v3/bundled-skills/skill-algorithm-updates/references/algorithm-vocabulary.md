## 抖音（Douyin）

| 术语 | 含义 |
|------|------|
| 流量池 | 抖音的阶梯式推荐机制——新内容先进入小流量池（约200曝光），表现好则递进到更大流量池 |
| 赛马机制 | 同类内容在同一流量池中竞争，互动数据更好的内容获得更多推荐 |
| 完播率 | 用户观看视频的完成比例，是抖音算法最核心的评估指标之一 |
| 互动率 | 点赞、评论、转发、收藏等行为的综合比率 |
| DOU+ | 抖音官方的内容加热工具，付费推广视频到更多用户 |
| 星图 | 抖音的品牌合作平台（达人接广告的官方通道），影响商业内容的流量分发 |
| 叠加推荐 | 内容在一个流量池中数据达标后，被推入更大流量池的过程 |
| 标签体系 | 抖音通过内容标签匹配用户兴趣标签的推荐逻辑 |
| 去重机制 | 识别并降权重复/搬运内容的算法 |

## 小红书（Xiaohongshu）

| 术语 | 含义 |
|------|------|
| CES评分 | Community Engagement Score，小红书笔记质量的核心指标；业内流传口径 CES = 点赞(1) + 收藏(1) + 评论(4) + 转发(4) + 关注(8)（**非官方公布，权重可能已调整，以平台实际为准**） |
| 薯条 | 小红书的内容推广工具（类似抖音DOU+） |
| 蒲公英 | 小红书的品牌合作平台，管理商业笔记的发布与流量 |
| 笔记流量漏斗 | 笔记从审核→初始曝光→扩大推荐的递进过程 |
| 啄木鸟计划 | 小红书打击虚假种草/刷量/黑灰产的治理专项（"星云"等其它风控名目为业内流传，未必是官方术语，以平台公告为准） |
| 限流 | 笔记因违规或被判定低质而被限制推荐流量 |
| 搜索权重 | 笔记在搜索结果中的排序权重，与标题关键词、标签、互动数据相关 |
| 双列信息流 | 小红书的内容呈现形式，影响封面和标题的点击率 |

## B站（Bilibili）

| 术语 | 含义 |
|------|------|
| 三级火箭 | B站创作者成长路径模型：内容→粉丝→变现 |
| 完播率权重 | B站算法中视频完整观看比例的重要性，影响推荐力度 |
| 充电计划 | B站的观众直接支持创作者的打赏功能 |
| 起飞计划 | B站的内容推广加热工具（类似DOU+） |
| 一键三连 | 点赞+投币+收藏三个动作的合称，是B站互动的标志性行为 |
| 花火平台 | B站的品牌合作平台（UP主接商单的官方通道） |
| 分区推荐 | B站按内容分区（科技、生活、游戏等）进行的推荐机制 |
| 创作激励 | B站根据播放量等数据给创作者的收益分成计划 |

## 微博（Weibo）

| 术语 | 含义 |
|------|------|
| 超话 | 超级话题，微博的垂直兴趣社区功能 |
| 热搜机制 | 微博热搜榜的排序算法，综合搜索量、互动量、时效性 |
| 粉丝头条 | 微博的付费推广工具，将内容推送给粉丝或潜在用户 |
| 微任务 | 微博的品牌合作平台 |
| 铁粉 | 微博标记的高互动粉丝，铁粉互动率影响内容推荐权重 |
| 博文推荐流 | 微博信息流中的推荐内容区域，区别于关注流 |
| 热度值 | 微博衡量话题和内容热度的综合指标 |

## 知乎（Zhihu）

| 术语 | 含义 |
|------|------|
| Wilson评分 | 知乎回答排序的核心算法，基于赞同/反对票的统计置信区间计算 |
| 盐值 | 知乎用户综合评分体系，影响社区权限和内容权重 |
| 知+ | 知乎的内容推广工具，付费扩大回答或文章的曝光 |
| 盐选 | 知乎的付费内容（会员专享）体系 |
| 创作等级 | 知乎创作者的等级体系，影响权益和内容权重 |
| 权重账号 | 在特定领域有高赞同率和专业认可的账号，回答获得更多初始曝光 |
| 折叠 | 低质回答或疑似广告被算法折叠，不在默认视图显示 |

## 视频号（WeChat Channels）

| 术语 | 含义 |
|------|------|
| 社交推荐 | 基于微信社交关系链的推荐——好友点赞的内容出现在你的信息流 |
| 算法推荐 | 基于用户兴趣的个性化推荐，与社交推荐并行 |
| 创作者分成计划 | 视频号的创作者收益分成机制 |
| 直播任务 | 视频号通过任务激励直播创作者的机制 |
| 公私域联动 | 视频号与公众号、小程序、企业微信之间的流量互通机制 |
| 冷启动 | 新账号或新内容获得初始流量的过程，视频号中社交传播对冷启动很重要 |

## 跨平台通用术语

| 术语 | 含义 |
|------|------|
| 推荐算法 | 平台根据用户行为和内容特征自动匹配内容给用户的系统 |
| 内容审核 | 平台对内容进行合规性检查的机制（机器审核 + 人工审核） |
| 限流/降权 | 因违规或低质被平台减少推荐流量 |
| 冷启动 | 新内容或新账号获得初始流量的过程 |
| 标签匹配 | 内容标签与用户兴趣标签的匹配推荐逻辑 |
| 去中心化分发 | 推荐不依赖粉丝量，新账号也能获得公域流量（抖音、小红书典型） |
| 中心化分发 | 推荐更依赖粉丝关系和账号权重（微博、公众号典型） |
