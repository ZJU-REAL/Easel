# 文案风格规则

撰写和审校营销文案时的**营销特有**风格准则。

> **去 AI 味的系统规则统一走 text-polisher 权威源**（`../text-polisher/references/{phrases-to-remove,structures-to-avoid,zh-ai-markers}.md`）——本文件不维护副本，只讲营销文案的风格增量。

## 核心原则（营销视角）

1. **讲利益不讲功能** — 特性说"是什么"，利益说"对你意味着什么"（FAB 内核）
2. **具体优于模糊** — 用结果和数字，避免 "优化"、"赋能"、"创新" 等营销空词
3. **信任前置** — 销量/评价/资质等信任信号早出现，符合国内从众决策
4. **展示优于描述** — 描述具体结果，不堆砌副词
5. **诚实优于夸张** — 不编造数据或评价，极端但真实的值原样展示

## 最佳实践

### 直截了当

先说价值，不要埋在修饰语里。

- 差：本工具支持即时分享文件，从文档到图片，均可直接在对话中传输
- 好：想发截图？文档、图片、语音，想发多少发多少

### 善用反问

反问能让读者代入自己的处境：
- "讨厌退货流程？"
- "还在追着人审批？"

### 善用类比

类比让抽象概念变得具象可记。

### 适度幽默

双关和巧思让文案更有记忆点 — 但前提是匹配品牌调性且不影响清晰度。
