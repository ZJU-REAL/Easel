# 自然衔接与流畅表达

让文案读起来顺、不生硬、不像 AI。用于正文段落之间的过渡与语气把控。定义原则与可选表达，不写死具体案例。

## 段落衔接的作用

好的衔接让读者顺着读下去，一段自然带出下一段。营销文案尤其要顺滑——一旦读起来卡顿或说教，用户就划走。原则：衔接为读者服务，不是为凑字，能不加就不加。

---

## 常用过渡表达

按需选用，同一篇里不要重复用同一个词。

**转折**
- 但是 / 不过 / 话说回来 / 反过来说 / 问题是 / 然而

**递进**
- 而且 / 更重要的是 / 不止如此 / 还有一点 / 关键是

**举例**
- 比如 / 举个例子 / 就拿…来说 / 像我自己

**因果**
- 所以 / 这就是为什么 / 结果就是 / 正因如此

**强调**
- 重点来了 / 划重点 / 说白了 / 最戳我的是 / 一定要知道

**收尾/总结**
- 总之 / 说到底 / 一句话 / 那到底怎么做

## 提问式过渡（增强代入感）

反问和设问能让读者代入自己的处境，适合种草和信息流开头或段落切换：
- 还在为{困扰}发愁吗？
- 那到底该怎么选？
- 是不是也有过这种时刻？
- 你可能会问：这不会很贵吧？
- 听起来很麻烦？其实不用。

---

## 口语化技巧

- **像跟朋友说话** — 种草尤其要有"闺蜜安利"的真实感，避免书面腔和官方腔。
- **短句为主** — 长句拆短，一句话说一件事，移动端读着不累。
- **先说结论/价值** — 别把重点埋在修饰语后面。
- **适度语气词** — "真的""绝了""谁懂啊"等增强真实感，但按品牌调性和平台用，别滥用。
- **读一遍** — 念出来觉得拗口就改，顺口才自然。

## 营销黑话黑名单（避免）

> 通用 AI 味/书面腔/被动语态/公式化结构的系统清单走 **text-polisher 权威源**（`../text-polisher/references/{phrases-to-remove,zh-ai-markers}.md`）。这里只列**营销文案特有**的黑话空词：

- "赋能" / "闭环" / "抓手" / "颗粒度" / "心智" / "链路"（B端营销黑话，to C 尤其忌）
- "极致的" / "满满的" / "满满的干货" / "绝绝子"式滥用空词
- 品牌自嗨词（"匠心""领先""高端大气"）——换成用户视角的具体收益
