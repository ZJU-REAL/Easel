# 文案结构模板库

国内营销文案的**各类型结构模板与分段写法**。用占位符表示变量，不写死具体产品/行业案例。

> **标题 / 钩子公式** → 公共源 `skills/shared/references/hook-title-formulas.md`。
> 本文件只保留 copywriting 特有的**文案类型结构模板 + 分段写法**，不重复上面两者。

## 各文案类型结构模板

### 种草文案

```
1. 钩子首行（痛点/反差/人群，去广告感）
2. 场景代入（我也遇到过… / 谁懂这种崩溃）
3. 转折发现（直到我用了…）
4. 亲测体验（真实使用过程、细节、before/after）
5. 卖点自然带出（藏在体验里，不硬夸）
6. 打消顾虑（价格/踩雷担心的回应）
7. 软性引导（姐妹们冲 / 链接在评论 / 自行搜索）
```
要点：真实感第一，避免硬广被平台限流；卖点融进体验而非罗列。

### 信息流广告

```
1. 首行钩子（利益或痛点前置，1 行定生死）
2. 放大相关性（戳中人群/场景）
3. 核心卖点（1-3 个，最强的先说）
4. 信任信号（销量/评价/权威，一句带过）
5. 明确 CTA + 行动理由（限时/赠品/低价）
```
要点：短、直给、利益前置；用户滑动很快，前 1-2 行决定停留。

### 卖点提炼

```
逐条 FAB 输出：
- 卖点1：{特性} → {优势} → {用户利益}
- 卖点2：…
- 卖点3：…
末尾：排出主打卖点（1 个）+ 辅助卖点（2-3 个）
```
要点：不堆特性，每条都翻译到用户利益；主次分明。

### 活动/促销文案

```
1. 活动主题/力度（一眼看清优惠多少）
2. 价值锚点（原价 vs 现价 / 到手价 / 赠品价值）
3. 紧迫感（限时/限量/前 N 名）
4. 降低决策成本（无门槛/包邮/退换保障）
5. 强 CTA（现在下单 + 具体好处）
```
要点：力度清晰可算、紧迫真实、消除下单顾虑。

### 电商详情页

```
1. 主图区文案（核心卖点一句话）
2. 痛点场景（唤起需求）
3. 卖点分层（FAB 逐条，配参数/成分可视化）
4. 信任背书（销量、评价、资质、检测报告）
5. 异议处理（常见顾虑 Q&A、对比、保障）
6. 下单引导（规格选择、赠品、售后）
```
要点：卖点分层递进，参数可视化，把顾虑一个个消掉。

### 落地页/产品页

```
1. 首屏：价值主张标题 + 副标题 + 主 CTA
2. 信任栏：销量/客户/评分/权威背书
3. 痛点共鸣
4. 方案与核心利益（3-5 个）
5. 使用流程（3-4 步，降低感知复杂度）
6. 案例/评价
7. 异议处理（FAQ / 对比 / 保障）
8. 终极 CTA（重述价值 + 风险逆转）
```
要点：单一核心信息、单一主 CTA；标题匹配流量来源。

## 分段写法要点

### 痛点段
先用具体场景唤起共鸣（"每次…就…"），再点出代价（时间/金钱/情绪），让用户认领问题。

### 利益段（每个卖点）
- 小标题：用户得到的结果
- 正文：怎么做到的（1-2 句）
- 证据：数字/评价/示例（有则加）

### 信任段
国内决策重从众与口碑：销量、真实评价、资质、检测、权威背书尽量前置且具体，"XX万人回购"优于"广受好评"。

### CTA 段
`行动动词 + 用户得到什么 + 行动理由`。避免光秃秃的"购买/提交"，给出现在行动的理由（限时、赠品、价格、名额）。

### 评价/证据选择
优先选带具体结果和场景的（"用了两周，痘印真的淡了"），舍弃"很好用""喜欢"这类空泛评价。
