# 帖子框架的阶段行数分配（post-formatter 专用）

> **框架定义**（每个阶段是什么意思、选择规则）见公共源 `skills/shared/references/copy-frameworks.md`。
> 本文件只补 post-formatter 特有的**帖子结构应用**：每个框架的适用场景 + 各阶段占几行。选定后只用一个，不混用。

## PAS｜痛点 → 放大 → 方案
- 适用：带货、种草、卖服务、任何"读者有明确痛点"的场景。
- 行数分配：痛点 1-2 行、放大 2-4 行、方案 3-5 行。

## AIDA｜注意 → 兴趣 → 欲望 → 行动
- 适用：新品发布、活动预热、任何需要"从围观到心动"的推广。
- 行数分配：四阶段各 2-4 行，欲望段可略多。

## BAB｜现状 → 愿景 → 桥梁
- 适用：前后对比强烈的转变类（减肥/学习/效率）。
- 行数分配：现状 2-3 行、愿景 2-3 行、桥梁 3-5 行。

## STAR｜情境 → 任务 → 行动 → 结果
- 适用：案例复盘、经验分享、客户故事、方法论拆解。
- 行数分配：情境+任务 3-4 行、行动 4-6 行、结果 2-3 行。

## SLAY｜故事 → 道理 → 建议 → 你
- 适用：个人向、干货带情绪、观点输出、求共鸣互动。
- 行数分配：故事 3-5 行、道理 2-3 行、建议 3-4 行、交给你 1-2 行。
