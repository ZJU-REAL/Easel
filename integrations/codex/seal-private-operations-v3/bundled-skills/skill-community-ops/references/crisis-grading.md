# 舆情危机分级与应对

> 供 skill-community-ops 模式 C 使用。危机分级必须给出判定依据，声明只承诺能兑现的措施，绝不做删评控评/情绪对线等损害长期信任的动作。

## 一、危机三级分级标准

按下列维度综合判定档位。**判定原则：命中任一更高档位的硬标准，即升到该档。** 判定时必须列出命中了哪几条。

### 判定维度

- **性质**：是口味吐槽/误解，还是产品质量、安全、虚假宣传、价值观、法律违规问题。
- **实锤程度**：无实据的情绪/抹黑，还是有截图/录音/检测报告等硬证据。
- **扩散度**：局限本条评论区，还是已被转发/搬运到其他平台、上热搜、有媒体/大V介入。
- **责任归属**：是否确实是己方过错。
- **底线触及**：是否涉及人身安全、健康、未成年人、法律、公序良俗、核心价值观。

### 🟢 可忽略（不回应 / 轻回应）

命中标准（同时满足）：
- 纯口味之争、个别情绪化吐槽、无实据的零星抹黑；
- 无实锤、无扩散、非己方明确过错；
- 不触及安全/法律/伦理底线。

处理：不主动回应或轻回应（幽默化解/一句澄清），内部持续监测，防止升级。

### 🟡 需回应（评论区 / 私信公开回应）

命中任一即属此档：
- 有一定合理性的批评或误解，正在小范围传播但未失控；
- 涉及产品/服务体验问题但非安全性、可通过解释或补偿解决；
- 单个有影响力账号提出质疑、有跟风苗头；
- 己方有部分责任但后果可控。

处理：及时公开回应（见「三、回应话术框架」），诚恳、给方案，防止发酵成 🔴。

### 🔴 需正式声明

命中任一即属此档：
- 有实锤的产品质量/安全/健康问题、虚假宣传、数据造假；
- 涉及法律风险、价值观争议、伤害用户或第三方；
- 已跨平台扩散 / 上热搜 / 媒体或大V介入 / 舆论一边倒；
- 事件持续发酵，评论区/私信已无法承接。

处理：出正式声明（见「四、正式声明结构」），必要时配合下架、召回、法律、赔偿等实际动作。

> 升级信号（🟡 随时可能升 🔴）：出现实锤、被搬运到微博/其他平台、有大V或媒体转发、话题量陡增、出现"避雷/塌房"关键词聚集。监测到即重新分级。

## 二、分级响应总览

| 档位 | 是否公开发声 | 产出形态 | 谁来说 |
|------|--------------|----------|--------|
| 🟢 可忽略 | 否 / 轻回应 | 监测建议 + 可选轻回应话术 | 一线运营 |
| 🟡 需回应 | 是 | 评论区/私信回应话术 | 账号主体/客服口径 |
| 🔴 需正式声明 | 是 | 正式声明草稿 + 全渠道同步 | 品牌主体署名 |

## 三、回应话术框架（🟡 档）

结构：**接住情绪 → 说明事实/态度 → 给解决方案 → 留后续通道**。

- 「看到大家的反馈了，[称呼]的心情我理解。关于[问题]，情况是[一句事实]。我们会[具体动作]，给你/大家一个交代。有问题私信我。」
- 体验类问题：「这次[问题]确实影响了体验，是我们没做好。已经在[改进/补偿动作]，也麻烦遇到同样情况的[称呼]私信登记，我们逐一处理。」
- 误解澄清：「先说明一下避免误会：[事实]。如果表达上让大家误解了，是我们的问题，后续会说得更清楚。」

要点：快、诚恳、给确定的下一步动作，不辩解、不甩锅、不挤牙膏。

## 四、正式声明结构（🔴 档）

四段式，逐段写实、不空话：

1. **事实陈述** — 客观说明发生了什么，承认已确认的事实，不回避、不模糊、不甩责任给用户或第三方。
2. **担责态度** — 明确该道歉道歉（"对由此给大家造成的困扰/损失，我们诚恳道歉"），责任是谁的说清楚。
3. **已采取 / 将采取的措施** — 具体、可核查、有时间节点（下架/召回/整改/补偿/追责），只写做得到的。
4. **承诺与后续** — 如何避免重演 + 后续进展公示通道。

写作红线：不用"临时工/系统问题/被黑"等甩锅式表述；不做无法兑现的承诺；不用模糊话术糊弄；语气真诚不端着。声明应由品牌主体署名并全渠道同步（发布平台 + 微博等扩散平台)。

## 五、统一口径

无论哪个档位，团队对外说法必须一致，避免各说各话引发二次舆情。产出：

- **一句话核心立场**：这件事我们的根本态度是什么（如"承认问题、正在解决、绝不推诿"）。
- **3-5 条 Q&A 应答口径**：预判外界会追问什么，逐条给统一回答（如"是不是质量问题？""会不会赔？""为什么现在才说？"）。
- **不确认口径**：尚未查清的事统一回答"正在核实，有结论第一时间同步"，绝不猜测或抢答。

所有对外触点（客服、评论、私信、媒体回应）都用这套口径。

## 六、危机红线（绝对不要做）

- **删评控评** — 大规模删负评、控评、买热搜压制，一旦被扒是"塌房"级二次危机。
- **甩锅** — 甩给临时工、系统、用户、供应商、"被黑"。
- **情绪化对线** — 与网友对骂、阴阳、群嘲、逐条硬刚。
- **发动粉丝** — 号召粉丝去攻击差评者/爆料者，构成网暴。
- **拖延挤牙膏** — 挤一点说一点，反复被追着爆料最被动。
- **虚假承诺** — 为平息舆论承诺做不到的补偿/整改。
- **装死** — 🔴 档沉默不回应，会被解读为默认+傲慢。
- **前后不一** — 不同渠道口径打架。

## 七、响应时效

- 🟢 可忽略：无需公开响应，内部 24 小时内评估一次是否升级。
- 🟡 需回应：建议"黄金 4-6 小时"内公开回应，最迟不过当天，越早越能掐灭发酵（时限为经验值，按事件性质与平台调整）。
- 🔴 需正式声明：建议"黄金 24 小时"内出正式声明（重大安全/法律事件应更快，数小时内先出"已关注并核实"的初步表态占位，再补详细声明）。
- 通则：舆情发酵速度以小时计，尤其微博/抖音。宁可先出"我们已关注，正在核实"的初步表态，也不要长时间沉默。后续按进展滚动更新。
