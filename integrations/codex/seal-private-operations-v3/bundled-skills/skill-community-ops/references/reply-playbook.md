# 评论分层话术库与分级处理规则

> 供 skill-community-ops 模式 A 使用。所有话术均为可套用框架，用 `[占位符]` 代替品牌/产品/链接，不写死具体 case。

## 一、五类评论分层话术库

先把每条评论归入下列五类之一，再套对应话术。同一类给 2-3 条模板供挑选。

### 1. 普通赞美（"好喜欢"、"太可了"、"学到了"）

目标：接住善意、强化关系、顺势引导下一步动作。

- 「谢谢你[称呼]～这条戳中你说明没白做，[下条内容钩子，如'下期讲 XX，蹲一下']」
- 「被夸到了哈哈，你要是也在[相关场景]，评论区聊聊你的做法呀」
- 「爱你！收藏点赞就是最大的动力，[相关合集/合辑入口]也可以翻翻」

要点：不要只回"谢谢"。每条赞美都是一次二次触达机会，顺手抛钩子或引导互动。高赞的正面评论优先置顶。

### 2. 专业提问（"XX 怎么选"、"参数是多少"、"能细说吗"）

目标：给确定性答案、树专业形象、把问题沉淀成选题。

- 「好问题！[一句直接答案]。展开说：[2-3 句要点]。想更细的话[指向对应内容/私信]」
- 「这个[相关变量]不同答案不一样：如果你是[场景A]就[答案A]，[场景B]就[答案B]」
- 「正好很多人问，我准备单独出一条讲透，[蹲更新钩子]」

要点：能公开答的公开答（利于其他人看到、涨专业分）；涉及个性化/隐私/交易的引导私信。高频提问记入选题池（交给模式 B）。

### 3. 求购买 / 求链接（"哪买"、"求链接"、"多少钱"）

目标：合规承接购买意图，不在评论区硬发导流违规内容。

- 「想要的话看[主页/私信/指定合规入口]哈，评论区不方便放链接～」
- 「[产品占位]我整理在[合规位置]了，[称呼]自取」
- 「懂你的心动！具体[规格/价格]私信我，给你说清楚不踩坑」

要点：多数平台评论区直接甩购买链接/微信/价格易触发导流违规（尤其小红书、抖音），一律引导到平台允许的合规入口或私信。这类评论建议归"引导私信"级。

### 4. 杠精抬杠（挑刺、抬杠、"这有什么难的"、阴阳怪气但非恶意）

目标：不被带节奏、四两拨千斤、展示格局，必要时借力打力涨互动。

- 「你说的这点确实可以更严谨，补充一下：[事实/依据]。也谢谢你较真～」（有理的杠，认+补）
- 「哈哈这个角度有意思，不过我更想说的是[重申核心观点]，你怎么看？」（无理的杠，幽默转移）
- 「各有各的玩法呀，适合你的就是好的[相关领域]」（纯口味之争，不辩）

要点：对事不对人，绝不情绪化对线。有理的杠大方认并补充（反而加分）；无理的杠幽默化解或重申观点；纯抬杠可冷处理。切忌逐条硬刚，会拉低评论区氛围也耗精力。

### 5. 黑粉 / 恶意差评（人身攻击、造谣、辱骂、恶意刷差评）

目标：保护自己和评论区氛围，不喂流量，留证据，分清"批评"与"攻击"。

- 真实批评（哪怕难听）→ 按第 2/4 类诚恳回应，把差评变口碑：「这点是我没做好，[改进动作]，谢谢直言」
- 无实据的抹黑造谣 → 「不实信息就不多解释了，事实是[一句澄清]，需要的话保留追责权利」（一次性澄清，不反复纠缠）
- 纯辱骂/人身攻击 → 不回复，直接隐藏/删除 + 拉黑，必要时举报。不要在评论区对骂。
- 有组织的恶意刷评（疑似水军）→ 截图留证，冷处理不上头，视规模决定是否升级到模式 C 危机流程。

要点：区分"尖锐批评"和"恶意攻击"，前者是养口碑的机会，后者不喂流量。绝不辱骂回击、不群嘲、不发动粉丝网暴对方。

## 二、分级处理规则

对每条评论判定处置级别（一条评论可叠加，如"必回+置顶"）：

| 级别 | 判定标准 | 动作 |
|------|----------|------|
| 必回 | 专业提问、高赞正面、真实批评、有影响力账号的评论、带明确诉求的评论 | 24 小时内回复（发布后前 1-2 小时的评论优先，吃早期互动流量） |
| 引导私信 | 求购买/求链接、涉及价格隐私、个性化咨询、需长篇解答 | 公开一句话接住 + 引导到私信/合规入口 |
| 置顶 | 优质提问、金句式好评、可补充信息的评论、能带节奏的正向评论 | 置顶以引导后续读者、塑造氛围、承接高频问题 |
| 冷处理 | 无理抬杠、口味之争、零星非恶意吐槽、纯情绪宣泄 | 不回复，不删除，让它自然沉底 |
| 删除/拉黑 | 人身攻击、辱骂、造谣、垃圾广告、导流小广告、疑似水军刷屏 | 隐藏或删除 + 拉黑，保留截图证据，必要时举报 |

补充原则：
- 发布后**黄金 1-2 小时**集中回复，早期互动率影响平台推流。
- 回复本身是内容：优质回复会被其他读者看到，值得像写正文一样对待。
- 不要"已读乱回"，宁可晚回也别敷衍模板刷屏。
- 高频重复问题不必逐条回，可置顶一条统一解答 + 记入选题池。
